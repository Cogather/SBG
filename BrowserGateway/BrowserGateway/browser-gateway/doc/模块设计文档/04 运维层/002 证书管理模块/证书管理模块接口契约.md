# 证书管理模块 - 模块间接口契约文档

## 1. 概述

本文档定义了证书管理模块与其他模块之间的接口契约。证书管理模块是BGW系统运维层的安全核心模块，负责TLS证书的全生命周期管理。模块通过`CertInfo`单例对外提供证书数据访问，通过`SubscribeCert`组件实现CSP SDK证书订阅，通过`ExCertInfo`处理器实现证书更新时的TCP服务器热重启。同时通过适配层的`CertificateAdapter`接口支持CSP SDK和Custom两种证书来源模式。本文档确保模块间的交互规范、明确、无歧义，依据本文档和设计说明书可100%复现证书管理模块的全部功能代码。

## 2. 模块依赖关系

```
证书管理模块 (tcpserver.cert.*)
│
├── [对外提供] CertInfo 单例
│   └── 调用方: AbstractTcpServer (tcpserver.AbstractTcpServer)
│       ├── ControlTcpServer (tcpserver.control.ControlTcpServer)
│       ├── MediaTcpServer (tcpserver.media.MediaTcpServer)
│       ├── ControlTlvServer (tcpserver.control.ControlTlvServer)
│       └── MediaTlvServer (tcpserver.media.MediaTlvServer)
│
├── [对外提供] ExCertInfo 证书更新处理器
│   └── 调用方: CSP SDK (通过IExCertHandler接口回调)
│
├── [对外提供] CertificateAdapter 适配器接口
│   ├── CspCertificateAdapter (CSP SDK模式)
│   └── CustomCertificateAdapter (Custom模式)
│
└── [依赖] 外部模块/组件
    ├── CSP SDK (com.huawei.csp.certsdk.*) - 反射调用
    ├── BouncyCastle (org.bouncycastle.*) - 加密库
    ├── Netty SSL (io.netty.handler.ssl.*) - TLS上下文
    ├── MediaTcpServer (tcpserver.media.MediaTcpServer) - 热重启
    └── ControlTcpServer (tcpserver.control.ControlTcpServer) - 热重启
```

## 3. 对外提供的接口契约

### 3.1 CertInfo 证书信息单例

#### 3.1.1 接口描述
证书信息的核心存储和访问单例，为TCP服务器提供TLS加密所需的CA证书、设备证书和私钥。采用双重检查锁定（DCL）单例模式，所有写操作通过`synchronized`方法保证线程安全。

#### 3.1.2 接口定义
```java
package com.huawei.browsergateway.tcpserver.cert;

import org.bouncycastle.asn1.pkcs.PrivateKeyInfo;
import org.bouncycastle.jce.provider.BouncyCastleProvider;
import org.bouncycastle.openssl.PEMDecryptorProvider;
import org.bouncycastle.openssl.PEMEncryptedKeyPair;
import org.bouncycastle.openssl.PEMKeyPair;
import org.bouncycastle.openssl.PEMParser;
import org.bouncycastle.openssl.jcajce.JcaPEMKeyConverter;
import org.bouncycastle.openssl.jcajce.JcePEMDecryptorProviderBuilder;
import org.bouncycastle.util.io.pem.PemObject;
import org.bouncycastle.util.io.pem.PemWriter;

import java.io.*;
import java.security.PrivateKey;
import java.security.Security;

/**
 * 证书信息单例
 * 职责：存储证书内容、提供证书访问、私钥格式转换（PKCS#1 → PKCS#8）
 */
public class CertInfo {
    private static CertInfo instance;
    private static String caContent = "";
    private static String deviceContent = "";
    private static String keyContent = "";
    private static String keypwd = "";

    /**
     * 获取CertInfo单例实例
     *
     * 调用方: AbstractTcpServer.start()
     * 调用时机: TCP服务器启动时获取证书信息
     *
     * @return CertInfo 单例实例
     *
     * 实现要求:
     *   - 使用双重检查锁定（DCL）模式
     *   - 外层方法使用synchronized修饰
     *   - 内层使用synchronized(CertInfo.class)同步块
     */
    public static synchronized CertInfo getInstance();

    /**
     * 设置CA证书内容
     *
     * 调用方: CSP SDK证书回调（通过反射调用）
     * 调用时机: 证书订阅成功后，CSP SDK回调设置CA证书
     *
     * @param c CA证书内容（PEM格式字符串）
     *
     * 实现要求:
     *   - synchronized方法
     *   - c为null时直接返回（空保护）
     *   - 将caContent设置为c
     */
    public static synchronized void SetCaContent(String c);

    /**
     * 设置设备证书内容、私钥和密码
     *
     * 调用方: CSP SDK证书回调（通过反射调用）
     * 调用时机: 证书订阅成功后，CSP SDK回调设置设备证书
     *
     * @param deviceContent 设备证书内容（PEM格式字符串）
     * @param keyContent 私钥内容（PEM格式字符串，可能为PKCS#1加密格式）
     * @param keypwd 私钥密码（用于解密加密的私钥，可为null）
     *
     * 实现要求:
     *   - synchronized方法
     *   - deviceContent或keyContent为null时直接返回（空保护）
     *   - keypwd为null时设为空字符串""
     */
    public static synchronized void SetDeviceContent(String deviceContent, String keyContent, String keypwd);

    /**
     * 设置设备证书内容（CSP兼容重载）
     *
     * 调用方: CSP SDK（通过反射调用，CSP模式下使用）
     * 说明: 保留的CSP模式兼容方法签名，Custom模式下不会被调用
     *
     * @param cert CSP SDK的证书对象（Object类型，通过反射获取字段值）
     *
     * 实现要求:
     *   - synchronized方法
     *   - Custom模式下方法体为空
     */
    public static synchronized void SetDeviceContent(Object cert);

    /**
     * 获取CA证书内容的输入流
     *
     * 调用方: AbstractTcpServer.start() - 构建SslContext时使用
     * 调用时机: TLS TCP服务器启动时
     *
     * @return InputStream CA证书内容的字节输入流
     *
     * 实现要求:
     *   - return new ByteArrayInputStream(caContent.getBytes())
     */
    public InputStream Ca();

    /**
     * 获取设备证书内容的输入流
     *
     * 调用方: AbstractTcpServer.start() - 构建SslContext时使用
     * 调用时机: TLS TCP服务器启动时
     *
     * @return InputStream 设备证书内容的字节输入流
     *
     * 实现要求:
     *   - return new ByteArrayInputStream(deviceContent.getBytes())
     */
    public InputStream Device();

    /**
     * 获取私钥内容的输入流（已转换为PKCS#8格式）
     *
     * 调用方: AbstractTcpServer.start() - 构建SslContext时使用
     * 调用时机: TLS TCP服务器启动时
     *
     * @return InputStream PKCS#8格式私钥的字节输入流
     * @throws IOException 私钥解析或转换失败时抛出
     *
     * 实现要求:
     *   - 调用loadEncryptedPrivateKey(keyContent, keypwd.toCharArray())解密私钥
     *   - 调用convertPkcs1ToPkcs8Stream(privateKey)转换为PKCS#8格式
     *   - 支持PEMEncryptedKeyPair（加密私钥）和PEMKeyPair（非加密私钥）
     *   - 使用BouncyCastle库进行PEM解析和格式转换
     *   - PKCS#8输出标签为"PRIVATE KEY"
     */
    public InputStream Key() throws IOException;

    /**
     * 检查证书是否就绪
     *
     * 调用方: AbstractTcpServer.start() - 判断是否启用TLS
     * 调用时机: TCP服务器启动时和每个新连接初始化时
     *
     * @return boolean true=证书就绪（可启用TLS），false=证书未就绪
     *
     * 实现要求:
     *   - 判断条件: !caContent.isEmpty() && !keyContent.isEmpty()
     *   - 注意: 仅检查caContent和keyContent，不检查deviceContent
     */
    public boolean isCertReady();
}
```

#### 3.1.3 线程安全要求

| 方法/字段 | 线程安全机制 | 说明 |
|----------|-------------|------|
| getInstance() | synchronized方法 + DCL | 双重检查锁定保证单例安全 |
| SetCaContent() | synchronized静态方法 | 确保CA证书写入原子性 |
| SetDeviceContent() | synchronized静态方法 | 确保设备证书+私钥+密码写入原子性 |
| caContent/deviceContent/keyContent/keypwd | static字段 | 通过synchronized方法保护读写 |

#### 3.1.4 私钥格式转换规范

**支持的输入格式**:
1. **PEMEncryptedKeyPair**: 加密的PKCS#1私钥（需要密码解密）
2. **PEMKeyPair**: 非加密的PKCS#1私钥

**输出格式**: PKCS#8 PEM格式（标签: "PRIVATE KEY"）

**转换流程**:
```
输入: PEM格式私钥字符串 + 密码
  → PEMParser解析
  → 判断类型:
    [PEMEncryptedKeyPair] → JcePEMDecryptorProviderBuilder解密 → PEMKeyPair
    [PEMKeyPair] → 直接使用
  → JcaPEMKeyConverter.getKeyPair().getPrivate() → PrivateKey
  → PrivateKeyInfo.getInstance(privateKey.getEncoded()) → PKCS#8 DER
  → PemObject("PRIVATE KEY", der) → PemWriter → 输出流
```

### 3.2 SubscribeCert 证书订阅组件

#### 3.2.1 接口描述
应用启动时自动执行的证书订阅组件。通过反射调用CSP SDK完成CA证书和设备证书的订阅，不直接依赖CSP SDK的编译时类。

#### 3.2.2 接口定义
```java
package com.huawei.browsergateway.tcpserver.cert;

import org.apache.logging.log4j.LogManager;
import org.apache.logging.log4j.Logger;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Component;

import javax.annotation.PostConstruct;
import java.lang.reflect.Method;
import java.util.ArrayList;
import java.util.List;

/**
 * 证书订阅组件
 * 负责订阅证书更新，并在证书更新时触发TCP服务器重启
 */
@Component
public class SubscribeCert {
    private static final Logger log = LogManager.getLogger(SubscribeCert.class);

    @Autowired
    private ExCertInfo exCertHandler;

    /**
     * 应用启动时自动订阅CSP SDK证书
     *
     * 触发时机: Spring容器初始化完成后（@PostConstruct）
     *
     * 执行流程:
     *   1. 通过反射初始化CSP SDK:
     *      - CertMgrApiImpl.getCertMgrApi() → certSDKInit()
     *   2. 创建证书订阅实体列表:
     *      - CA证书实体:
     *        sceneName = "sbg_server_ca_certificate"
     *        sceneDescCN = "云浏览器服务端CA证书"
     *        sceneDescEN = "SBG server CA certificate"
     *        sceneType = SceneType.CA
     *        feature = 0
     *      - 设备证书实体:
     *        sceneName = "sbg_server_device_certificate"
     *        sceneDescCN = "云浏览器服务端设备证书"
     *        sceneDescEN = "SBG server Device Certificate"
     *        sceneType = SceneType.DEVICE
     *        feature = 0
     *   3. 通过反射执行证书订阅:
     *      - ExCertMgrApiImpl.getExCertMgrApi()
     *      - subscribeExCert("browsergw", certList, exCertHandler, "/opt/csp/browsergw")
     *   4. 检查订阅结果并记录日志
     *
     * 异常处理: catch所有Exception，打印error日志，不向上传播
     *
     * CSP SDK反射调用的类:
     *   - com.huawei.csp.certsdk.certapiImpl.CertMgrApiImpl
     *   - com.huawei.csp.certsdk.certapiImpl.ExCertMgrApiImpl
     *   - com.huawei.csp.certsdk.pojo.SubscribeEntity
     *   - com.huawei.csp.certsdk.enums.SceneType
     *   - com.huawei.csp.certsdk.handler.IExCertHandler
     */
    @PostConstruct
    public void SubscribeCertInfo();
}
```

|------|-----|------|
| serviceName | "browsergw" | CSP SDK注册的服务名 |
| certPath | "/opt/csp/browsergw" | CSP SDK证书存储路径 |
| handler | ExCertInfo实例 | 证书更新回调处理器 |

#### 3.2.4 证书订阅场景

### 3.3 ExCertInfo 扩展证书处理器

#### 3.3.1 接口描述
CSP SDK证书更新的回调处理器。仅在CSP模式（`adapter.provider.type=CSP_SDK`）下激活。接收证书更新通知后，执行TCP服务器热重启以应用新证书。

#### 3.3.2 接口定义
```java
package com.huawei.browsergateway.tcpserver.cert;

import com.huawei.browsergateway.tcpserver.control.ControlTcpServer;
import com.huawei.browsergateway.tcpserver.media.MediaTcpServer;
import org.apache.logging.log4j.LogManager;
import org.apache.logging.log4j.Logger;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Component;

/**
 * CSP证书处理器 - 仅在CSP模式下可用
 * Custom模式下此功能由CustomCertificateAdapter处理
 */
@Component
@ConditionalOnProperty(name = "adapter.provider.type", havingValue = "CSP_SDK", matchIfMissing = false)
public class ExCertInfo {
    private static final Logger log = LogManager.getLogger(ExCertInfo.class);

    @Autowired
    private MediaTcpServer mediaServer;

    @Autowired
    private ControlTcpServer controlServer;

    /**
     * 处理CSP SDK的证书更新通知
     *
     * 调用方: CSP SDK（通过IExCertHandler接口回调）
     * 调用时机: CSP SDK检测到证书更新时
     *
     * @param exCertEntityList 证书实体列表（CSP SDK传递的Object）
     * @param certNotifyType 证书通知类型（CSP SDK传递的Object）
     *
     * 执行流程:
     *   1. 打印info日志 "start processing the certificate list"
     *   2. 打印info日志 "start restarting the server"
     *   3. 停止媒体TLS服务器: mediaServer.stopServer()
     *   4. 停止控制TLS服务器: controlServer.stopServer()
     *   5. 启动媒体TLS服务器: mediaServer.startServer()
     *   6. 启动控制TLS服务器: controlServer.startServer()
     *   7. 打印info日志 "restart the server end"
     *
     * 热重启顺序: 先停止所有TLS服务器，再依次启动（确保使用最新证书）
     *
     * 条件激活: 仅当adapter.provider.type=CSP_SDK时注册为Spring Bean
     */
    public void exCertHandler(Object exCertEntityList, Object certNotifyType);
}
```

#### 3.3.3 热重启时序

```
CSP SDK证书更新通知
  → exCertHandler()
    → mediaServer.stopServer()    // 停止媒体TLS服务器
      → AbstractTcpServer.stop()
        → channelFuture.channel().close().sync()
        → workerGroup.shutdownGracefully()
        → bossGroup.shutdownGracefully()
    → controlServer.stopServer()  // 停止控制TLS服务器
    → mediaServer.startServer()   // 启动媒体TLS服务器（使用新证书）
      → AbstractTcpServer.start(true)
        → CertInfo.getInstance() → 获取最新证书
        → SslContextBuilder构建新的SSL上下文
    → controlServer.startServer() // 启动控制TLS服务器（使用新证书）
```

### 3.4 CertificateAdapter 证书适配器接口

#### 3.4.1 接口描述
证书管理的统一适配器接口，定义证书订阅、获取和就绪检查的标准方法。通过`AdapterBeanConfiguration`根据运行环境自动选择CSP SDK实现或Custom实现。

#### 3.4.2 接口定义
```java
package com.huawei.browsergateway.adapter.interfaces;

import com.huawei.browsergateway.adapter.dto.CertScene;
import com.huawei.browsergateway.adapter.dto.CertUpdateCallback;
import java.util.List;

/**
 * 证书适配器接口
 * 职责：管理证书的订阅、更新和获取
 */
public interface CertificateAdapter {

    /**
     * 订阅证书
     *
     * 功能: 向证书管理系统订阅指定场景的证书，并注册更新回调
     *
     * @param serviceName 服务名称（如 "browsergw"）
     * @param certScenes 证书场景列表（CA证书场景 + 设备证书场景）
     * @param certPath 证书存储路径（如 "/opt/csp/browsergw"）
     * @param callback 证书更新回调（可为null）
     * @return boolean 订阅是否成功
     *
     * CSP模式实现要求:
     *   - 通过反射初始化CSP SDK: CertMgrApiImpl.getCertMgrApi() → certSDKInit()
     *   - 将CertScene列表转换为CSP SDK的SubscribeEntity列表
     *   - 使用JDK动态代理创建IExCertHandler处理器
     *   - 通过反射调用subscribeExCert()
     *   - 订阅成功且callback不为null时，将callback加入回调列表
     *   - 异常时返回false
     *
     * Custom模式实现要求:
     *   - 打印info日志
     *   - 如果callback不为null:
     *     a. 将callback加入回调列表
     *     b. 立即触发一次回调: callback.onCertificateUpdate(caContent, deviceContent, privateKey)
     *   - 始终返回true
     */
    boolean subscribeCertificates(String serviceName, List<CertScene> certScenes,
        String certPath, CertUpdateCallback callback);

    /**
     * 获取CA证书内容
     *
     * @return String CA证书内容（PEM格式字符串），未加载时返回空字符串""
     */
    String getCaCertificate();

    /**
     * 获取设备证书内容
     *
     * @return String 设备证书内容（PEM格式字符串），未加载时返回空字符串""
     */
    String getDeviceCertificate();

    /**
     * 获取私钥内容（已转换为PKCS#8格式）
     *
     * @return String 私钥内容（PEM格式字符串），未加载时返回空字符串""
     */
    String getPrivateKey();

    /**
     * 检查证书是否就绪
     *
     * @return boolean true=CA证书和设备证书都已加载，false=尚未就绪
     *
     * 实现要求:
     *   - 判断条件: caContent != null && !caContent.isEmpty() && 
     *               deviceContent != null && !deviceContent.isEmpty()
     */
    boolean isCertificateReady();

    /**
     * 初始化证书SDK
     *
     * CSP模式: 通过反射调用CertMgrApiImpl.getCertMgrApi().certSDKInit()
     * Custom模式: 调用loadCertificatesFromFile()从本地文件加载证书
     *
     * @return boolean 初始化是否成功
     */
    boolean initialize();
}
```

#### 3.4.3 适配器Bean选择策略

**配置类**: `com.huawei.browsergateway.config.AdapterBeanConfiguration`

```java
@Bean
@Primary
public CertificateAdapter certificateAdapter(
        @Autowired(required = false) CspCertificateAdapter cspAdapter,
        @Autowired(required = false) CustomCertificateAdapter customAdapter) {
    // 优先级: CSP SDK > Custom
    // 两者都不可用时抛出IllegalStateException
}
```

**选择规则**:
1. 如果`CspCertificateAdapter` Bean存在 → 使用CSP SDK实现
2. 否则如果`CustomCertificateAdapter` Bean存在 → 使用Custom实现
3. 否则 → 抛出`IllegalStateException("No CertificateAdapter implementation found")`

### 4.2 CertUpdateCallback 证书更新回调接口

```java
package com.huawei.browsergateway.adapter.dto;

/**
 * 证书更新回调接口
 * 当证书内容发生变更时触发
 */
public interface CertUpdateCallback {
    /**
     * 证书更新时的回调
     *
     * 调用时机:
     *   - CSP模式: CSP SDK检测到证书更新时，通过动态代理触发
     *   - Custom模式: subscribeCertificates()调用时立即触发一次
     *
     * @param caContent CA证书内容（PEM格式字符串）
     * @param deviceContent 设备证书内容（PEM格式字符串）
     * @param privateKey 私钥内容（PEM格式字符串）
     */
    void onCertificateUpdate(String caContent, String deviceContent, String privateKey);
}
```

## 5. 依赖的外部接口契约

### 5.1 AbstractTcpServer（消费方）

#### 5.1.1 接口描述
抽象TCP服务器基类，是证书管理模块的主要消费方。在启动TCP服务器时使用`CertInfo`提供的证书构建Netty `SslContext`。

#### 5.1.2 证书消费方式

```java
/**
 * AbstractTcpServer.start() 方法中的证书使用
 *
 * 调用的CertInfo方法:
 *   - CertInfo.getInstance() - 获取单例
 *   - certInstance.isCertReady() - 检查证书就绪状态
 *   - certInstance.Ca() - 获取CA证书流
 *   - certInstance.Device() - 获取设备证书流
 *   - certInstance.Key() - 获取PKCS#8私钥流
 *
 * TLS配置参数:
 *   - 密码套件:
 *     "TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256"
 *     "TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384"
 *     "TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256"
 *     "TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384"
 *   - 协议版本: "TLSv1.2", "TLSv1.3"
 *   - 信任管理器: CA证书
 */
```

#### 5.1.3 TLS启用条件

| 条件 | 说明 |
|------|------|
| `certInstance.isCertReady() == true` | CA证书和私钥已加载 |
| `isTLS == true` | 启动参数指定为TLS模式 |

**两个条件同时满足时**: 构建`SslContext`，在Netty Pipeline中添加SSL Handler

**任一条件不满足时**: `sslCtx = null`，启动非TLS的TCP服务器

#### 5.1.4 TLS TCP服务器类型

| 服务器类 | 端口配置键 | 默认端口 | isTLS | 说明 |
|---------|-----------|---------|-------|------|
| ControlTcpServer | browsergw.tcp.control-tls-port | 30012 | true | 控制通道TLS服务器 |
| MediaTcpServer | browsergw.tcp.media-tls-port | 30013 | true | 媒体通道TLS服务器 |
| ControlTlvServer | browsergw.tcp.control-port | 30001 | false | 控制通道非TLS服务器（需enable-http=true） |
| MediaTlvServer | browsergw.tcp.media-port | 30011 | false | 媒体通道非TLS服务器（需enable-http=true） |

### 5.2 MediaTcpServer / ControlTcpServer（热重启依赖）

#### 5.2.1 接口描述
`ExCertInfo`依赖`MediaTcpServer`和`ControlTcpServer`执行证书更新后的热重启。

#### 5.2.2 使用的接口方法

```java
/**
 * MediaTcpServer / ControlTcpServer
 * 继承自 AbstractTcpServer
 */

/**
 * 停止TCP服务器
 *
 * 调用方: ExCertInfo.exCertHandler()
 * 调用时机: 证书更新时，先停止服务器
 *
 * 内部流程:
 *   1. channelFuture.channel().close().sync()
 *   2. workerGroup.shutdownGracefully()
 *   3. bossGroup.shutdownGracefully()
 */
public void stopServer();

/**
 * 启动TCP服务器
 *
 * 调用方: ExCertInfo.exCertHandler()
 * 调用时机: 证书更新后，重新启动服务器
 *
 * 内部流程:
 *   1. 调用AbstractTcpServer.start(true) - TLS模式
 *   2. 从CertInfo获取最新证书
 *   3. 构建新的SslContext
 *   4. 绑定端口启动服务
 */
public void startServer();
```

#### 5.3.2 CspCertificateAdapter 动态代理处理器

**代理接口**: `com.huawei.csp.certsdk.handler.IExCertHandler`

**拦截方法**: `handle(Object certInfo)`

**处理逻辑**:
```
当method.getName() == "handle" && args.length == 1:
  1. 从certInfo获取CA内容: certInfo.getCaContent()
  2. 从certInfo获取扩展证书实体: certInfo.getExCertEntity()
  3. 如果exCertEntity不为null:
     - 获取设备证书: exCertEntity.getDeviceContent()
     - 获取私钥: exCertEntity.getPrivateKeyContent()
  4. 更新本地字段: caContent, deviceContent, privateKey
  5. 如果callback不为null: callback.onCertificateUpdate(caContent, deviceContent, privateKey)
```

## 9. 性能要求

### 9.1 响应时间要求

| 操作 | 最大响应时间 | 说明 |
|------|------------|------|
| CertInfo.getInstance() | 1毫秒 | 内存操作，单例已创建后无锁竞争 |
| CertInfo.Ca() / Device() | 1毫秒 | 字符串转字节流 |
| CertInfo.Key() | 100毫秒 | 涉及PEM解析和PKCS格式转换 |
| CertInfo.isCertReady() | 1毫秒 | 字符串判空 |
| SubscribeCert.SubscribeCertInfo() | 5秒 | CSP SDK初始化和订阅 |
| ExCertInfo.exCertHandler() | 10秒 | 包含TCP服务器停止和重启 |
| CustomCertificateAdapter.loadCertificatesFromFile() | 1秒 | 文件I/O |
| SslContextBuilder.build() | 500毫秒 | SSL上下文构建 |

### 9.2 并发要求

- CertInfo所有写方法使用`synchronized`保证线程安全
- CertInfo单例使用DCL保证多线程下只创建一个实例
- CertificateAdapter的callbacks使用`CopyOnWriteArrayList`保证并发安全
- TCP服务器热重启期间会有短暂的服务中断（停止→启动之间）
