# BrowserGateway 证书管理模块设计说明书

## 1. 概述

### 1.1 模块定位
证书管理模块是BrowserGateway系统运维层的核心安全模块，负责TLS证书的全生命周期管理，包括证书订阅、证书加载、证书更新、私钥格式转换以及TLS上下文构建。模块通过`CertInfo`单例类为TCP服务器（控制通道和媒体通道）提供TLS加密所需的CA证书、设备证书和私钥，通过`SubscribeCert`组件实现CSP SDK证书的自动订阅，通过`ExCertInfo`处理器实现证书更新时的TCP服务器热重启。同时，模块还通过适配层的`CertificateAdapter`接口支持CSP SDK和Custom两种证书来源模式。

### 1.2 设计目标
- **证书存储与访问**：通过`CertInfo`单例提供线程安全的证书内容存储和访问
- **私钥格式转换**：支持PKCS#1加密私钥到PKCS#8格式的自动转换（使用BouncyCastle库）
- **证书订阅**：通过CSP SDK实现证书的自动订阅和更新通知
- **热重启支持**：证书更新时自动重启TLS TCP服务器，实现证书热更新
- **多模式适配**：通过`CertificateAdapter`接口支持CSP SDK模式和Custom本地文件模式
- **TLS安全通信**：为Netty TCP服务器提供TLS上下文，支持TLSv1.2/TLSv1.3协议

### 2.4 数据存储

证书管理模块使用内存级单例模式存储证书数据：

```java

private static CertInfo instance;

private static String deviceContent = "";  // 设备证书内容（PEM格式）
```

- **存储方式**: 内存单例（`CertInfo.getInstance()`）

- **数据来源**: CSP SDK证书订阅回调 或 Custom模式本地文件加载

### 3.1 CertInfo 证书信息单例

**包路径**: `com.huawei.browsergateway.tcpserver.cert.CertInfo`

**设计模式**: 双重检查锁定单例模式（DCL Singleton）

#### 3.1.1 字段定义

#### 3.1.2 getInstance() 方法

**功能**: 获取CertInfo单例实例

**修饰符**: `public static synchronized`

**执行流程**:
```
1. 检查instance是否为null
2. 如果为null，进入synchronized(CertInfo.class)同步块
   a. 再次检查instance是否为null（双重检查锁定）
   b. 如果仍为null，创建新的CertInfo实例
3. 返回instance
```

**完整代码**:
```java
public static synchronized CertInfo getInstance() {
    if (instance == null) {
        synchronized (CertInfo.class) {
            if (instance == null) {
                instance = new CertInfo();
            }
        }
    }
    return instance;
}
```

#### 3.1.10 私有方法 loadEncryptedPrivateKey(String pemFile, char[] password)

**功能**: 加载并解密PEM格式的私钥

**修饰符**: `private static`

**抛出异常**: `IOException`

**执行流程**:
```
1. 注册BouncyCastle安全提供者: Security.addProvider(new BouncyCastleProvider())
2. 创建StringReader包装PEM字符串
3. 创建PEMParser解析PEM内容
4. 读取PEM对象: parser.readObject()
5. 创建JcaPEMKeyConverter，设置provider为"BC"
6. 根据PEM对象类型处理:
   a. 如果是PEMEncryptedKeyPair（加密私钥）:
      - 检查密码是否为空，为空则抛出IllegalArgumentException
      - 使用JcePEMDecryptorProviderBuilder构建解密器
      - 调用encryptedKeyPair.decryptKeyPair(decProv)解密
   b. 如果是PEMKeyPair（非加密私钥）:
      - 直接使用
   c. 其他类型:
      - 抛出IllegalArgumentException("Unsupported PEM object: " + obj)
7. 通过converter.getKeyPair(keyPair).getPrivate()获取PrivateKey对象
8. 返回PrivateKey
```

**完整代码**:
```java
private static PrivateKey loadEncryptedPrivateKey(String pemFile, char[] paasword) throws IOException {
    Security.addProvider(new BouncyCastleProvider());
    try (
            Reader reader = new StringReader(pemFile);
            PEMParser parser = new PEMParser(reader)) {
        Object obj = parser.readObject();
        JcaPEMKeyConverter converter = new JcaPEMKeyConverter().setProvider("BC");
        PEMKeyPair keyPair;
        if (obj instanceof PEMEncryptedKeyPair) {
            PEMEncryptedKeyPair encryptedKeyPair = (PEMEncryptedKeyPair) obj;
            if (paasword == null || paasword.length == 0) {
                throw new IllegalArgumentException("need paasword to encrypt the privateKey");
            }
            PEMDecryptorProvider decProv = new JcePEMDecryptorProviderBuilder().build(paasword);
            keyPair = encryptedKeyPair.decryptKeyPair(decProv);
        } else if (obj instanceof PEMKeyPair) {
            keyPair = (PEMKeyPair) obj;
        } else {
            throw new IllegalArgumentException("Unsupported PEM object: " + obj);
        }
        return converter.getKeyPair(keyPair).getPrivate();
    }
}
```

#### 3.1.11 私有方法 convertPkcs1ToPkcs8Stream(PrivateKey privateKey)

**功能**: 将PrivateKey对象转换为PKCS#8格式的PEM输入流

**修饰符**: `private static`

**抛出异常**: `IOException`

**执行流程**:
```
1. 从PrivateKey获取PKCS#8编码: PrivateKeyInfo.getInstance(privateKey.getEncoded())
2. 获取DER编码字节: pkInfo.getEncoded()
3. 创建PemObject，标签为"PRIVATE KEY"（PKCS#8标准标签）
4. 使用PemWriter将PemObject写入StringWriter
5. 将结果字符串转换为ByteArrayInputStream返回
```

**完整代码**:
```java
private static InputStream convertPkcs1ToPkcs8Stream(PrivateKey privateKey) throws IOException {
    PrivateKeyInfo pkInfo = PrivateKeyInfo.getInstance(privateKey.getEncoded());
    byte[] der = pkInfo.getEncoded();
    PemObject pemObject = new PemObject("PRIVATE KEY", der); // PKCS#8 标签
    StringWriter sw = new StringWriter();
    try (PemWriter pemWriter = new PemWriter(sw)) {
        pemWriter.writeObject(pemObject);
    }
    return new ByteArrayInputStream(sw.toString().getBytes());
}
```

### 3.2 SubscribeCert 证书订阅组件

**包路径**: `com.huawei.browsergateway.tcpserver.cert.SubscribeCert`

**Spring注解**: `@Component`

**说明**: 此组件在应用启动时通过`@PostConstruct`自动执行证书订阅。通过反射调用CSP SDK完成证书订阅，不直接依赖CSP SDK的编译时类。

#### 3.2.1 字段定义

| 字段名 | 类型 | 注入方式 | 说明 |
|--------|------|---------|------|
| log | Logger | static final | Log4j2日志记录器 |
| exCertHandler | ExCertInfo | @Autowired | 扩展证书处理器（作为IExCertHandler传递给CSP SDK） |

#### 3.2.2 SubscribeCertInfo() 方法（@PostConstruct）

**功能**: 应用启动时自动订阅CSP SDK证书

**触发时机**: Spring容器初始化完成后（`@PostConstruct`）

**执行流程**:
```
1. 打印info日志 "start subscribe sbg certificate scene"
2. 通过反射初始化CSP SDK:
   a. 加载类: Class.forName("com.huawei.csp.certsdk.certapiImpl.CertMgrApiImpl")
   b. 获取CertMgrApi实例: getCertMgrApi()
   c. 初始化SDK: certSDKInit()
3. 通过反射创建证书订阅实体列表:
   a. 加载类: Class.forName("com.huawei.csp.certsdk.pojo.SubscribeEntity")
   b. 加载枚举类: Class.forName("com.huawei.csp.certsdk.enums.SceneType")
   c. 创建CA证书实体:
      - sceneName = "sbg_server_ca_certificate"
      - sceneDescCN = "云浏览器服务端CA证书"
      - sceneDescEN = "SBG server CA certificate"
      - sceneType = SceneType.CA
      - feature = 0
   d. 创建设备证书实体:
      - sceneName = "sbg_server_device_certificate"
      - sceneDescCN = "云浏览器服务端设备证书"
      - sceneDescEN = "SBG server Device Certificate"
      - sceneType = SceneType.DEVICE
      - feature = 0
4. 通过反射执行证书订阅:
   a. 加载类: Class.forName("com.huawei.csp.certsdk.certapiImpl.ExCertMgrApiImpl")
   b. 获取ExCertMgrApi实例: getExCertMgrApi()
   c. 调用subscribeExCert方法:
      - serviceName = "browsergw"
      - certList = [caEntity, certEntity]
      - handler = exCertHandler (ExCertInfo实例)
      - certPath = "/opt/csp/browsergw"
5. 检查订阅结果:
   - 如果isSubscriptionSuccessful为null或false:
     打印error日志 "subscribe sbg certificate scene failed"
     返回
   - 否则打印info日志 "subscribe sbg certificate scene successful"
```

**异常处理**: catch所有Exception，打印error日志 "Failed to subscribe certificates"

**CSP SDK反射调用链**:
```
CertMgrApiImpl.getCertMgrApi() → certMgrApi.certSDKInit()
ExCertMgrApiImpl.getExCertMgrApi() → exCertMgr.subscribeExCert(
    serviceName: "browsergw",
    certList: ArrayList<SubscribeEntity>,
    handler: ExCertInfo (implements IExCertHandler),
    certPath: "/opt/csp/browsergw"
)
```

**完整代码**:
```java
@PostConstruct
public void SubscribeCertInfo() {
    log.info("start subscribe sbg certificate scene");
    try {
        // 使用反射访问 CSP SDK 类
        Class<?> certMgrApiImplClass = Class.forName("com.huawei.csp.certsdk.certapiImpl.CertMgrApiImpl");
        Method getCertMgrApi = certMgrApiImplClass.getMethod("getCertMgrApi");
        Object certMgrApi = getCertMgrApi.invoke(null);
        Method certSDKInit = certMgrApi.getClass().getMethod("certSDKInit");
        certSDKInit.invoke(certMgrApi);
        
        Class<?> subscribeEntityClass = Class.forName("com.huawei.csp.certsdk.pojo.SubscribeEntity");
        Class<?> sceneTypeClass = Class.forName("com.huawei.csp.certsdk.enums.SceneType");
        
        ArrayList<Object> certList = new ArrayList<>();
        
        // 创建 CA 证书实体
        Object caEntity = subscribeEntityClass.newInstance();
        Method setSceneName = subscribeEntityClass.getMethod("setSceneName", String.class);
        Method setSceneDescCN = subscribeEntityClass.getMethod("setSceneDescCN", String.class);
        Method setSceneDescEN = subscribeEntityClass.getMethod("setSceneDescEN", String.class);
        Method setSceneType = subscribeEntityClass.getMethod("setSceneType", sceneTypeClass);
        Method setFeature = subscribeEntityClass.getMethod("setFeature", int.class);
        
        setSceneName.invoke(caEntity, "sbg_server_ca_certificate");
        setSceneDescCN.invoke(caEntity, "云浏览器服务端CA证书");
        setSceneDescEN.invoke(caEntity, "SBG server CA certificate");
        Object caSceneType = Enum.valueOf((Class<Enum>) sceneTypeClass, "CA");
        setSceneType.invoke(caEntity, caSceneType);
        setFeature.invoke(caEntity, 0);
        certList.add(caEntity);
        
        // 创建设备证书实体
        Object certEntity = subscribeEntityClass.newInstance();
        setSceneName.invoke(certEntity, "sbg_server_device_certificate");
        setSceneDescCN.invoke(certEntity, "云浏览器服务端设备证书");
        setSceneDescEN.invoke(certEntity, "SBG server Device Certificate");
        Object deviceSceneType = Enum.valueOf((Class<Enum>) sceneTypeClass, "DEVICE");
        setSceneType.invoke(certEntity, deviceSceneType);
        setFeature.invoke(certEntity, 0);
        certList.add(certEntity);
        
        // 订阅证书
        Class<?> exCertMgrApiImplClass = Class.forName("com.huawei.csp.certsdk.certapiImpl.ExCertMgrApiImpl");
        Method getExCertMgrApi = exCertMgrApiImplClass.getMethod("getExCertMgrApi");
        Object exCertMgr = getExCertMgrApi.invoke(null);
        Method subscribeExCert = exCertMgr.getClass().getMethod("subscribeExCert", 
                String.class, List.class, 
                Class.forName("com.huawei.csp.certsdk.handler.IExCertHandler"), 
                String.class);
        Boolean isSubscriptionSuccessful = (Boolean) subscribeExCert.invoke(exCertMgr, 
                "browsergw", certList, exCertHandler, "/opt/csp/browsergw");
        
        if (isSubscriptionSuccessful == null || !isSubscriptionSuccessful) {
            log.error("subscribe sbg certificate scene failed");
            return;
        }
        log.info("subscribe sbg certificate scene successful");
    } catch (Exception e) {
        log.error("Failed to subscribe certificates", e);
    }
}
```

### 3.7 AbstractTcpServer 中的TLS上下文构建（消费方）

**包路径**: `com.huawei.browsergateway.tcpserver.AbstractTcpServer`

**说明**: AbstractTcpServer是证书管理模块的主要消费方，在TCP服务器启动时使用CertInfo提供的证书构建Netty SslContext。

#### 3.7.1 start(boolean isTLS) 方法中的证书使用

**执行流程**:
```
1. 获取CertInfo单例: CertInfo certInstance = CertInfo.getInstance()
2. 判断证书就绪且需要TLS: certInstance.isCertReady() && isTLS
3. 如果条件满足:
   a. 获取CA证书流: InputStream caInfo = certInstance.Ca()
   b. 获取设备证书流: InputStream certInfo = certInstance.Device()
   c. 获取私钥流(PKCS#8): InputStream keyInfo = certInstance.Key()
   d. 构建SslContext:
      SslContextBuilder.forServer(certInfo, keyInfo)
          .ciphers(Arrays.asList(
              "TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256",
              "TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384",
              "TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256",
              "TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384"
          ))
          .protocols("TLSv1.2", "TLSv1.3")
          .trustManager(caInfo)
          .build()
4. 如果条件不满足:
   - sslCtx = null（启动非TLS的TCP服务器）
5. 在ChannelInitializer中:
   - 如果certInstance.isCertReady() && isTLS:
     ch.pipeline().addLast(sslCtx.newHandler(ch.alloc()))
```

**TLS配置参数**:

| 参数 | 值 | 说明 |
|------|-----|------|
| 密码套件 | TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256 | ECDHE+RSA+AES128+GCM |
| 密码套件 | TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384 | ECDHE+RSA+AES256+GCM |
| 密码套件 | TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256 | ECDHE+ECDSA+AES128+GCM |
| 密码套件 | TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384 | ECDHE+ECDSA+AES256+GCM |
| 协议版本 | TLSv1.2, TLSv1.3 | 支持TLS 1.2和1.3 |
| 信任管理器 | CA证书 | 使用CA证书验证客户端 |

## 6. 关键流程

### 6.1 CSP模式 - 应用启动证书订阅流程

```
应用启动 (Spring容器初始化)
  → SubscribeCert.SubscribeCertInfo() [@PostConstruct]
    → 反射调用 CertMgrApiImpl.getCertMgrApi()
    → 反射调用 certMgrApi.certSDKInit()
    → 创建SubscribeEntity列表:
      - CA证书实体 (SceneType.CA)
      - 设备证书实体 (SceneType.DEVICE)
    → 反射调用 ExCertMgrApiImpl.getExCertMgrApi()
    → 反射调用 exCertMgr.subscribeExCert("browsergw", certList, exCertHandler, "/opt/csp/browsergw")
    → CSP SDK异步回调 ExCertInfo.exCertHandler()
      → CertInfo.SetCaContent(caContent) [由CSP SDK内部触发]
      → CertInfo.SetDeviceContent(deviceContent, keyContent, keypwd) [由CSP SDK内部触发]
```

### 6.2 CSP模式 - 证书更新热重启流程

```
CSP SDK检测到证书更新
  → 回调 ExCertInfo.exCertHandler(exCertEntityList, certNotifyType)
    → 处理证书列表（更新CertInfo中的证书内容）
    → 停止媒体TLS服务器: mediaServer.stopServer()
      → AbstractTcpServer.stop()
        → channelFuture.channel().close().sync()
        → workerGroup.shutdownGracefully()
        → bossGroup.shutdownGracefully()
    → 停止控制TLS服务器: controlServer.stopServer()
    → 启动媒体TLS服务器: mediaServer.startServer()
      → AbstractTcpServer.start(true)
        → CertInfo.getInstance()
        → certInstance.isCertReady() → true
        → certInstance.Ca() / Device() / Key()
        → SslContextBuilder.forServer(certInfo, keyInfo)
            .ciphers([4种密码套件])
            .protocols("TLSv1.2", "TLSv1.3")
            .trustManager(caInfo)
            .build()
        → bootstrap.bind(address, port)
    → 启动控制TLS服务器: controlServer.startServer()
```

### 6.3 Custom模式 - 本地证书加载流程

```
应用启动 (Spring容器初始化)
  → CustomCertificateAdapter.initializeCustomCertificates() [@PostConstruct]
    → loadCertificatesFromFile()
      → 检查caCertPath配置
        → Files.exists(caPath) && Files.isReadable(caPath)
        → caContent = new String(Files.readAllBytes(caPath))
      → 检查deviceCertPath配置
        → Files.exists(devicePath) && Files.isReadable(devicePath)
        → deviceContent = new String(Files.readAllBytes(devicePath))
      → 检查privateKeyPath配置
        → Files.exists(keyPath) && Files.isReadable(keyPath)
        → privateKey = new String(Files.readAllBytes(keyPath))
      → 返回isCertificateReady()
```

### 6.4 TLS TCP服务器启动时的证书消费流程

```
ControlTcpServer.startServer() [@PostConstruct]
  → AbstractTcpServer.start(true)  // isTLS=true
    → CertInfo certInstance = CertInfo.getInstance()
    → 判断: certInstance.isCertReady() && isTLS
    → [证书就绪]:
      → InputStream caInfo = certInstance.Ca()        // CA证书流
      → InputStream certInfo = certInstance.Device()   // 设备证书流
      → InputStream keyInfo = certInstance.Key()       // PKCS#8私钥流
        → loadEncryptedPrivateKey(keyContent, keypwd)  // 解密私钥
          → PEMParser解析PEM
          → 判断加密/非加密格式
          → JcaPEMKeyConverter转换
        → convertPkcs1ToPkcs8Stream(privateKey)        // 转换为PKCS#8
          → PrivateKeyInfo.getInstance(privateKey.getEncoded())
          → PemWriter写出"PRIVATE KEY"标签
      → SslContextBuilder.forServer(certInfo, keyInfo)
          .ciphers([密码套件列表])
          .protocols("TLSv1.2", "TLSv1.3")
          .trustManager(caInfo)
          .build()
      → Netty Pipeline添加SSL Handler
    → [证书未就绪]:
      → sslCtx = null
      → 启动非TLS的TCP服务器
```

### 6.5 私钥格式转换流程

```
CertInfo.Key()
  → loadEncryptedPrivateKey(keyContent, keypwd.toCharArray())
    → Security.addProvider(new BouncyCastleProvider())
    → PEMParser.readObject()
    → [PEMEncryptedKeyPair]: 加密的PKCS#1私钥
      → JcePEMDecryptorProviderBuilder.build(password)
      → encryptedKeyPair.decryptKeyPair(decProv)
      → converter.getKeyPair(keyPair).getPrivate()
    → [PEMKeyPair]: 非加密的PKCS#1私钥
      → converter.getKeyPair(keyPair).getPrivate()
    → [其他]: 抛出IllegalArgumentException
  → convertPkcs1ToPkcs8Stream(privateKey)
    → PrivateKeyInfo.getInstance(privateKey.getEncoded())
    → pkInfo.getEncoded() → DER字节
    → new PemObject("PRIVATE KEY", der)  // PKCS#8标签
    → PemWriter → StringWriter → ByteArrayInputStream
```

## 7. AdapterBeanConfiguration 中的证书适配器选择

**包路径**: `com.huawei.browsergateway.config.AdapterBeanConfiguration`

**Spring注解**: `@Configuration`

**证书适配器Bean注册逻辑**:

```java
@Bean
@Primary
public CertificateAdapter certificateAdapter(
        @Autowired(required = false) CspCertificateAdapter cspAdapter,
        @Autowired(required = false) CustomCertificateAdapter customAdapter) {
    if (cspAdapter != null) {
        logger.info("Using CSP SDK CertificateAdapter");
        return cspAdapter;
    } else if (customAdapter != null) {
        logger.info("Using Custom CertificateAdapter");
        return customAdapter;
    } else {
        throw new IllegalStateException("No CertificateAdapter implementation found");
    }
}
```

**选择策略**: 优先使用CSP SDK实现，若不可用则使用Custom实现，两者都不可用时抛出异常。

## 8. 线程安全设计

### 8.1 并发控制

| 组件 | 线程安全机制 | 说明 |
|------|-------------|------|
| CertInfo.instance | 双重检查锁定（DCL） | getInstance()使用synchronized + DCL保证单例安全 |
| CertInfo.SetCaContent() | synchronized方法 | 静态同步方法，确保CA证书写入原子性 |
| CertInfo.SetDeviceContent() | synchronized方法 | 静态同步方法，确保设备证书+私钥+密码写入原子性 |
| CertInfo.caContent/deviceContent/keyContent/keypwd | static字段 | 通过synchronized方法保护读写 |
| CspCertificateAdapter.callbacks | CopyOnWriteArrayList | 线程安全的回调列表 |
| CustomCertificateAdapter.callbacks | CopyOnWriteArrayList | 线程安全的回调列表 |

### 8.2 证书更新一致性

证书更新时通过以下机制保证一致性：
1. `SetCaContent()`和`SetDeviceContent()`都是`synchronized`方法，防止并发写入
2. `ExCertInfo.exCertHandler()`先停止所有TLS服务器，再启动，确保使用最新证书
3. `AbstractTcpServer.start()`在启动时从`CertInfo.getInstance()`获取最新证书

## 9. 异常处理

### 9.1 SubscribeCert层

- 所有CSP SDK反射调用使用try-catch包裹
- 异常时打印error日志 "Failed to subscribe certificates"
- 不向上传播异常（避免影响应用启动）

### 9.2 CertInfo层

- `loadEncryptedPrivateKey()`: 密码为空时抛出`IllegalArgumentException`
- `loadEncryptedPrivateKey()`: 不支持的PEM对象类型时抛出`IllegalArgumentException`
- `Key()`: IOException向上传播给调用方（AbstractTcpServer）
- `SetCaContent()`: null参数时静默返回（不抛异常）
- `SetDeviceContent()`: null参数时静默返回（不抛异常）

### 9.3 CustomCertificateAdapter层

- `loadCertificatesFromFile()`: IOException时打印warn日志，返回false（降级处理）
- `initialize()`: 所有异常catch后打印error日志，返回false
- 文件不存在或不可读时打印warn日志（不抛异常）

### 9.4 CspCertificateAdapter层

- `subscribeCertificates()`: 所有异常catch后打印error日志，返回false
- `initialize()`: 所有异常catch后打印error日志，返回false
- `createCertHandler()`: 异常时打印error日志，返回null

### 9.5 AbstractTcpServer层（消费方）

- `start()`: 所有异常catch后打印error日志
- 证书未就绪时自动降级为非TLS模式（sslCtx = null）
