# 定时任务模块 - 模块间接口契约文档

## 1. 概述

本文档定义了定时任务模块(scheduled)与其他模块之间的接口契约,确保模块间的交互规范、明确、无歧义。

## 2. 模块依赖关系

```
定时任务模块 (scheduled)
├── 浏览器管理模块 (service.IChromeSet)
├── 远程服务模块 (service.IRemote)
├── 告警适配器模块 (adapter.AlarmAdapter)
├── 服务管理适配器模块 (adapter.ServiceManagementAdapter)
├── 资源监控适配器模块 (adapter.ResourceMonitorAdapter)
├── 浏览器驱动SDK模块 (sdk.DriverClient)
├── TCP服务器模块 (tcpserver.ClientSet)
└── 配置管理模块 (config.Config)
```

## 3. 接口契约详细定义

### 3.1 浏览器管理接口 (IChromeSet)

#### 3.1.1 接口描述
提供浏览器实例的生命周期管理、状态查询和心跳管理功能。

#### 3.1.2 接口定义
```java
package com.huawei.browsergateway.service;

import com.huawei.browsergateway.service.impl.UserChrome;
import com.huawei.browsergateway.entity.request.InitBrowserRequest;
import java.util.Set;

public interface IChromeSet {
    /**
     * 上报服务使用状态
     * 功能: 将当前实例的浏览器使用情况上报到服务注册中心
     * 调用方: ServiceStatusRefresherTask
     * 调用频率: 30秒/次
     * 异常处理: 接口内部处理异常,不抛出
     */
    void reportUsed();

    /**
     * 上报链路端点信息
     * 功能: 上报当前实例的控制端点、媒体端点等信息
     * 调用方: ServiceReporter
     * 调用时机: 应用启动时,支持重试
     * 返回值:
     *   - true: 上报成功
     *   - false: 上报失败,需要重试
     */
    boolean reportChainEndpoints();

    /**
     * 创建浏览器实例
     * @param request 浏览器创建请求参数
     * @return 创建的浏览器实例
     * @throws RuntimeException 创建失败时抛出
     */
    UserChrome create(InitBrowserRequest request);

    /**
     * 获取指定用户的浏览器实例
     * @param userId 用户ID
     * @return 浏览器实例,不存在时返回null
     */
    UserChrome get(String userId);

    /**
     * 删除指定用户的浏览器实例
     * 功能: 关闭浏览器进程,释放资源,清理本地状态
     * 调用方: BrowserCheckTask, BrowserCloserTask
     * @param userId 用户ID
     * 异常处理: 接口内部处理异常,不抛出
     */
    void delete(String userId);

    /**
     * 删除并重启浏览器实例
     * @param userId 用户ID
     */
    void deleteForRestart(String userId);

    /**
     * 获取所有用户ID集合
     * @return 用户ID集合,线程安全
     */
    Set<String> getAllUser();

    /**
     * 删除所有浏览器实例
     * 功能: 用于应用关闭时的资源清理
     */
    void deleteAll();

    /**
     * 更新用户心跳时间
     * @param userId 用户ID
     * @param heartbeats 心跳时间戳(纳秒)
     */
    void updateHeartbeats(String userId, long heartbeats);

    /**
     * 获取用户心跳时间
     * @param userId 用户ID
     * @return 心跳时间戳(纳秒),用户不存在时返回0
     */
    long getHeartbeats(String userId);
}
```

#### 3.1.3 数据结构
```java
// UserChrome - 用户浏览器实例
public class UserChrome {
    private String userId;              // 用户ID(唯一标识)
    private ChromeDriver chromeDriver;  // 浏览器驱动
    private long createTime;            // 创建时间(纳秒)
    private long lastAccessTime;        // 最后访问时间(纳秒)
}

// ChromeDriver - 浏览器驱动
public class ChromeDriver {
    private String browserId;           // 浏览器ID
    private String proxyContextId;      // 代理上下文ID(用于健康检查)
    private String endpoint;            // 浏览器驱动服务端点
}
```

#### 3.1.4 线程安全要求
- `getAllUser()` 返回的Set是线程安全的,可以安全遍历
- `delete()` 方法支持并发调用
- `getHeartbeats()` 和 `updateHeartbeats()` 方法支持并发调用

### 3.2 远程服务接口 (IRemote)

#### 3.2.1 接口描述
提供远程服务的调用能力,包括用户绑定信息查询、浏览器创建、事件处理等。

#### 3.2.2 接口定义
```java
package com.huawei.browsergateway.service;

import com.huawei.browsergateway.entity.event.EventInfo;
import com.huawei.browsergateway.entity.request.InitBrowserRequest;
import com.huawei.browsergateway.service.impl.UserBind;
import java.util.function.Consumer;

public interface IRemote {
    /**
     * 获取用户绑定信息
     * 功能: 从远程存储获取用户与浏览器实例的绑定关系
     * 调用方: BrowserCloserTask
     * @param sessionID 会话ID
     * @return UserBind对象,不存在或获取失败时返回null
     * 异常处理: 接口内部处理所有异常,不抛出
     */
    UserBind getUserBind(String sessionID);

    /**
     * 过期用户绑定
     * @param sessionID 会话ID
     */
    void expiredUserBind(String sessionID);

    /**
     * 创建浏览器
     * @param receivedControlPackets 控制报文
     * @param parsedParams 解析后的参数
     * @param consumer 结果消费者
     */
    void createChrome(byte[] receivedControlPackets,
                      InitBrowserRequest parsedParams,
                      Consumer<Object> consumer);

    /**
     * 容错处理
     * @param sessionID 会话ID
     */
    void fallback(String sessionID);

    /**
     * 错误容错处理
     * @param sessionId 会话ID
     */
    void fallbackByError(String sessionId);

    /**
     * 处理事件
     * @param receivedControlPackets 控制报文
     * @param userId 用户ID
     */
    void handleEvent(byte[] receivedControlPackets, String userId);

    /**
     * 更新用户绑定
     * @param key 键
     * @return 更新后的UserBind
     */
    UserBind updateUserBind(String key);

    /**
     * 发送媒体流量数据
     * @param dataJson 数据JSON
     */
    void sendTrafficMedia(String dataJson);

    /**
     * 发送控制流量数据
     * @param dataJson 数据JSON
     */
    void sendTrafficControl(String dataJson);

    /**
     * 发送会话数据
     * @param dataJson 数据JSON
     */
    void sendSession(String dataJson);

    /**
     * 上报事件
     * @param event 事件信息
     * @param <T> 事件数据类型
     */
    <T> void reportEvent(EventInfo<T> event);
}
```

#### 3.2.3 数据结构
```java
// UserBind - 用户绑定信息
public class UserBind {
    private String sessionID;           // 会话ID(唯一标识)
    private String browserInstance;     // 浏览器实例地址(IP:Port)
    private Long heartbeats;            // 心跳时间戳(纳秒)
    private String userId;              // 用户ID
    private String status;              // 状态
}
```

#### 3.2.4 线程安全要求
- `getUserBind()` 方法支持并发调用
- 返回的UserBind对象不可变,线程安全

### 3.3 告警适配器接口 (AlarmAdapter)

#### 3.3.1 接口描述
提供告警发送、清除和查询功能。

#### 3.3.2 接口定义
```java
package com.huawei.browsergateway.adapter;

import com.huawei.browsergateway.adapter.dto.AlarmInfo;
import com.huawei.browsergateway.adapter.dto.AlarmRequest;
import java.util.List;
import java.util.Map;

public interface AlarmAdapter {
    /**
     * 发送告警
     * 功能: 向告警系统发送告警信息
     * 调用方: HealthCheckTask
     * 调用频率: 1分钟/次
     * @param alarmId 告警ID(如: "ALARM_300032")
     * @param type 告警类型(GENERATE-产生告警, CLEAR-清除告警)
     * @param parameters 告警参数键值对
     * @return true-发送成功, false-发送失败
     * 异常处理: 接口内部处理异常,不抛出
     * 重试机制: 接口内部实现重试,最多重试2次
     * 去重机制: 同一告警10分钟内只发送一次
     */
    boolean sendAlarm(String alarmId, AlarmType type, Map<String, String> parameters);

    /**
     * 清除告警
     * @param alarmId 告警ID
     * @return true-清除成功, false-清除失败
     */
    boolean clearAlarm(String alarmId);

    /**
     * 批量发送告警(支持重试)
     * @param alarms 告警列表
     * @param maxRetry 最大重试次数
     * @return 成功发送的告警数量
     */
    int sendAlarmsBatch(List<AlarmRequest> alarms, int maxRetry);

    /**
     * 查询历史告警
     * @param alarmIds 告警ID列表
     * @return 历史告警信息列表
     */
    List<AlarmInfo> queryHistoricalAlarms(List<String> alarmIds);

    /**
     * 告警类型枚举
     */
    enum AlarmType {
        GENERATE,  // 产生告警
        CLEAR      // 清除告警
    }
}
```

#### 3.3.3 数据结构
```java
// AlarmRequest - 告警请求
public class AlarmRequest {
    private String alarmId;                      // 告警ID
    private AlarmType type;                      // 告警类型
    private Map<String, String> parameters;      // 告警参数
}

// AlarmInfo - 告警信息
public class AlarmInfo {
    private String alarmId;                      // 告警ID
    private String alarmName;                    // 告警名称
    private long timestamp;                      // 告警时间戳
    private String status;                       // 告警状态
}
```

#### 3.3.4 告警ID规范
| 告警ID | 告警名称 | 触发条件 |
|--------|---------|---------|
| ALARM_300032 | 亚健康检查 | CPU/内存/网络任一指标不健康 |

### 3.4 服务管理适配器接口 (ServiceManagementAdapter)

#### 3.4.1 接口描述
提供服务注册、发现和实例属性上报功能。

#### 3.4.2 接口定义
```java
package com.huawei.browsergateway.adapter;

import com.huawei.browsergateway.adapter.dto.ServiceInstance;
import java.util.List;
import java.util.Map;

public interface ServiceManagementAdapter {
    /**
     * 上报服务实例属性
     * 功能: 将实例属性上报到服务注册中心
     * 调用方: HealthCheckTask
     * 调用频率: 1分钟/次
     * @param properties 属性键值对
     * @return true-上报成功, false-上报失败
     * 异常处理: 接口内部处理异常,不抛出
     */
    boolean reportInstanceProperties(Map<String, String> properties);

    /**
     * 获取服务实例属性
     * @param key 属性键
     * @return 属性值,不存在或获取失败时返回null
     */
    String getInstanceProperty(String key);

    /**
     * 查找服务实例
     * @param serviceName 服务名称
     * @return 服务实例列表,失败时返回空列表
     */
    List<ServiceInstance> findServiceInstances(String serviceName);

    /**
     * 获取当前服务实例信息
     * @return 当前服务实例,失败时返回null
     */
    ServiceInstance getCurrentInstance();

    /**
     * 注册REST服务
     * @param schemaId Schema ID
     * @param serviceInstance 服务实例
     * @return true-注册成功, false-注册失败
     */
    boolean registerRestService(String schemaId, Object serviceInstance);
}
```

#### 3.4.3 数据结构

### 3.6 浏览器驱动SDK接口 (DriverClient)

#### 3.6.1 接口描述
提供浏览器驱动服务的远程调用能力。

#### 3.6.2 接口定义
```java
package com.huawei.browsergateway.sdk;

import java.util.List;

public interface DriverClient {
    /**
     * 获取浏览器操作接口
     * @return Browser接口实例
     */
    Browser browser();

    /**
     * 获取上下文操作接口
     * @param browserId 浏览器ID
     * @return Context接口实例
     */
    Context context(String browserId);

    /**
     * 浏览器操作接口
     */
    interface Browser {
        /**
         * 创建浏览器
         * @param req 创建请求
         * @return 创建的浏览器信息
         */
        Browser create(Request.CreateBrowser req);

        /**
         * 获取浏览器信息
         * @param id 浏览器ID
         * @return 浏览器信息
         */
        Browser get(String id);

        /**
         * 列出所有浏览器
         * @return 浏览器列表
         */
        List<Browser> list();

        /**
         * 删除浏览器
         * @param id 浏览器ID
         */
        void delete(String id);

        /**
         * 健康检查
         * 功能: 检查所有浏览器上下文的健康状态
         * 调用方: BrowserCheckTask
         * 调用频率: 30分钟/次
         * @return 健康检查结果
         * 异常处理: 失败时返回success=false的对象
         */
        HealthCheckResult healthCheck();
    }

    /**
     * 上下文操作接口
     */
    interface Context {
        /**
         * 创建上下文
         * @param req 创建请求
         * @return 创建的上下文信息
         */
        Context create(Request.CreateContext req);

        /**
         * 获取上下文信息
         * @param id 上下文ID
         * @return 上下文信息
         */
        Context get(String id);

        /**
         * 列出所有上下文
         * @return 上下文列表
         */
        List<Context> list();

        /**
         * 删除上下文
         * @param id 上下文ID
         */
        void delete(String id);

        /**
         * 保存用户数据
         * @param id 上下文ID
         */
        void saveUserdata(String id);

        /**
         * 获取页面操作接口
         * @param contextId 上下文ID
         * @return Page接口实例
         */
        Page page(String contextId);
    }

    /**
     * 页面操作接口
     */
    interface Page {
        /**
         * 删除页面
         * @param id 页面ID
         * @return 上下文信息
         */
        Context delete(String id);

        /**
         * 创建页面
         * @param url URL地址
         * @return 上下文信息
         */
        Context create(String url);

        /**
         * 执行JavaScript
         * @param expression JS表达式
         * @return 执行结果
         */
        Request.JSResult execute(String expression);

        /**
         * 执行CDP命令
         * @param method CDP方法名
         * @param params CDP参数
         * @return 执行结果
         */
        Map<String, Object> executeCdp(String method, Map<String, Object> params);

        /**
         * 跳转到URL
         * @param url URL地址
         * @return 上下文信息
         */
        Context gotoUrl(String url);

        /**
         * 执行元素操作
         * @param action 操作动作
         */
        void executeElement(Request.Action action);

        /**
         * 后退
         */
        void goBack();

        /**
         * 前进
         */
        void goForward();

        /**
         * 查找元素
         * @param selector 选择器
         * @return 查找结果
         */
        Request.JSResult findElement(String selector);

        /**
         * 获取元素大小
         * @param elementId 元素ID
         * @return 元素大小
         */
        Type.Size getElementSize(String elementId);
    }
}
```

- `allClient()` 返回的Set是线程安全的,可以安全遍历
- `get()` 和 `del()` 方法支持并发调用
- `Client.getTime()` 方法支持并发调用

## 5. 异常处理规范

### 5.1 接口层异常处理
所有接口实现必须遵循以下异常处理规范:
1. 不向调用方抛出受检异常
2. 在接口内部捕获所有异常
3. 记录错误日志
4. 返回合理的默认值或失败状态

### 5.2 定时任务层异常处理
定时任务必须遵循以下异常处理规范:
1. 任务执行方法包含在try-catch块中
2. 异常时记录错误日志,包含堆栈信息
3. 异常不影响定时任务的继续执行
4. 对于子任务级操作(如遍历用户列表),单个异常不影响其他子任务

### 5.3 重试机制
以下接口需要实现重试机制:
- `IChromeSet.reportChainEndpoints()`: 最大重试5次,间隔30秒
- `AlarmAdapter.sendAlarm()`: 最大重试2次,间隔5秒

## 7. 日志规范

### 7.1 日志级别使用
- **INFO**: 任务开始、结束、关键操作
- **WARN**: 接口调用失败、资源不足
- **ERROR**: 接口调用异常、严重错误

### 7.2 日志格式
```java
// 接口调用成功
log.info("[接口名] 操作成功, 参数: {}", params);

// 接口调用失败
log.warn("[接口名] 操作失败, 参数: {}, 原因: {}", params, reason);

// 接口调用异常
log.error("[接口名] 操作异常, 参数: {}", params, exception);
```
