ws.onclose = function(event) {
  console.log('WebSocket连接已关闭');
};

// 连接错误
ws.onerror = function(error) {
  console.error('WebSocket错误:', error);
};

## 8. 错误码说明

### 8.1 HTTP 状态码

| 状态码 | 说明 | 处理建议 |
|--------|------|---------|
| 200 | 成功 | - |
| 400 | 请求参数错误 | 检查请求参数格式 |
| 401 | 未授权 | 检查认证信息 |
| 403 | 禁止访问 | 检查权限 |
| 404 | 资源不存在 | 检查资源路径 |
| 500 | 服务器内部错误 | 联系管理员 |
| 503 | 服务不可用 | 稍后重试 |
