# BrowserGateway 插件管理模块设计说明书

## 1. 概述

### 1.1 模块定位
插件管理模块是BrowserGateway系统的核心业务模块，负责Moon Cloud Browser SDK插件（JAR包）和Chrome扩展插件（JS扩展）的加载、管理和生命周期维护。模块通过`IPluginManage`接口对外提供服务，由`PluginManageImpl`实现，通过`ExtensionManageApi`对外暴露REST API。

### 1.2 设计目标
- **插件加载**：从S3下载插件包，解压并加载JAR包和JS扩展
- **动态类加载**：使用URLClassLoader动态加载Moon SDK驱动类
- **驱动实例创建**：为每个用户创建独立的MuenDriver实例
- **状态管理**：维护插件加载状态（NotStart/Completed/Failed）
- **告警上报**：插件加载失败时上报告警到CSE
- **自动初始化**：服务启动时自动从CSE获取并加载插件

### 2.4 数据存储

插件管理模块使用内存级对象存储插件状态和类加载器：

- **pluginActive**: `PluginActive`对象（存储插件名称、版本、类型、状态）
- **muenPluginClassLoader**: `MuenPluginClassLoader`对象（存储Moon SDK类加载器实例）

插件文件存储路径（基于`browsergw.workspace`配置）：

- **JAR包目录**: `{workspace}/jar/`
- **按键扩展目录**: `{workspace}/extension/keys/`
- **触屏扩展目录**: `{workspace}/extension/touch/`
- **临时文件目录**: `{workspace}/tmp/`

### 3.1 IPluginManage 接口定义

**包路径**: `com.huawei.browsergateway.service.IPluginManage`

```java
public interface IPluginManage {
    // 获取插件激活状态
    PluginActive getPluginActive();

    // 更新插件激活信息（名称、版本、类型）
    void updatePluginActive(String name, String version, String type);

    // 加载插件（JAR包和JS扩展）
    void loadPlugin(String keyPath, String touchPath, String jarPath);

    // 更新插件状态
    void updateStatus(String pluginStatus);

    // 获取插件状态
    String getPluginStatus();

    // 为用户创建MuenDriver实例
    MuenDriver createDriver(String userId);
}
```

#### 3.2.2 @PostConstruct initPluginActive() 方法

**功能**: 初始化插件激活状态

**执行流程**:
```
1. 创建新的PluginActive对象
2. 设置status = Constant.NOTSTART（"NotStart"）
3. 设置type = "ChromeExtend"
```

#### 3.2.3 getPluginActive() 方法

**功能**: 获取插件激活状态对象

**返回值**: `PluginActive`对象

**执行流程**:
```
1. 直接返回pluginActive字段
```

#### 3.2.4 updatePluginActive(String name, String version, String type) 方法

**功能**: 更新插件激活信息

**执行流程**:
```
1. 设置pluginActive.setName(name)
2. 设置pluginActive.setVersion(version)
3. 设置pluginActive.setType(type)
```

#### 3.2.5 loadPlugin(String keyPath, String touchPath, String jarPath) 方法

**功能**: 加载插件（JAR包和JS扩展）

**执行流程**:
```
1. 调用loadSDK(jarPath)加载JAR包
2. 调用loadJSExtension(keyPath, touchPath)加载JS扩展
3. 如果两者都成功：
   - 调用updateStatus(Constant.COMPLETE)
4. 否则：
   - 调用updateStatus(Constant.FAILED)
```

#### 3.2.6 updateStatus(String pluginStatus) 方法

**功能**: 更新插件状态并上报告警

**执行流程**:
```
1. 如果pluginStatus等于Constant.COMPLETE（"Completed"）：
   - 调用alarm.clearAlarm(AlarmEnum.ALARM_300030.getAlarmId())清除告警
2. 否则：
   - 调用alarm.sendAlarm(new AlarmEvent(AlarmEnum.ALARM_300030, "ERROR:Failed to create plugin"))发送告警
3. 设置pluginActive.setStatus(pluginStatus)
```

#### 3.2.7 getPluginStatus() 方法

**功能**: 获取插件状态

**返回值**: 插件状态字符串（"NotStart"/"Completed"/"Failed"）

**执行流程**:
```
1. 返回pluginActive.getStatus()
```

#### 3.2.8 createDriver(String userId) 方法

**功能**: 为用户创建MuenDriver实例

**返回值**: `MuenDriver`对象，如果类加载器未初始化则返回null

**执行流程**:
```
1. 如果muenPluginClassLoader为null：
   - 返回null
2. 计算websocketAddr = address + ":" + config.getWebsocket().getMediaPort()
3. 获取localTmp = config.getTmpPath()
4. 创建HWCallbackImpl对象：
   new HWCallbackImpl(cse.getReportEndpoint(), fs, controlClientSet, 
                      muenSessionManager, userId, websocketAddr, localTmp)
5. 调用muenPluginClassLoader.createDriverInstance(hwCallback)
6. 返回MuenDriver实例
```

#### 3.2.9 loadJSExtension(String keyPath, String touchPath) 方法

**功能**: 加载JS扩展（按键和触屏扩展）

**返回值**: `boolean`（总是返回true）

**执行流程**:
```
1. 如果keyPath不为空：
   a. 删除旧扩展：FileUtil.del(config.getKeyExtensionPath())
   b. 复制新扩展：FileUtil.copy(keyPath, FileUtil.getParent(config.getKeyExtensionPath(), 1), true)
2. 如果touchPath不为空：
   a. 删除旧扩展：FileUtil.del(config.getTouchExtensionPath())
   b. 复制新扩展：FileUtil.copy(touchPath, FileUtil.getParent(config.getTouchExtensionPath(), 1), true)
3. 返回true
```

#### 3.2.10 loadSDK(String jarPath) 方法

**功能**: 加载Moon SDK JAR包

**返回值**: `boolean`（成功返回true，失败返回false）

**执行流程**:
```
1. 如果jarPath为空：
   - 返回true（允许不加载JAR包）
2. 如果muenPluginClassLoader不为null：
   - 调用muenPluginClassLoader.close()关闭旧的类加载器
3. 创建JAR目录：FileUtil.mkdir(config.getJarDirPath())
4. 清空JAR目录：FileUtil.clean(config.getJarDirPath())
5. 复制JAR文件：FileUtil.copy(jarPath, config.getJarDirPath(), true)
6. 获取JAR文件名：name = FileUtil.getName(jarPath)
7. 构建完整路径：path = FileUtil.file(config.getJarDirPath(), name).getAbsolutePath()
8. 创建新的MuenPluginClassLoader对象
9. 调用muenPluginClassLoader.init(Paths.get(path))初始化
10. 返回初始化结果
```

#### 3.3.2 loadExtension(LoadExtensionRequest request) 方法

**功能**: 加载或更新浏览器扩展插件（同步方法）

**修饰符**: `synchronized`（确保并发安全）

**返回值**: `boolean`（成功返回true，失败返回false）

**执行流程**:
```
1. 打印info日志"reload extension, request params: {json}"
2. try块：
   a. 调用downPlugin(request)下载插件，返回ExtensionFilePaths对象
   b. 调用pluginManage.updatePluginActive(request.getName(), request.getVersion(), request.getType())
   c. 调用pluginManage.loadPlugin(extensionFilePaths.getKeyDir(), extensionFilePaths.getTouchDir(), extensionFilePaths.jarPath)
   d. 调用postLoadingPlugin(extensionFilePaths)后处理
   e. 打印info日志"success to load extension name:{} version:{}"
   f. 返回true
3. catch块：
   a. 打印error日志"load extension failed"
   b. 调用pluginManage.updateStatus(Constant.FAILED)
   c. 返回false
4. finally块：
   a. 调用chromeSet.reportUsed()上报实例使用量
```

#### 3.3.3 downPlugin(LoadExtensionRequest request) 方法

**功能**: 从S3下载插件包并解压

**返回值**: `ExtensionFilePaths`对象（包含所有文件路径）

**执行流程**:
```
1. 构建远程路径：remoteExtensionPath = Paths.get(request.getBucketName(), request.getExtensionFilePath())
2. 获取本地临时目录：localTmpPath = Paths.get(config.getTmpPath())
3. 创建临时目录：FileUtil.mkdir(localTmpPath)
4. 构建本地文件路径：localExtensionPath = localTmpPath.resolve(remoteExtensionPath.getFileName())
5. 删除旧文件：FileUtil.del(localExtensionPath)
6. 打印info日志"clear local extension path success, start download from remote"
7. 下载文件：fileStorageService.downloadFile(localExtensionPath.toString(), remoteExtensionPath.toString())
8. 打印info日志"download extension success, start decompress"
9. 解压文件：unGzipDir = decompress(localExtensionPath.toString(), config.getTmpPath())
10. 打印info日志"decompress success, start get extension file paths"
11. 获取扩展文件路径：extensionFilePaths = getExtensionFilePaths(unGzipDir, localExtensionPath.toString())
12. 打印info日志"get extension file paths success, start close all chrome instance"
13. 返回extensionFilePaths
```

#### 3.3.4 decompress(String zipFilePath, String unzipDir) 方法

**功能**: 解压插件包（ZIP -> TAR.GZ -> 目录）

**返回值**: 解压后的目录路径

**执行流程**:
```
1. 获取ZIP文件名：zipFileName = FileUtil.getName(zipFilePath)
2. 获取文件名前缀（不含扩展名）：zipFilePrefix = FileUtil.mainName(zipFileName)
3. 构建解压目录：unzipDir = Paths.get(unzipDir, zipFilePrefix).toString()
4. 删除旧目录：FileUtil.del(unzipDir)
5. 创建新目录：FileUtil.mkdir(unzipDir)
6. 解压ZIP文件：ZipUtil.unzip(zipFilePath, unzipDir)
7. 检查package.json是否存在：
   - 路径：packageSdfFilepath = Paths.get(unzipDir, "package.json").toString()
   - 如果不存在：抛出RuntimeException("not found package.json file in {unzipDir}")
8. 打印info日志"extension package.json is {content}"
9. 检查TAR.GZ文件是否存在：
   - 路径：gzipFilePath = Paths.get(unzipDir, zipFilePrefix + ".tar.gz").toString()
   - 如果不存在：抛出RuntimeException("not found {zipFilePrefix}.tar.gz gzip file in {unzipDir}")
10. 构建TAR.GZ解压目录：unGzipDir = Paths.get(unzipDir, zipFilePrefix).toString()
11. 创建解压目录：FileUtil.mkdir(unGzipDir)
12. 解压TAR.GZ文件：GzipUtil.unGzip(gzipFilePath, unGzipDir)
13. 返回unGzipDir
```

#### 3.3.5 getExtensionFilePaths(String unGzipDir, String localExtensionPath) 方法

**功能**: 从解压目录中提取扩展文件路径

**返回值**: `ExtensionFilePaths`对象

**执行流程**:
```
1. 创建ExtensionFilePaths对象：efp = new ExtensionFilePaths()
2. 查找JAR文件路径：jarPath = findJarPath(unGzipDir)
3. 如果jarPath是文件：
   - 设置efp.setJarPath(jarPath)
4. 构建按键扩展目录：keyDir = Paths.get(unGzipDir, "keys").toString()
5. 如果keyDir是目录：
   - 设置efp.setKeyDir(keyDir)
6. 设置efp.setKeyDir(keyDir)（无论是否存在都设置）
7. 构建触屏扩展目录：touchDir = Paths.get(unGzipDir, "touch").toString()
8. 如果touchDir是目录：
```

### 3.4 MuenPluginClassLoader Moon SDK类加载器

**包路径**: `com.huawei.browsergateway.service.MuenPluginClassLoader`

#### 3.4.1 字段定义

| 字段名 | 类型 | 修饰符 | 说明 |
|--------|------|--------|------|
| classLoader | `URLClassLoader` | - | URL类加载器实例 |
| MUENGROUPPREFIX | `String` | static final = "com.moon" | Moon SDK包名前缀 |
| driverImplClass | `Class<?>` | - | 驱动实现类 |

#### 3.4.2 init(Path jarPath) 方法

**功能**: 初始化类加载器并查找驱动实现类

**返回值**: `boolean`（成功返回true，失败返回false）

**执行流程**:
```
1. 打印info日志"load jar from {jarPath}"
2. try块：
   a. 创建URLClassLoader：
      classLoader = new URLClassLoader(new URL[]{jarPath.toUri().toURL()}, 
                                       Thread.currentThread().getContextClassLoader())
3. catch块（MalformedURLException）：
   a. 打印error日志"failed to new urlClassLoader"
   b. 返回false
4. 列出所有类名：classNames = listAllClassName(jarPath)
5. 查找驱动实现类：driverImplClass = findDriverImpl(classNames)
6. 如果driverImplClass为null：
   a. 打印warn日志"cannot find the driver implement class from {jarPath}"
   b. 返回false
7. 返回true
```

#### 3.4.3 createDriverInstance(HWCallback hwCallback) 方法

**功能**: 创建MuenDriver实例

**返回值**: `MuenDriver`对象，如果类或回调为null则返回null

**执行流程**:
```
1. 如果driverImplClass为null或hwCallback为null：
   - 返回null
2. try块：
   a. 通过反射创建实例：
      muenDriver = (MuenDriver) driverImplClass.getConstructor(HWCallback.class).newInstance(hwCallback)
   b. 返回muenDriver
3. catch块（InstantiationException | IllegalAccessException | InvocationTargetException | NoSuchMethodException）：
   a. 打印error日志"failed to instance MuenDriver"
   b. 返回null
```

#### 3.4.4 listAllClassName(Path path) 方法

**功能**: 列出JAR包中所有类名（仅Moon SDK包下的类）

**返回值**: `List<String>`类名列表

**执行流程**:
```
1. 创建结果列表：result = new LinkedList<>()
2. try块（使用JarFile）：
   a. 打开JAR文件：jarFile = new JarFile(path.toFile())
   b. 获取所有条目：entries = jarFile.entries()
   c. 遍历条目：
      - 如果是目录：跳过
      - 如果不是.class文件：跳过
      - 如果是module-info.class：跳过
      - 转换类名：className = name.substring(0, name.length() - 6).replace('/', '.')
      - 添加到结果列表
3. catch块（IOException）：
   a. 打印error日志"failed to list all class names"
   b. 返回空列表
4. 过滤类名：
   a. 只保留以MUENGROUPPREFIX（"com.moon"）开头的类
   b. 过滤掉包含"$"的子类（内部类）
5. 返回过滤后的列表
```

#### 3.4.5 findDriverImpl(List<String> classNames) 方法

**功能**: 查找MuenDriver的实现类

**返回值**: `Class<?>`驱动实现类，如果未找到返回null

**执行流程**:
```
1. 如果classNames为空：
   - 返回null
2. 遍历类名：
   a. try块：
      - 加载类：loadedClass = classLoader.loadClass(clazz)
      - 如果类可实例化且是MuenDriver的子类：
        - 返回loadedClass
   b. catch块（ClassNotFoundException）：
      - 打印error日志"cannot load class of {clazz}"
      - break（跳出循环）
3. 返回null（未找到）
```

#### 3.4.6 isInstantiable(Class<?> clazz) 方法

**功能**: 判断类是否可实例化（静态方法）

**返回值**: `boolean`

**执行流程**:
```
1. 返回：!clazz.isInterface() && 
         !Modifier.isAbstract(clazz.getModifiers()) && 
         !clazz.isEnum() && 
         !clazz.isAnnotation()
```

#### 3.4.7 close() 方法

**功能**: 关闭类加载器

**执行流程**:
```
1. try块：
   a. 调用classLoader.close()
2. catch块（IOException）：
   a. 打印error日志"close classLoader failed."
```

## 7. 关键流程

### 7.1 插件加载完整流程

```
客户端 -> ExtensionManageApi.loadExtension(LoadExtensionRequest)
  -> 参数校验（name/version/bucketName/extensionFilePath）
  -> ExtensionManageService.loadExtension(request)
    -> downPlugin(request)
      -> 从S3下载插件包（ZIP格式）
      -> 解压ZIP文件
      -> 检查package.json
      -> 解压TAR.GZ文件
      -> 提取文件路径（JAR/keys/touch）
    -> pluginManage.updatePluginActive(name, version, type)
    -> pluginManage.loadPlugin(keyDir, touchDir, jarPath)
      -> loadSDK(jarPath)
        -> 关闭旧类加载器（如果存在）
        -> 复制JAR文件到jar目录
        -> MuenPluginClassLoader.init(jarPath)
          -> 创建URLClassLoader
          -> 列出所有类名（过滤com.moon包）
          -> 查找MuenDriver实现类
      -> loadJSExtension(keyPath, touchPath)
        -> 复制按键扩展到extension/keys
        -> 复制触屏扩展到extension/touch
      -> updateStatus(COMPLETE/FAILED)
        -> 上报告警（成功清除，失败发送）
    -> postLoadingPlugin(extensionFilePaths)
      -> 删除临时文件
      -> chromeSet.deleteAll()（关闭所有浏览器）
      -> 删除CDP服务中的所有浏览器实例
    -> chromeSet.reportUsed()（上报实例使用量）
  -> 返回CommonResult.success(response)
```

### 7.2 服务启动自动加载插件流程

```
服务启动 -> InitServer构造函数
  -> startInitializationThread()
    -> 启动后台线程
      -> initializeExtensions()
        -> while循环（直到状态为COMPLETE）：
          -> getLoadExtensionRequest()
            -> 从CSE获取当前插件：GET http://{endpoint}/plugin/v1/current
            -> 构建LoadExtensionRequest
          -> extensionManageService.loadExtension(request)
            -> [执行插件加载流程]
          -> Thread.sleep(5000)（如果失败，等待5秒后重试）
```

### 7.3 创建MuenDriver实例流程

```
ChromeSetImpl.create(request)
  -> pluginManage.createDriver(userId)
    -> 检查muenPluginClassLoader是否为null
    -> 构建websocketAddr = address + ":" + mediaPort
    -> 创建HWCallbackImpl对象
      -> 注入endpoint/fs/controlClientSet/muenSessionManager/userId/websocketAddr/localTmp
    -> muenPluginClassLoader.createDriverInstance(hwCallback)
      -> 通过反射创建MuenDriver实例
        -> driverImplClass.getConstructor(HWCallback.class).newInstance(hwCallback)
    -> 返回MuenDriver实例
```

### 7.4 HWCallback回调流程

```
Moon SDK调用HWCallback方法：
  -> GetConfig()
    -> HTTP GET http://{endpoint}/config/v1
    -> 返回MuenConfig的JSON字符串
  -> Send(muenContext, bytes)
    -> controlClientSet.get(userId)获取客户端
    -> cli.send(bytes)发送到控制通道
  -> Address()
    -> 返回websocketAddr
  -> Log(event)
    -> ReportEventUtil.reportSdkEvent(event, endpoint)
  -> sendMessageToWebscoket(imeiAndImsi, message)
    -> muenSessionManager.getSession(imeiAndImsi)获取会话
    -> session.sendText(message)发送消息
  -> getFile(remoteUrl)
    -> fileStorage.downloadFile(localPath, remoteUrl)
    -> 返回本地File对象
  -> uploadFile(s, file)
    -> fileStorage.uploadFile(filePath, remoteUrl)
    -> 返回远程路径
```

## 8. 线程安全设计

### 8.1 并发控制

| 组件 | 线程安全机制 | 说明 |
|------|-------------|------|
| ExtensionManageService.loadExtension() | synchronized方法 | 确保插件加载操作的原子性 |
| PluginManageImpl.pluginActive | 单例对象 | 通过synchronized方法保护状态更新 |
| MuenPluginClassLoader.classLoader | 实例字段 | 每个实例独立，不共享 |
| InitServer.initializeExtensions() | 后台线程 | 独立线程执行，不阻塞主线程 |

### 8.2 类加载器隔离

- 每次加载新JAR包时，会先关闭旧的`URLClassLoader`
- 新的类加载器实例与旧的完全隔离，避免类冲突

## 9. 异常处理

### 9.1 ExtensionManageApi层

- 所有接口方法使用try-catch包裹
- 异常时返回`CommonResult.error(ResultCode.FAIL)`
- 不向客户端暴露内部异常细节

### 9.2 ExtensionManageService层

- `loadExtension()`: 异常时打印error日志，设置状态为FAILED，返回false
- `downPlugin()`: 抛出IOException，由调用方捕获
- `decompress()`: 文件不存在时抛出RuntimeException
- `findJarPath()`: 异常时抛出RuntimeException

### 9.3 PluginManageImpl层

- `loadSDK()`: 异常时返回false，不抛异常
- `loadJSExtension()`: 总是返回true（文件操作失败不影响）
- `createDriver()`: 类加载器为null时返回null，不抛异常

### 9.4 MuenPluginClassLoader层

- `init()`: 异常时打印error/warn日志，返回false
- `createDriverInstance()`: 异常时打印error日志，返回null
- `listAllClassName()`: 异常时返回空列表

### 9.5 InitServer层

- `initializeExtensions()`: 异常时打印error日志，继续循环重试
- `getLoadExtensionRequest()`: 异常时返回空的LoadExtensionRequest
