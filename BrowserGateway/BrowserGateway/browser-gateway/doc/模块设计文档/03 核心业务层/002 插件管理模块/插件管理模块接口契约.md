# 插件管理模块 - 模块间接口契约文档

## 1. 概述

本文档定义了插件管理模块与其他模块之间的接口契约。插件管理模块是BGW系统的核心模块，负责Moon Cloud Browser SDK插件（JAR包）和Chrome扩展插件（JS扩展）的加载、管理和生命周期维护。对外通过`IPluginManage`接口提供插件管理能力，对外通过`ExtensionManageApi`提供REST API。本文档确保模块间的交互规范、明确、无歧义，依据本文档和设计说明书可100%复现插件管理模块的全部功能代码。

## 2. 模块依赖关系

```
插件管理模块 (service.IPluginManage / api.ExtensionManageApi)
│
├── [对外提供] IPluginManage 接口
│   ├── 调用方: 浏览器管理模块 (service.impl.ChromeSetImpl)
│   │   ├── createDriver(userId) - 创建MuenDriver实例
│   │   └── getPluginStatus() - 获取插件状态（用于上报）
│   ├── 调用方: 扩展管理服务 (service.ExtensionManageService)
│   │   ├── updatePluginActive() - 更新插件信息
│   │   ├── loadPlugin() - 加载插件
│   │   ├── updateStatus() - 更新插件状态
│   │   └── getPluginActive() - 获取插件信息
│   └── 调用方: 服务初始化 (service.InitServer)
│       └── getPluginStatus() - 检查插件加载状态
│
├── [对外提供] ExtensionManageApi REST接口
│   └── 调用方: 外部HTTP客户端
│
└── [依赖] 外部模块接口
    ├── 文件存储服务 (service.IFileStorage)
    ├── 浏览器管理服务 (service.IChromeSet)
    ├── 告警服务 (service.IAlarm)
    ├── CSE服务接口 (service.ICse)
    ├── 控制通道集合 (tcpserver.control.ControlClientSet)
    ├── Moon SDK会话管理器 (websocket.extension.MuenSessionManager)
    └── 配置管理 (config.Config)
```

## 3. 对外提供的接口契约

### 3.1 IPluginManage 接口

#### 3.1.1 接口描述
插件管理的核心接口，提供插件状态管理、插件加载和MuenDriver实例创建功能。由`PluginManageImpl`实现，注册为Spring Bean（`@Component`）。

#### 3.1.2 接口定义
```java
package com.huawei.browsergateway.service;

import com.huawei.browsergateway.entity.plugin.PluginActive;
import com.moon.cloud.browser.sdk.core.MuenDriver;

/**
 * 插件管理接口
 */
public interface IPluginManage {

    /**
     * 获取插件激活状态
     *
     * 功能: 返回当前插件的激活状态对象，包含名称、版本、类型、状态等信息
     *
     * 调用方:
     *   - ExtensionManageService.getPluginInfo() - 获取插件信息供API返回
     *
     * @return PluginActive 插件激活状态对象（包含name/version/type/status等字段）
     *
     * 实现要求:
     *   - 直接返回内部pluginActive字段
     *   - 初始化时status="NotStart", type="ChromeExtend"
     *   - 线程安全：pluginActive是实例字段，单例Bean，天然线程安全
     */
    PluginActive getPluginActive();

    /**
     * 更新插件激活信息
     *
     * 功能: 更新插件的名称、版本和类型信息（不更新状态）
     *
     * 调用方: ExtensionManageService.loadExtension()
     * 调用时机: 在加载插件前更新插件信息
     *
     * @param name 插件名称
     * @param version 插件版本
     * @param type 插件类型
     *
     * 实现要求:
     *   - 设置pluginActive.setName(name)
     *   - 设置pluginActive.setVersion(version)
     *   - 设置pluginActive.setType(type)
     *   - 不更新status字段
     */
    void updatePluginActive(String name, String version, String type);

    /**
     * 加载插件（JAR包和JS扩展）
     *
     * 功能: 加载Moon SDK JAR包和Chrome JS扩展（按键/触屏）
     *
     * 调用方: ExtensionManageService.loadExtension()
     * 调用时机: 从S3下载并解压插件包后调用
     *
     * @param keyPath 按键扩展目录路径（可为null或空）
     * @param touchPath 触屏扩展目录路径（可为null或空）
     * @param jarPath JAR文件路径（可为null或空，null时跳过JAR加载）
     *
     * 实现要求:
     *   - 执行顺序: loadSDK(jarPath) -> loadJSExtension(keyPath, touchPath)
     *   - 如果两者都成功: updateStatus(Constant.COMPLETE)
     *   - 否则: updateStatus(Constant.FAILED)
     *   - jarPath为null或空时，loadSDK()返回true（允许不加载JAR）
     *   - keyPath/touchPath为null或空时，loadJSExtension()跳过对应扩展
     */
    void loadPlugin(String keyPath, String touchPath, String jarPath);

    /**
     * 更新插件状态
     *
     * 功能: 更新插件状态并上报告警
     *
     * 调用方:
     *   - PluginManageImpl.loadPlugin() - 内部调用
     *   - ExtensionManageService.loadExtension() - 加载失败时调用
     *
     * @param pluginStatus 插件状态（"NotStart"/"Completed"/"Failed"）
     *
     * 实现要求:
     *   - 如果pluginStatus == Constant.COMPLETE:
     *     - 调用alarm.clearAlarm(AlarmEnum.ALARM_300030.getAlarmId())清除告警
     *   - 否则:
     *     - 调用alarm.sendAlarm(new AlarmEvent(AlarmEnum.ALARM_300030, "ERROR:Failed to create plugin"))发送告警
     *   - 设置pluginActive.setStatus(pluginStatus)
     */
    void updateStatus(String pluginStatus);

    /**
     * 获取插件状态
     *
     * 功能: 获取当前插件的加载状态
     *
     * 调用方:
     *   - ChromeSetImpl.reportUsed() - 上报插件状态到CSE
     *   - InitServer.initializeExtensions() - 检查插件是否已加载完成
     *
     * @return String 插件状态字符串（"NotStart"/"Completed"/"Failed"）
     *
     * 实现要求:
     *   - 返回pluginActive.getStatus()
     */
    String getPluginStatus();

    /**
     * 为用户创建MuenDriver实例
     *
     * 功能: 基于已加载的Moon SDK JAR包，为指定用户创建MuenDriver驱动实例
     *
     * 调用方: ChromeSetImpl.create()
     * 调用时机: 创建UserChrome实例时，需要MuenDriver作为构造参数
     *
     * @param userId 用户ID（格式: {imei}_{imsi}）
     * @return MuenDriver Moon SDK驱动实例，如果类加载器未初始化则返回null
     *
     * 实现要求:
     *   - 如果muenPluginClassLoader == null: 返回null
     *   - 构建websocketAddr = address + ":" + config.getWebsocket().getMediaPort()
     *   - 获取localTmp = config.getTmpPath()
     *   - 创建HWCallbackImpl对象:
     *     new HWCallbackImpl(cse.getReportEndpoint(), fs, controlClientSet, 
     *                        muenSessionManager, userId, websocketAddr, localTmp)
     *   - 调用muenPluginClassLoader.createDriverInstance(hwCallback)
     *   - 返回MuenDriver实例（可能为null）
     *
     * 异常处理: 内部异常不向上传播，返回null
     */
    MuenDriver createDriver(String userId);
}
```

### 3.2 ExtensionManageApi REST接口

#### 3.2.1 接口描述
插件管理模块对外暴露的REST API，提供加载扩展和查询插件信息功能。

#### 3.2.2 接口定义

##### 3.2.2.1 加载扩展

```
POST /browsergw/extension/load
Content-Type: application/json
```

**请求体**:
```java
/**
 * 加载扩展请求
 */
@Data
public class LoadExtensionRequest {
    @JsonProperty("bucket_name")
    private String bucketName;              // S3存储桶名称（必填）

    @JsonProperty("extension_file_path")
    private String extensionFilePath;       // 扩展文件路径（必填，必须以.jar结尾）

    @JsonProperty("name")
    private String name;                     // 插件名称（必填）

    @JsonProperty("version")
    private String version;                  // 插件版本（必填）

    @JsonProperty("type")
    private String type;                     // 插件类型（可选）
}
```

**响应体（成功）**:
```json
{
    "code": 200,
    "message": "success",
    "data": {
        "bucket_name": "xxx",
        "extension_file_path": "xxx.jar"
    }
}
```

**响应体（失败）**:
```json
{
    "code": 500,
    "message": "system error!",
    "data": null
}
```

**处理流程**:
```
1. 参数校验:
   a. request != null → 返回CommonResult.error(ResultCode.VALIDATE_ERROR)
   b. name不能为空（trim后判断） → 返回CommonResult.error(ResultCode.VALIDATE_ERROR)
   c. version不能为空（trim后判断） → 返回CommonResult.error(ResultCode.VALIDATE_ERROR)
   d. bucketName不能为空（trim后判断） → 返回CommonResult.error(ResultCode.VALIDATE_ERROR)
   e. extensionFilePath不能为空（trim后判断） → 返回CommonResult.error(ResultCode.VALIDATE_ERROR)
   f. extensionFilePath必须以".jar"结尾 → 返回CommonResult.error(ResultCode.VALIDATE_ERROR)

2. 调用extensionManageService.loadExtension(request)
   - 内部执行: 下载插件包 -> 解压 -> 加载JAR和JS扩展 -> 关闭所有浏览器 -> 清理临时文件

3. 如果返回true:
   a. 创建LoadExtensionResponse对象
   b. 设置bucketName和extensionFilePath
   c. 返回CommonResult.success(response)
4. 否则:
   - 返回CommonResult.error(ResultCode.FAIL.getCode(), "reload extension failed")

异常处理: catch所有Exception，返回CommonResult.error(ResultCode.FAIL)
注意: 确保任何异常都不会导致500错误，始终返回结构化响应
```

##### 3.2.2.2 获取插件信息

```
GET /browsergw/extension/pluginInfo
```

**响应体（成功）**:
```json
{
    "code": 200,
    "message": "success",
    "data": {
        "name": "xxx",
        "version": "1.0.0",
        "type": "ChromeExtend",
        "status": "Completed",
        "bucket": "xxx",
        "packageName": "xxx.jar"
    }
}
```

**处理流程**:
```
1. 调用extensionManageService.getPluginInfo()
   - 内部: pluginManage.getPluginActive()

2. 返回CommonResult.success(pluginActive)

异常处理: catch所有Exception，返回CommonResult.error(ResultCode.FAIL)
```

### 4.1 文件存储服务 (IFileStorage)

#### 4.1.1 接口描述
提供文件的上传、下载、删除和查询功能，用于管理插件包和用户文件的S3远程存储。

#### 4.1.2 使用的接口方法

```java
package com.huawei.browsergateway.service;

public interface IFileStorage {
    /**
     * 下载文件从远程到本地
     *
     * 调用方:
     *   - ExtensionManageService.downPlugin() - 下载插件包
     *   - HWCallbackImpl.getFile() - SDK下载文件
     *
     * @param localPath 本地文件路径（绝对路径）
     * @param remotePath 远程文件路径（S3路径，格式: bucketName/path/to/file）
     *
     * 异常处理: 接口内部处理异常，可能抛出IOException
     * 说明: 如果本地文件已存在，会被覆盖
     */
    void downloadFile(String localPath, String remotePath) throws IOException;

    /**
     * 上传文件到远程
     *
     * 调用方: HWCallbackImpl.uploadFile() - SDK上传文件
     *
     * @param localPath 本地文件路径（绝对路径）
     * @param remotePath 远程文件路径（S3路径）
     *
     * 异常处理: 接口内部处理异常，可能抛出IOException
     */
    void uploadFile(String localPath, String remotePath) throws IOException;

    /**
     * 删除远程文件
     *
     * 调用方: HWCallbackImpl.uploadFile() - 上传前删除旧文件
     *
     * @param remotePath 远程文件路径（S3路径）
     *
     * 异常处理: 接口内部处理异常，不抛出
     * 说明: 文件不存在时不抛异常
     */
    void deleteFile(String remotePath);

    /**
     * 检查远程文件是否存在
     *
     * 调用方: HWCallbackImpl.uploadFile() - 检查文件是否存在
     *
     * @param remotePath 远程文件路径（S3路径）
     * @return boolean true=存在, false=不存在
     *
     * 异常处理: 接口内部处理异常，返回false
     */
    boolean exist(String remotePath);
}
```

| 组件 | 调用场景 | 说明 |
|------|---------|------|
| ExtensionManageService | downPlugin() | 从S3下载插件包（ZIP格式） |
| HWCallbackImpl | getFile() | SDK请求下载文件时 |
| HWCallbackImpl | uploadFile() | SDK请求上传文件时 |

### 4.2 浏览器管理服务 (IChromeSet)

#### 4.2.1 接口描述
浏览器实例管理服务，插件管理模块在加载新插件时需要关闭所有现有浏览器实例。

#### 4.2.2 使用的接口方法

```java
package com.huawei.browsergateway.service;

public interface IChromeSet {
    /**
     * 删除所有浏览器实例
     *
     * 调用方: ExtensionManageService.postLoadingPlugin()
     * 调用时机: 插件加载成功后，需要关闭所有现有浏览器实例以应用新插件
     *
     * 功能: 关闭所有用户的浏览器实例并清空映射表
     *   - 遍历所有key，逐个调用delete(key)
     *   - 遍历前复制keySet到新集合（避免ConcurrentModificationException）
     *   - 遍历完成后调用userChromeMap.clear()
     *   - 最后调用reportUsed()上报
     *
     * 异常处理: 接口内部处理异常，不抛出
     * 说明: 即使部分实例删除失败，也会继续删除其他实例
     */
    void deleteAll();

    /**
     * 上报服务使用状态到CSE
     *
     * 调用方: ExtensionManageService.loadExtension() - finally块中调用
     * 调用时机: 插件加载完成后（无论成功或失败），更新实例使用量上报
     *
     * 功能: 将当前实例的浏览器使用情况上报到服务注册中心
     *   - 构建ServiceReport对象（包含pluginStatus字段）
     *   - 序列化为JSON，以key="status"上报到CSE
     *
     * 异常处理: 接口内部处理异常，不抛出
     */
    void reportUsed();
}
```

| 组件 | 调用场景 | 说明 |
|------|---------|------|
| ExtensionManageService | postLoadingPlugin() | 插件加载后关闭所有浏览器实例 |
| ExtensionManageService | loadExtension() | finally块中上报实例使用量 |

```java
package com.huawei.browsergateway.service;

import com.huawei.browsergateway.entity.alarm.AlarmEvent;

public interface IAlarm {

     * @return boolean true=清除成功, false=清除失败
```

| 组件 | 调用场景 | 说明 |

### 4.7 配置管理 (Config)

#### 4.7.1 使用的配置项

```java
package com.huawei.browsergateway.config;

/**
 * 插件管理模块使用的配置项
 */
public class Config {
    // === 基础配置 ===
    String getAddress();                    // 服务器监听地址（用于构建websocketAddr）
    String getTmpPath();                    // 临时文件目录 = workspace + "/tmp"
```

## 6. 数据格式契约

### 6.1 LoadExtensionRequest 请求格式

```json
{
    "bucket_name": "s3-bucket-name",
    "extension_file_path": "path/to/extension.jar",
    "name": "plugin-name",
    "version": "1.0.0",
    "type": "ChromeExtend"
}
```

**字段说明**:
- `bucket_name`: S3存储桶名称（必填，非空）
- `extension_file_path`: 扩展文件路径（必填，必须以".jar"结尾）
- `name`: 插件名称（必填，非空）
- `version`: 插件版本（必填，非空）
- `type`: 插件类型（可选）

### 6.2 PluginActive 响应格式

```json
{
    "name": "plugin-name",
    "version": "1.0.0",
    "type": "ChromeExtend",
    "status": "Completed",
    "bucket": "s3-bucket-name",
    "packageName": "extension.jar"
}
```

**状态值说明**:
- `"NotStart"`: 插件未开始加载（初始化状态）
- `"Completed"`: 插件加载完成
- `"Failed"`: 插件加载失败

### 6.3 CSE插件信息响应格式

```json
[
    {
        "name": "plugin-name",
        "version": "1.0.0",
        "type": "ChromeExtend",
        "status": "Completed",
        "bucket": "s3-bucket-name",
        "packageName": "extension.jar"
    }
]
```

**说明**: CSE返回的是数组，取第一个元素作为当前插件。

## 8. 线程安全契约

### 8.1 并发安全要求

| 组件 | 线程安全机制 | 说明 |
|------|-------------|------|
| PluginManageImpl | Spring单例Bean | 实例字段天然线程安全 |
| ExtensionManageService.loadExtension() | synchronized方法 | 确保插件加载操作的原子性 |
| MuenPluginClassLoader | 实例字段 | 每个PluginManageImpl实例独立，不共享 |
| InitServer | 后台线程 | 独立线程执行，不阻塞主线程 |

### 8.2 并发场景说明

1. **插件加载并发**: `ExtensionManageService.loadExtension()`使用synchronized修饰，确保同一时间只有一个线程执行插件加载操作。

2. **MuenDriver创建并发**: `PluginManageImpl.createDriver()`无同步机制，但内部操作简单（创建对象），天然线程安全。

3. **状态查询并发**: `getPluginStatus()`和`getPluginActive()`直接返回字段，无并发问题。
