# 浏览器管理模块 - 模块间接口契约文档

## 1. 概述

本文档定义了浏览器管理模块与其他模块之间的接口契约。浏览器管理模块是BGW系统的核心模块，对外通过`IChromeSet`接口提供浏览器实例的全生命周期管理能力，对外通过`ChromeApi`提供REST API。本文档确保模块间的交互规范、明确、无歧义，依据本文档和设计说明书可100%复现浏览器管理模块的全部功能代码。

## 2. 模块依赖关系

```
浏览器管理模块 (service.IChromeSet / api.ChromeApi)
│
├── [对外提供] IChromeSet 接口
│   ├── 调用方: 远程通信模块 (service.impl.RemoteImpl)
│   ├── 调用方: 控制TCP服务 (tcpserver.control.ControlTcpServerHandler)
│   ├── 调用方: 定时任务模块 (scheduled.*)
│   ├── 调用方: 扩展管理服务 (service.ExtensionManageService)
│   ├── 调用方: WebSocket服务 (websocket.extension.MuenProxySocketServer)
│   └── 调用方: REST API (api.ChromeApi)
│
├── [对外提供] ChromeApi REST接口
│   └── 调用方: 外部HTTP客户端
│
└── [依赖] 外部模块接口
    ├── 文件存储服务 (service.IFileStorage)
    ├── 远程服务接口 (service.IRemote)
    ├── 插件管理服务 (service.IPluginManage)
    ├── 服务管理适配器 (adapter.interfaces.ServiceManagementAdapter)
    ├── 控制通道集合 (tcpserver.control.ControlClientSet)
    ├── 媒体通道集合 (tcpserver.media.MediaClientSet)
    ├── 配置管理 (config.Config)
    └── 浏览器驱动SDK (sdk.*)
```

## 3. 对外提供的接口契约

### 3.1 IChromeSet 接口

#### 3.1.1 接口描述
浏览器实例的全生命周期管理接口，提供创建、查询、删除、心跳管理和状态上报功能。由`ChromeSetImpl`实现，注册为Spring Bean（`@Service`）。

#### 3.1.2 接口定义
```java
package com.huawei.browsergateway.service;

import com.huawei.browsergateway.entity.request.InitBrowserRequest;
import com.huawei.browsergateway.service.impl.UserChrome;
import java.util.Set;

/**
 * 浏览器会话管理接口
 */
public interface IChromeSet {

    /**
     * 创建用户浏览器实例
     *
     * 功能: 根据请求参数创建浏览器实例，包括：
     *   1. 容量检查（当前实例数 vs config.report.cap）
     *   2. 生成userId（{imei}_{imsi}）
     *   3. 创建MuenDriver（通过IPluginManage.createDriver）
     *   4. 创建UserChrome对象（内部会下载用户数据、构建BrowserOptions）
     *   5. 存入内存映射表
     *   6. 上报实例使用量到CSE
     *
     * 调用方: RemoteImpl.createInstance()
     * 调用时机: 用户首次连接或配置变更需要重建实例时
     *
     * @param request 浏览器初始化请求参数（包含imei、imsi、设备信息等）
     * @return UserChrome 创建的用户浏览器实例
     * @throws RuntimeException 当容量不足时抛出，message = "cap is not enough!"
     * @throws RuntimeException 当用户数据下载、MuenDriver创建等失败时向上传播异常
     *
     * 实现要求:
     *   - userId生成规则: UserIdUtil.generateUserIdByImeiAndImsi(imei, imsi) = "{imei}_{imsi}"
     *   - 容量上限来源: config.getReport().getCap()
     *   - 创建成功后必须调用reportUsed()
     *   - 日志: INFO级别记录请求参数JSON
     */
    UserChrome create(InitBrowserRequest request);

    /**
     * 获取用户浏览器实例
     *
     * 功能: 从内存映射表中获取指定用户的浏览器实例
     *
     * 调用方:
     *   - RemoteImpl.createChrome() - 检查是否已有实例
     *   - RemoteImpl.fallback() - 获取实例执行回退
     *   - RemoteImpl.handleEvent() - 获取实例处理事件
     *   - ChromeApi.deleteUserData() - 检查是否存在实例
     *   - BrowserCheckTask - 遍历检查实例健康状态
     *   - BrowserCloserTask - 遍历检查实例超时
     *
     * @param userId 用户ID（格式: {imei}_{imsi}）
     * @return UserChrome 用户浏览器实例，不存在时返回null
     *
     * 实现要求:
     *   - 直接从ConcurrentHashMap获取，线程安全
     *   - 不抛出异常
     */
    UserChrome get(String userId);

    /**
     * 删除用户浏览器实例（完整删除）
     *
     * 功能: 断开TCP连接 + 关闭浏览器进程 + 上传用户数据 + 移除映射 + 上报
     *
     * 调用方:
     *   - RemoteImpl.createChrome() - 创建失败时清理
     *   - ChromeApi.deleteUserData() - 删除用户数据时先关闭实例
     *   - BrowserCheckTask - 清理失效实例
     *   - BrowserCloserTask - 关闭超时实例
     *
     * @param userId 用户ID
     *
     * 实现要求:
     *   - 用户不存在时打印WARN日志并返回（不抛异常）
     *   - 执行顺序: closeConnection() -> closeInstance() -> remove -> reportUsed()
     *   - closeConnection(): controlClientSet.del(userId) + mediaClientSet.del(userId)
     *   - closeInstance(): chromeDriver.quit() + userData.upload()
     *   - 日志: INFO级别记录userId和耗时
     */
    void delete(String userId);

    /**
     * 为重启场景删除实例（保持TCP连接）
     *
     * 功能: 仅关闭浏览器进程 + 上传用户数据 + 移除映射 + 上报（不断开TCP连接）
     *
     * 调用方: RemoteImpl.createChrome() - 配置变更或状态异常需要重建实例时
     * 调用时机: 在重新创建实例前调用，保持客户端TCP连接不断开
     *
     * @param userId 用户ID
     *
     * 实现要求:
     *   - 与delete()的唯一区别: 不调用closeConnection()
     *   - 执行顺序: closeInstance() -> remove -> reportUsed()
     */
    void deleteForRestart(String userId);

    /**
     * 删除所有浏览器实例
     *
     * 功能: 关闭所有用户的浏览器实例并清空映射表
     *
     * 调用方: 应用关闭时的资源清理
     *
     * 实现要求:
     *   - 遍历所有key，逐个调用delete(key)
     *   - 遍历前复制keySet到新集合（避免ConcurrentModificationException）
     *   - 遍历完成后调用userChromeMap.clear()
     *   - 最后调用reportUsed()
     *   - 日志: INFO级别记录开始和结束
     */
    void deleteAll();

    /**
     * 获取所有用户ID集合
     *
     * 调用方:
     *   - BrowserCheckTask - 遍历检查实例健康状态
     *   - BrowserCloserTask - 遍历检查实例超时
     *
     * @return Set<String> 用户ID集合（ConcurrentHashMap.keySet()，线程安全）
     *
     * 实现要求:
     *   - 直接返回ConcurrentHashMap的keySet()
     */
    Set<String> getAllUser();

    /**
     * 更新用户心跳时间
     *
     * 功能: 更新指定用户的心跳时间戳（纳秒级单调时钟）
     *
     * 调用方: ControlTcpServerHandler
     *   - processLogin(): 登录成功后更新心跳
     *   - processHeartbeats(): 收到心跳包后更新心跳
     *
     * @param userId 用户ID
     * @param heartbeats 心跳时间戳（System.nanoTime()）
     *
     * 实现要求:
     *   - 用户不存在时打印WARN日志并返回（不抛异常）
     *   - 调用UserChrome.setHeartbeats()（synchronized方法）
     */
    void updateHeartbeats(String userId, long heartbeats);

    /**
     * 获取用户心跳时间
     *
     * 功能: 获取指定用户的最后心跳时间戳
     *
     * 调用方: BrowserCloserTask - 判断实例是否超时
     *   - 超时判断: System.nanoTime() - getHeartbeats(userId) > config.getChrome().getTtl()
     *
     * @param userId 用户ID
     * @return long 心跳时间戳（纳秒），用户不存在时返回0
     *
     * 实现要求:
     *   - 用户不存在时打印WARN日志并返回0
     */
    long getHeartbeats(String userId);

    /**
     * 上报服务使用状态到CSE
     *
     * 功能: 将当前实例的浏览器使用情况上报到服务注册中心
     *
     * 调用方:
     *   - ServiceStatusRefresherTask: 定时上报（30秒/次）
     *   - ChromeSetImpl内部: create/delete/deleteAll后自动调用
     *
     * 实现要求:
     *   - synchronized方法（确保并发安全）
     *   - 构建ServiceReport对象:
     *     - id = config.getSelfAddr()
     *     - 从config.getReport()获取controlEndpoint/mediaEndpoint/controlTlsEndpoint/mediaTlsEndpoint/cap
     *     - edgeMediaInnerEndpoint = config.getAddress() + ":" + config.getWebsocket().getMediaPort()
     *     - pluginStatus = pluginManage.getPluginStatus()
     *     - used = userChromeMap.size()
     *   - 序列化为JSON，以key="status"上报到CSE
     *   - 调用serviceManagementAdapter.reportInstanceProperties({"status": jsonStr})
     *   - 上报失败时打印ERROR日志（不抛异常）
     */
    void reportUsed();

    /**
     * 上报链路端点信息到CSE
     *
     * 功能: 上报当前实例的链路端点配置信息
     *
     * 调用方: ServiceReporter - 应用启动时调用，支持重试
     *
     * @return boolean true=上报成功, false=上报失败（需要重试）
     *
     * 实现要求:
     *   - 构建属性Map: {"chainEndpoints": config.getReport().getChainEndpoints()}
     *   - 调用serviceManagementAdapter.reportInstanceProperties(reportMap)
     *   - 失败时打印ERROR日志并返回false
     */
    boolean reportChainEndpoints();
}
```

#### 3.1.3 UserChrome 数据结构契约

```java
package com.huawei.browsergateway.service.impl;

import com.huawei.browsergateway.config.Config;
import com.huawei.browsergateway.entity.browser.ChromeRecordConfig;
import com.huawei.browsergateway.entity.enums.BrowserStatus;
import com.huawei.browsergateway.entity.request.InitBrowserRequest;
import com.huawei.browsergateway.sdk.BrowserOptions;
import com.huawei.browsergateway.sdk.ChromiumDriverProxy;
import com.huawei.browsergateway.service.IFileStorage;
import com.huawei.browsergateway.service.IRemote;
import com.huawei.browsergateway.tcpserver.control.ControlClientSet;
import com.huawei.browsergateway.tcpserver.media.MediaClientSet;
import com.huawei.browsergateway.util.UserIdUtil;
import com.moon.cloud.browser.sdk.core.MuenDriver;
import com.moon.cloud.browser.sdk.model.pojo.ChromeParams;
import lombok.Data;

/**
 * 用户浏览器实例
 * 封装单个用户的浏览器实例及相关资源
 */
@Data
public class UserChrome {
    /** 用户唯一标识（格式: {imei}_{imsi}），构造时生成，不可变 */
    private final String userId;

    /** 浏览器配置选项，构造时由InitBrowserRequest.buildBrowserOptions()生成 */
    private BrowserOptions options;

    /**
     * Chromium浏览器驱动代理
     * 初始为null，在createBrowser()调用后赋值
     * 通过此对象操作浏览器（导航、执行脚本、关闭等）
     */
    private ChromiumDriverProxy chromeDriver;

    /** Moon SDK驱动实例，构造时由IPluginManage.createDriver()创建，不可变 */
    private final MuenDriver muenDriver;

    /** 用户数据管理器，构造时创建，不可变 */
    private final UserData userData;

    /** 控制通道客户端集合引用，构造时注入，不可变 */
    private final ControlClientSet controlClientSet;

    /** 媒体通道客户端集合引用，构造时注入，不可变 */
    private final MediaClientSet mediaClientSet;

    /**
     * Moon SDK返回的浏览器配置参数
     * 由RemoteImpl.createInstance()在Login后设置
     * 包含: chromeWidth, chromeHeight, frameRate, sampleRate, channels, bitRite,
     *       controlExtentionId, controlExtentionPath
     */
    private ChromeParams chromeParams;

    /**
     * 浏览器状态（volatile确保可见性）
     * - NORMAL: 正常状态（构造时默认值）
     * - REOPEN: 配置变更需要重建
     * - OPEN_ERROR: 打开错误（实例为null时RemoteImpl判定）
     * - PAGE_CONTROL_ERROR: 页面控制错误（RemoteImpl.fallbackByError()设置）
     */
    private volatile BrowserStatus status;

    /**
     * 控制流心跳时间（纳秒，单调时钟）
     * 构造时初始化为System.nanoTime()
     * 由ControlTcpServerHandler通过IChromeSet.updateHeartbeats()更新
     */
    private long heartbeats;

    /**
     * 构造函数
     * 执行流程:
     *   1. userId = UserIdUtil.generateUserIdByImeiAndImsi(request.getImei(), request.getImsi())
     *   2. userData = new UserData(fs, config.getUserDataPath(), userId, config.getSelfAddr(), remote)
     *   3. userdata = userData.download() // 从S3下载用户数据
     *   4. options = request.buildBrowserOptions(userdata, config) // 构建浏览器选项
     *   5. options.setUrl(config.getRecordExtensionPage()) // "chrome-extension://{recordExtensionId}/offscreen.html"
     *   6. 保存controlClientSet, mediaClientSet, muenDriver引用
     *   7. status = BrowserStatus.NORMAL
     *   8. heartbeats = System.nanoTime()
     */
    public UserChrome(InitBrowserRequest request, IFileStorage fs, Config config,
                      MuenDriver muenDriver, ControlClientSet controlClientSet,
                      MediaClientSet mediaClientSet, IRemote remote) { /* ... */ }

    /**
     * 创建实际的浏览器进程
     *
     * 调用方: RemoteImpl.createInstance()
     * 调用时机: 在构造UserChrome之后、MuenDriver.Login()之后调用
     *
     * 执行流程:
     *   1. options.setViewpoint(new ViewPort(params.getWidth(), params.getHeight() + 100))
     *      注意: 高度额外+100像素
     *   2. options.setRecordData(JSONUtil.toJsonStr(params))
     *   3. 确定browserType:
     *      - 默认 KEYS
     *      - 如果params.getControlExtensionPath()包含"touch"(小写)，则为TOUCH
     *   4. options.setBrowserType(browserType)
     *   5. options.getExtensionIds().add(params.getControlExtensionId())
     *   6. options.getExtensionPaths().add(params.getControlExtensionPath())
     *   7. options.setLimit(params.getLimit())
     *   8. chromeDriver = new ChromiumDriverProxy(options)
     *      - 内部创建BrowserDriver -> 连接CDP服务 -> 查找/创建浏览器 -> 创建上下文
     *
     * @param params 录制配置参数（由ChromeRecordConfig.from()生成）
     */
    public void createBrowser(ChromeRecordConfig params) { /* ... */ }

    /**
     * 关闭应用（完整关闭：断开连接+通知SDK+保存数据+上传数据）
     *
     * 调用方: RemoteImpl.fallback() / RemoteImpl.fallbackByError()
     * 调用时机: 用户正常退出或异常退出时
     *
     * 执行流程:
     *   1. controlClientSet.del(userId)
     *   2. mediaClientSet.del(userId)
     *   3. muenDriver.onControlTcpDisconnected()
     *   4. chromeDriver.saveUserdata() // 保存浏览器数据到本地
     *   5. userData.upload() // 上传到S3
     */
    public void closeApp() { /* ... */ }

    /**
     * 仅断开TCP连接（不关闭浏览器实例）
     *
     * 调用方: ChromeSetImpl.delete() 内部调用（非重启场景）
     *
     * 执行流程:
     *   1. controlClientSet.del(userId)
     *   2. mediaClientSet.del(userId)
     */
    public void closeConnection() { /* ... */ }

    /**
     * 关闭浏览器实例并上传用户数据（不断开TCP连接）
     *
     * 调用方: ChromeSetImpl.delete() / ChromeSetImpl.deleteForRestart() 内部调用
     *
     * 执行流程:
     *   1. 如果chromeDriver != null: chromeDriver.quit()
     *      - 内部: BrowserDriver.close() -> 删除CDP上下文
     *   2. userData.upload() // 上传到S3
     */
    public void closeInstance() { /* ... */ }

    /**
     * 线程安全地更新心跳时间
     * synchronized方法
     */
    public synchronized void setHeartbeats(long heartbeats) { /* ... */ }
}
```

#### 3.1.4 线程安全要求

| 方法/字段 | 线程安全机制 | 说明 |
|----------|-------------|------|
| userChromeMap | ConcurrentHashMap | 所有对映射表的操作天然线程安全 |
| getAllUser() | ConcurrentHashMap.keySet() | 返回的Set是弱一致性视图 |
| reportUsed() | synchronized方法 | 确保上报操作的原子性 |
| heartbeats字段 | volatile + synchronized setter | 确保心跳值的可见性和更新原子性 |
| status字段 | volatile | 确保状态变更对所有线程可见 |
| IRemote注入 | @Lazy | 延迟注入，避免与RemoteImpl的循环依赖 |

### 3.2 ChromeApi REST接口

#### 3.2.1 接口描述
浏览器管理模块对外暴露的REST API，提供预打开浏览器和删除用户数据功能。

#### 3.2.2 接口定义

##### 3.2.2.1 预打开浏览器

```
POST /browsergw/browser/preOpen
Content-Type: application/json
```

**请求体**:
```java
/**
 * 初始化浏览器请求
 */
@Data
public class InitBrowserRequest {
    @JsonProperty("factory")
    private String factory;          // 厂商

    @JsonProperty("dev_type")
    private String devType;          // 机型

    @JsonProperty("ext_type")
    private String extType;          // 扩展机型

    @JsonProperty("plat_type")
    private int platType;            // 平台类型

    @JsonProperty("lcd_width")
    private int lcdWidth;            // 屏幕宽度

    @JsonProperty("lcd_height")
    private int lcdHeight;           // 屏幕高度

    @JsonProperty("app_type")
    private int appType;             // 应用类型

    @JsonProperty("appid")
    private int appID;               // 应用ID

    private String innerMediaEndpoint = "127.0.0.1:30002"; // 内部媒体端点

    @JsonProperty("imsi")
    private String imsi;             // 用户设备IMSI号

    @JsonProperty("imei")
    private String imei;             // 用户设备IMEI号

    @JsonProperty("device_type")
    private int deviceType;          // 机器类型（1=按键，2=触屏）

    @JsonProperty("client_language")
    private String clientLanguage;   // 客户端语言

    @JsonProperty("play_mode")
    private int playMode = 1;        // 播放模式（0=JPG，1=实时流，默认1）
}
```

**响应体**:
```json
{
    "code": 200,
    "message": "success",
    "data": "success"
}
```

**错误响应**:
```json
{
    "code": 500,
    "message": "system error!",
    "data": null
}
```

**处理流程**:
```
1. 参数校验:
   a. param != null
   b. imei和imsi不能同时为空（trim后判断）
   - 校验失败: 返回CommonResult.error(ResultCode.FAIL)

2. 生成userId: UserIdUtil.generateUserIdByImeiAndImsi(imei, imsi)

3. 设置内部媒体端点: param.setInnerMediaEndpoint(config.getInnerMediaEndpoint())
   - config.getInnerMediaEndpoint() = config.address + ":" + config.websocket.mediaPort

4. TLV编码:
   a. 将param序列化为JSON字符串
   b. 反序列化为Message对象
   c. 设置message.audType = ""
   d. 设置message.token = ""
   e. TlvCodec.marshal(message) -> Tlv对象
   f. tlv.marshal(ByteOrder.BIG_ENDIAN) -> byte[]

5. 调用remote.createChrome(encodeParam, param, null)
   - 第三个参数null表示预打开场景（无回调Consumer）

6. 返回CommonResult.success("success")

异常处理: catch所有Exception，返回CommonResult.error(ResultCode.FAIL)
```

##### 3.2.2.2 删除用户数据

```
DELETE /browsergw/browser/userdata/delete
Content-Type: application/json
```

**请求体**:
```java
@Data
public class DeleteUserDataRequest {
    private String imei;    // 用户设备IMEI号
    private String imsi;    // 用户设备IMSI号
}
```

**响应体**:
```json
{
    "code": 200,
    "message": "success",
    "data": {
        "imei": "xxx",
        "imsi": "xxx"
    }
}
```

**处理流程**:
```
1. 生成userId: UserIdUtil.generateUserIdByImeiAndImsi(param.getImei(), param.getImsi())
2. 日志: INFO "deleteUserData userId:{userId}"

3. 查询浏览器实例: chromeSet.get(userId)
4. 如果实例存在:
   a. 日志: INFO "deleteUserData userChromeInfo:{}"
   b. chromeSet.delete(userId) // 关闭浏览器实例

5. 创建新UserData对象:
   new UserData(fs, config.getUserDataPath(), userId, config.getSelfAddr(), remote)

6. userdata.delete() // 删除本地和远程S3用户数据

7. 返回CommonResult.success(new DeleteUserDataResponse().setImei(imei).setImsi(imsi))

异常处理: catch所有Exception，返回CommonResult.error(ResultCode.FAIL)
注意: 确保任何异常都不会导致500错误，始终返回结构化响应
```

## 7. 异常处理规范

### 7.1 ChromeApi层（REST接口）

| 接口 | 异常处理策略 | 返回值 |
|------|-------------|--------|
| preOpenBrowser | try-catch包裹全部逻辑 | 异常时返回CommonResult.error(ResultCode.FAIL) |
| deleteUserData | try-catch包裹全部逻辑 | 异常时返回CommonResult.error(ResultCode.FAIL) |

**原则**: 不向客户端暴露内部异常细节，始终返回结构化响应。

### 7.2 ChromeSetImpl层（服务实现）

| 方法 | 异常处理策略 | 说明 |
|------|-------------|------|
| create() | 容量不足时抛出RuntimeException | 由调用方（RemoteImpl）处理 |
| get() | 不抛异常，不存在返回null | - |
| delete() | 用户不存在时WARN日志并返回 | 不抛异常 |
| deleteForRestart() | 同delete() | 不抛异常 |
| deleteAll() | 逐个删除，单个失败不影响其他 | 不抛异常 |
| updateHeartbeats() | 用户不存在时WARN日志并返回 | 不抛异常 |
| getHeartbeats() | 用户不存在时WARN日志并返回0 | 不抛异常 |
| reportUsed() | 上报失败时ERROR日志 | 不抛异常 |
| reportChainEndpoints() | 上报失败时ERROR日志并返回false | 不抛异常 |

### 7.3 UserData层（数据管理）

| 方法 | 异常处理策略 | 说明 |
|------|-------------|------|
| download() | catch所有异常，ERROR日志，返回本地路径 | 降级处理：使用空的本地数据 |
| upload() | 各步骤独立异常处理 | needUpload异常返回false；压缩异常提前返回 |
| delete() | 不catch异常 | 由调用方处理 |
| needUpload() | catch所有异常，返回false | 安全降级 |

## 9. 数据流转路径

### 9.1 用户数据存储路径

```
本地路径: {workspace}/userdata/{userId}/userdata.json
本地压缩: {workspace}/userdata/{userId}/userdata.json.zst
远程路径: userdata/{userId}/userdata.json.zst
```

### 9.2 用户数据生命周期

```
创建浏览器:
  S3远程 --[downloadFile]--> 本地.zst --[decompressJson]--> 本地.json
  本地.json --> BrowserOptions.userdata

关闭浏览器:
  chromeDriver.saveUserdata() --> 本地.json
  本地.json --[slimInplace]--> 本地.json(裁剪后)
  本地.json --[compressJson]--> 本地.zst --[uploadFile]--> S3远程
  删除本地.zst

删除用户数据:
  删除本地.json
  deleteFile(S3远程.zst)
```

### 9.3 ServiceReport上报数据流

```
ChromeSetImpl.reportUsed()
  -> 构建ServiceReport对象（从Config和pluginManage获取数据）
  -> JSONUtil.toJsonStr(report)
  -> Map{"status": jsonStr}
  -> serviceManagementAdapter.reportInstanceProperties(map)
  -> CSE服务注册中心
```
