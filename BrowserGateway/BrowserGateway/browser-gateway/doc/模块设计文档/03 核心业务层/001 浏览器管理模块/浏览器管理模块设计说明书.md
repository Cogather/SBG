# BrowserGateway 浏览器管理模块设计说明书

## 1. 概述

### 1.1 模块定位
浏览器管理模块是BrowserGateway系统的核心业务模块，负责用户浏览器实例的全生命周期管理。模块通过`IChromeSet`接口对外提供服务，由`ChromeSetImpl`实现，通过`ChromeApi`对外暴露REST API。

### 1.2 设计目标
- **会话管理**：创建和管理用户与浏览器实例的映射关系
- **容量控制**：限制单实例最大浏览器数量，防止资源溢出
- **心跳管理**：通过纳秒级单调时钟维护心跳，检测超时连接
- **数据持久化**：浏览器关闭时自动上传用户数据到S3，启动时自动下载
- **状态上报**：实时上报实例使用情况到CSE服务注册中心
- **用户数据管理**：支持用户数据的删除（本地+远程S3）

### 2.4 数据存储

浏览器管理模块使用内存级`ConcurrentHashMap`存储所有用户浏览器实例：

```java
private static final ConcurrentMap<String, UserChrome> userChromeMap = new ConcurrentHashMap<>();
```

- **Key**: userId（由IMEI和IMSI拼接生成，格式：`{imei}_{imsi}`）
- **Value**: UserChrome对象（封装浏览器实例、用户数据、连接信息）

## 3. 详细设计

### 3.1 IChromeSet 接口定义

**包路径**: `com.huawei.browsergateway.service.IChromeSet`

```java
public interface IChromeSet {
    // 创建用户浏览器实例
    UserChrome create(InitBrowserRequest request);

    // 获取用户浏览器实例
    UserChrome get(String userId);

    // 删除用户浏览器实例（断开连接+关闭实例+上传数据）
    void delete(String userId);

    // 为重启删除实例（不断开连接，仅关闭实例+上传数据）
    void deleteForRestart(String userId);

    // 删除所有实例
    void deleteAll();

    // 获取所有用户ID集合
    Set<String> getAllUser();

    // 更新用户心跳时间
    void updateHeartbeats(String userId, long heartbeats);

    // 获取用户心跳时间
    long getHeartbeats(String userId);

    // 上报已使用数量到CSE
    void reportUsed();

    // 上报链路端点信息到CSE
    boolean reportChainEndpoints();
}
```

#### 3.2.2 create(InitBrowserRequest request) 方法

**功能**: 创建用户浏览器实例

**执行流程**:
```
1. 打印日志，记录请求参数（JSON序列化）
2. 从config.getReport().getCap()获取容量上限
3. 判断当前实例数是否已达上限
   - 是：抛出RuntimeException("cap is not enough!")
   - 否：继续
4. 调用UserIdUtil.generateUserIdByImeiAndImsi(imei, imsi)生成userId
5. 调用pluginManage.createDriver(userId)创建MuenDriver实例
6. new UserChrome(request, fs, config, muenDriver, controlClientSet, mediaClientSet, remote)
   - UserChrome构造函数内部：
     a. 生成userId
     b. 创建UserData对象
     c. 调用userData.download()下载用户数据
     d. 调用request.buildBrowserOptions(userdata, config)构建浏览器选项
     e. 设置options.url为config.getRecordExtensionPage()
     f. 保存controlClientSet、mediaClientSet、muenDriver引用
     g. 设置status=BrowserStatus.NORMAL
     h. 设置heartbeats=System.nanoTime()
7. 将userId->UserChrome放入userChromeMap
8. 调用reportUsed()上报实例使用量
9. 返回UserChrome对象
```

**异常处理**:
- 容量不足时抛出RuntimeException
- UserChrome构造函数中的异常向上传播

#### 3.2.3 get(String userId) 方法

**功能**: 获取指定用户的浏览器实例

**执行流程**:
```
1. 直接返回userChromeMap.get(userId)
2. 不存在时返回null
```

#### 3.2.4 delete(String userId) 方法

**功能**: 删除用户浏览器实例（完整删除，包括断开连接）

**执行流程**:
```
1. 调用私有方法delete(userId, false)
```

#### 3.2.5 deleteForRestart(String userId) 方法

**功能**: 为重启场景删除实例（不断开连接）

**执行流程**:
```
1. 调用私有方法delete(userId, true)
```

#### 3.2.6 私有方法 delete(String userId, boolean reopen)

**功能**: 统一的删除逻辑

**执行流程**:
```
1. 记录开始时间 start = System.currentTimeMillis()
2. 从userChromeMap获取UserChrome实例
3. 如果实例为null
   - 打印warn日志"user: {userId} not exist."
   - 直接返回
4. 如果reopen==false（非重启场景）
   - 调用userChromeInfo.closeConnection()
     - 内部：controlClientSet.del(userId) + mediaClientSet.del(userId)
5. 调用userChromeInfo.closeInstance()
   - 内部：
     a. 如果chromeDriver不为null，调用chromeDriver.quit()（关闭浏览器进程）
     b. 调用userData.upload()（上传用户数据到S3）
6. 从userChromeMap移除该userId
7. 调用reportUsed()上报实例使用量
8. 打印info日志，包含userId和耗时
```

#### 3.2.7 deleteAll() 方法

**功能**: 关闭所有浏览器实例

**执行流程**:
```
1. 打印info日志"close all chrome instance start."
2. 复制userChromeMap的keySet到新HashMap（避免并发修改异常）
3. 遍历所有key，逐个调用delete(key)
4. 调用userChromeMap.clear()清空映射表
5. 调用reportUsed()上报实例使用量
6. 打印info日志"close all chrome instance success."
```

#### 3.2.8 getAllUser() 方法

**功能**: 获取所有用户ID集合

**返回值**: `userChromeMap.keySet()`（ConcurrentHashMap的keySet，线程安全）

#### 3.2.9 updateHeartbeats(String userId, long heartbeats) 方法

**功能**: 更新指定用户的心跳时间

**执行流程**:
```
1. 从userChromeMap获取UserChrome实例
2. 如果实例为null
   - 打印warn日志"user: {userId} not exist."
   - 直接返回
3. 调用userChromeInfo.setHeartbeats(heartbeats)（synchronized方法）
```

#### 3.2.10 getHeartbeats(String userId) 方法

**功能**: 获取指定用户的心跳时间

**执行流程**:
```
1. 从userChromeMap获取UserChrome实例
2. 如果实例为null
   - 打印warn日志"user: {userId} not exist."
   - 返回0
3. 返回userChromeInfo.getHeartbeats()
```

#### 3.2.11 reportUsed() 方法

**功能**: 上报当前实例使用情况到CSE服务注册中心

**修饰符**: `synchronized`（确保并发安全）

**执行流程**:
```
1. 获取本机ID: config.getSelfAddr()
2. 获取媒体内部端点: config.getAddress() + ":" + config.getWebsocket().getMediaPort()
3. 获取插件状态: pluginManage.getPluginStatus()
4. 创建ServiceReport对象:
   new ServiceReport(id, config.getReport(), mediaInnerEndpoint, pluginStatus)

#### 3.4.3 download() 方法

**功能**: 从S3下载用户数据到本地

**返回值**: 本地用户数据文件路径

**执行流程**:
```
1. 打印info日志"Downloading Chrome user data for user {userId}"
2. 计算本地路径: getLocalURL() -> {userdataDir}/{userId}/userdata.json
3. 计算远程路径: getRemoteURL() -> userdata/{userId}/userdata.json.zst
4. 调用fileStorageService.exist(remoteURL)检查远程文件是否存在
   - 不存在：打印info日志，返回本地路径（使用空的本地数据）

   - 不存在：创建目录并touch文件
6. 计算本地压缩文件路径: {userdataDir}/{userId}/userdata.json.zst
7. 调用fileStorageService.downloadFile(localZip, remoteURL)下载压缩文件
8. 调用ZstdUtil.decompressJson(localZip, localUserData)解压
9. 删除本地压缩文件
10. 返回本地用户数据文件路径
```

**异常处理**: catch所有异常，打印error日志，返回本地路径

#### 3.4.4 upload() 方法

**功能**: 上传用户数据到S3

**执行流程**:
```
1. 打印info日志"Uploading Chrome user data for user {userId}"
2. 调用needUpload()检查是否需要上传
   - 内部：调用remote.getUserBind(userId)获取用户绑定信息
   - 判断userBind不为null且selfAddr等于userBind.getBrowserInstance()
   - 异常时返回false
3. 如果不需要上传，打印info日志并返回
4. 获取本地文件路径: getLocalURL()
5. 检查本地文件是否存在
   - 不存在：打印warn日志并返回
6. 调用UserdataSlimmer.slimInplace(localUserData) - 原地脱敏处理
   - 过滤过期Cookie
   - 仅保留登录凭证相关Cookie（包含session/token/auth等关键字或HttpOnly）
   - 过滤localStorage，仅保留登录和验证相关条目
   - 特殊处理：tmofamily.com域名的数据不裁剪
7. 压缩: ZstdUtil.compressJson(localUserData, localZip) - Zstd压缩（级别6）
   - 压缩失败：打印error日志并返回
8. 计算远程路径: getRemoteURL()
9. 如果远程文件已存在，先删除
10. 调用fileStorageService.uploadFile(localZip, remoteURL)上传
11. 删除本地压缩文件
```

#### 3.4.5 delete() 方法

**功能**: 删除用户数据（本地+远程）

```
1. 打印info日志"Deleting Chrome user data for user {userId}"

### 6.2 UserdataSlimmer

**包路径**: `com.huawei.browsergateway.util.UserdataSlimmer`

**功能**: 用户数据脱敏（原地修改文件）

**裁剪规则**:
1. **Cookie裁剪**:
   - tmofamily.com域名的Cookie不裁剪
   - 过滤已过期的Cookie（expires < 当前时间戳）
   - 过滤空值或长度<=1的Cookie
   - 仅保留：名称包含登录关键字（session/token/auth/login等）或HttpOnly的Cookie
2. **Origins裁剪**:
   - tmofamily.com域名不裁剪
   - localStorage中仅保留名称包含登录/验证关键字或值为验证通过状态的条目
   - 过滤已过期的条目（JSON值中的expire/expires字段）
   - TikTok域名特殊处理：排除包含"text"的条目

### 6.3 ZstdUtil

**包路径**: `com.huawei.browsergateway.util.ZstdUtil`

**功能**: Zstd压缩/解压JSON文件

**参数**:
- 压缩级别: 6（范围1-22）
- 缓冲区大小: 8192字节

**方法**:
- `compressJson(String sourceJsonPath, String targetZstPath)`: 压缩JSON文件
- `decompressJson(String sourceZstPath, String targetJsonPath)`: 解压为JSON文件

### 6.4 TlvCodec

**包路径**: `com.huawei.browsergateway.util.encode.TlvCodec`

**功能**: TLV编解码器，用于控制流协议的消息编码

**方法**:
- `marshal(Object obj)`: 将Java对象转换为TLV结构（基于@TlvTag注解）
- `unmarshal(Tlv tlv, Object obj)`: 将TLV结构解析到Java对象

## 7. 关键流程

### 7.1 预打开浏览器完整流程

```
客户端 -> ChromeApi.preOpenBrowser(InitBrowserRequest)
  -> 参数校验（imei/imsi不能同时为空）
  -> 设置innerMediaEndpoint
  -> TLV编码请求参数
  -> IRemote.createChrome(encodedBytes, request, null)
    -> [远程通信模块处理]
    -> IChromeSet.create(request)
      -> 容量检查
      -> 生成userId
      -> 创建MuenDriver
      -> 创建UserChrome
        -> 创建UserData
        -> 下载用户数据(S3 -> 本地)
        -> 解压(Zstd)
        -> 构建BrowserOptions
      -> 存入userChromeMap
      -> 上报实例使用量到CSE
    -> [后续由远程通信模块调用UserChrome.createBrowser()创建实际浏览器]
```

### 7.2 删除用户数据完整流程

```
客户端 -> ChromeApi.deleteUserData(DeleteUserDataRequest)
  -> 生成userId
  -> 查询浏览器实例
  -> 如果存在实例:
    -> IChromeSet.delete(userId)
      -> closeConnection() [断开控制+媒体TCP连接]
      -> closeInstance()
        -> chromeDriver.quit() [关闭浏览器进程]
        -> userData.upload()
          -> needUpload()检查 [验证userBind归属]
          -> UserdataSlimmer.slimInplace() [数据脱敏]
          -> ZstdUtil.compressJson() [Zstd压缩]
          -> 上传到S3
      -> 从userChromeMap移除
      -> reportUsed() [上报到CSE]
  -> 创建新UserData对象
  -> UserData.delete()
    -> 删除本地文件
    -> 删除S3远程文件
```

### 7.3 浏览器实例关闭流程（delete vs deleteForRestart）

```
delete(userId):
  1. closeConnection() - 断开TCP连接
  2. closeInstance() - 关闭浏览器+上传数据
  3. 移除映射
  4. 上报

deleteForRestart(userId):
  1. [跳过closeConnection] - 保持TCP连接
  2. closeInstance() - 关闭浏览器+上传数据
  3. 移除映射
  4. 上报
```

## 8. 线程安全设计

### 8.1 并发控制

| 组件 | 线程安全机制 | 说明 |
|------|-------------|------|
| userChromeMap | ConcurrentHashMap | 线程安全的实例映射表 |
| reportUsed() | synchronized方法 | 确保上报操作原子性 |
| heartbeats | volatile字段 + synchronized setter | 确保心跳更新可见性 |
| status | volatile字段 | 确保状态变更可见性 |

### 8.2 延迟注入

`IRemote`使用`@Lazy`注入，原因是存在循环依赖：
- ChromeSetImpl依赖IRemote
- RemoteImpl依赖IChromeSet

## 9. 异常处理

### 9.1 ChromeApi层

- 所有接口方法使用try-catch包裹
- 异常时返回`CommonResult.error(ResultCode.FAIL)`
- 不向客户端暴露内部异常细节

### 9.2 ChromeSetImpl层

- create()：容量不足时抛出RuntimeException
- delete()：用户不存在时打印warn日志并返回（不抛异常）
- reportUsed()：上报失败时打印error日志（不抛异常）

### 9.3 UserData层

- download()：异常时打印error日志，返回本地路径（降级处理）
- upload()：各步骤独立异常处理，不影响其他步骤
- needUpload()：异常时返回false（安全降级）
