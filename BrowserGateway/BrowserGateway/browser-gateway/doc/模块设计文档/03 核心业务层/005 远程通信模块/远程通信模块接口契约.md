# 远程通信模块 - 模块间接口契约文档

## 1. 概述

本文档定义了远程通信模块与其他模块之间的接口契约。远程通信模块是BGW系统的核心模块，负责与远程服务（CSE服务注册中心）进行通信，提供用户绑定信息管理、浏览器实例创建协调、数据统计上报、事件上报等功能。对外通过`IRemote`接口提供服务。本文档确保模块间的交互规范、明确、无歧义，依据本文档和设计说明书可100%复现远程通信模块的全部功能代码。

## 2. 模块依赖关系

```
远程通信模块 (service.IRemote)
│
├── [对外提供] IRemote 接口
│   ├── 调用方: 浏览器管理模块 (service.impl.UserData)
│   │   ├── getUserBind(sessionID) - 检查用户绑定归属
│   │   └── updateUserBind(sessionID) - 更新用户绑定信息
│   ├── 调用方: 控制TCP服务 (tcpserver.control.ControlTcpServerHandler)
│   │   ├── createChrome(encodedBytes, request, consumer) - 创建浏览器实例
│   │   ├── handleEvent(encodedBytes, userId) - 处理控制事件
│   │   ├── fallback(sessionID) - 正常退出容错
│   │   ├── fallbackByError(sessionId) - 异常退出容错
│   │   ├── sendTrafficMedia(dataJson) - 上报媒体流量
│   │   ├── sendTrafficControl(dataJson) - 上报控制流量
│   │   ├── sendSession(dataJson) - 上报会话信息
│   │   └── reportEvent(event) - 上报事件
│   ├── 调用方: 媒体TCP服务 (tcpserver.media.MediaTcpServerHandle)
│   │   └── sendTrafficMedia(dataJson) - 上报媒体流量
│   ├── 调用方: REST API (api.ChromeApi)
│   │   └── createChrome(encodedBytes, request, null) - 预打开浏览器
│   └── 调用方: 定时任务模块 (scheduled.*)
│       └── getUserBind(sessionID) - 查询用户绑定信息
│
└── [依赖] 外部模块接口
    ├── 浏览器管理服务 (service.IChromeSet)
    ├── CSE服务接口 (service.ICse)
    ├── 告警服务接口 (service.IAlarm)
    ├── 配置管理 (config.Config)
    └── 工具类 (util.*)
```

## 3. 对外提供的接口契约

### 3.1 IRemote 接口

#### 3.1.1 接口描述
远程通信服务的核心接口，提供用户绑定管理、浏览器创建协调、数据统计上报、事件上报等功能。由`RemoteImpl`实现，注册为Spring Bean（`@Service`）。

#### 3.1.2 接口定义

```java
package com.huawei.browsergateway.service;

import com.huawei.browsergateway.entity.event.EventInfo;
import com.huawei.browsergateway.entity.request.InitBrowserRequest;
import com.huawei.browsergateway.service.impl.UserBind;
import java.util.function.Consumer;

/**
 * 远程通信服务接口
 */
public interface IRemote {
    
    /**
     * 获取用户绑定信息
     *
     * 功能: 从远程服务获取用户与浏览器实例的绑定关系
     *
     * 调用方:
     *   - UserData.needUpload() - 检查用户数据是否需要上传（验证归属）
     *   - BrowserCloserTask - 查询用户绑定信息，判断是否需要关闭实例
     *
     * 调用时机:
     *   - 上传用户数据前检查归属
     *   - 定时任务检查用户超时时
     *
     * @param sessionID 会话ID（格式: {imei}_{imsi}）
     * @return UserBind 用户绑定信息对象，不存在或获取失败时返回null
     *
     * 接口行为:
     *   - 发送GET请求到: http://{cse.getReportEndpoint()}/user-bind/v1/{sessionID}
     *   - 将响应体反序列化为UserBind对象
     *   - 异常时返回null（降级处理）
     *
     * 异常处理: 内部catch RuntimeException，打印error日志，返回null
     */
    UserBind getUserBind(String sessionID);
    
    /**
     * 过期用户绑定
     *
     * 功能: 使指定会话的用户绑定信息过期
     *
     * 调用方: BrowserCloserTask - 关闭超时实例后过期绑定
     *
     * 调用时机: 浏览器实例关闭后，使远程绑定信息过期
     *
     * @param sessionID 会话ID
     *
     * 接口行为:
     *   - 发送PUT请求到: http://{cse.getReportEndpoint()}/user-bind/v1/{sessionID}
     *   - 无请求体，无返回值
     *
     * 异常处理: 不捕获异常，由HttpUtil内部处理
     */
    void expiredUserBind(String sessionID);
    
    /**
     * 创建浏览器实例
     *
     * 功能: 创建或复用浏览器实例，处理配置变更和状态检查
     *
     * 调用方:
     *   - ControlTcpServerHandler.processLogin() - 用户连接时创建实例
     *   - ChromeApi.preOpenBrowser() - 预打开浏览器（consumer=null）
     *
     * 调用时机:
     *   - 用户首次连接时
     *   - 预打开浏览器时
     *   - 配置变更需要重建实例时
     *
     * @param receivedControlPackets 控制报文（TLV编码的字节数组）
     * @param parsedParams 解析后的浏览器初始化参数
     * @param consumer 结果消费者回调函数
     *   - null: 预打开场景，创建完实例即可结束
     *   - 非null: 用户连接场景，创建成功后执行回调
     *
     * 接口行为:
     *   1. 生成userId: UserIdUtil.generateUserIdByImeiAndImsi(imei, imsi)
     *   2. 获取用户锁（30秒超时）
     *   3. 检查浏览器状态:
     *      - 实例不存在 -> OPEN_ERROR
     *      - 状态为PAGE_CONTROL_ERROR -> PAGE_CONTROL_ERROR
     *      - 调用Moon SDK登录，比较配置 -> REOPEN 或 NORMAL
     *   4. 如果状态不是NORMAL:
     *      - chromeSet.deleteForRestart(userId) - 删除实例（不断开连接）
     *      - createInstance() - 创建新实例
     *   5. 如果consumer不为null:
     *      - Moon SDK登录
     *      - 通知控制连接已建立
     *      - 执行回调
     *      - 处理控制事件
     *      - 清除告警
     *   6. 释放锁
     *
     * 异常处理:
     *   - 锁超时: 抛出RuntimeException("get lock timeout!")
     *   - 其他异常: catch后删除实例，发送告警，打印error日志
     *   - finally块确保锁释放
     */
    void createChrome(byte[] receivedControlPackets, InitBrowserRequest parsedParams, Consumer<Object> consumer);
    
    /**
     * 容错处理（正常退出场景）
     *
     * 功能: 用户正常退出时的容错处理，关闭浏览器实例
     *
     * 调用方: ControlTcpServerHandler - 用户正常断开连接时
     *
     * 调用时机: TCP连接正常关闭时
     *
     * @param sessionID 会话ID（格式: {imei}_{imsi}）
     *
     * 接口行为:
     *   - 调用私有方法fallback(sessionID, false)
     *   - 获取浏览器实例
     *   - chrome.closeApp() - 关闭应用（断开连接+保存数据+上传数据）
     *   - 不设置错误状态
     *
     * 异常处理: 实例不存在时直接返回（不抛异常）
     */
    void fallback(String sessionID);
    
    /**
     * 容错处理（异常退出场景）
     *
     * 功能: 用户异常退出时的容错处理，关闭浏览器实例并设置错误状态
     *
     * 调用方: ControlTcpServerHandler - 用户异常断开连接时
     *
     * 调用时机: TCP连接异常关闭时
     *
     * @param sessionId 会话ID（格式: {imei}_{imsi}）
     *
     * 接口行为:
     *   - 调用私有方法fallback(sessionId, true)
     *   - 获取浏览器实例
     *   - chrome.closeApp() - 关闭应用
     *   - chrome.setStatus(BrowserStatus.PAGE_CONTROL_ERROR) - 设置错误状态
     *
     * 异常处理: 实例不存在时直接返回（不抛异常）
     */
    void fallbackByError(String sessionId);
    
    /**
     * 处理控制事件
     *
     * 功能: 处理控制事件，转发给Moon SDK
     *
     * 调用方:
     *   - ControlTcpServerHandler - 收到控制事件时
     *   - RemoteImpl.createChrome() - 创建实例后处理初始事件
     *
     * 调用时机:
     *   - 收到控制事件报文时
     *   - 浏览器实例创建成功后
     *
     * @param receivedControlPackets 控制报文（TLV编码的字节数组）
     * @param userId 用户ID（格式: {imei}_{imsi}）
     *
     * 接口行为:
     *   - 获取浏览器实例
     *   - 创建HWContext对象
     *   - 设置ChromeDriver到HWContext
     *   - 调用Moon SDK处理: muenDriver.Handle(hwContext, receivedControlPackets)
     *
     * 异常处理: 实例不存在时打印error日志并返回（不抛异常）
     */
    void handleEvent(byte[] receivedControlPackets, String userId);
    
    /**
     * 更新用户绑定信息
     *
     * 功能: 更新用户绑定信息到远程服务
     *
     * 调用方: ControlTcpServerHandler.processLogin() - 用户登录成功后
     *
     * 调用时机: 用户成功连接并登录后
     *
     * @param sessionID 会话ID（格式: {imei}_{imsi}）
     * @return UserBind 更新后的用户绑定信息对象，失败时返回null
     *
     * 接口行为:
     *   1. 创建UserBind对象
     *   2. 设置字段（从config获取）:
     *      - sessionId = sessionID
     *      - browserInstance = config.getSelfAddr()
     *      - controlEndpoint = config.getReport().getControlEndpoint()
     *      - mediaEndpoint = config.getReport().getMediaEndpoint()
     *      - controlTlsEndpoint = config.getReport().getControlTlsEndpoint()
     *      - mediaTlsEndpoint = config.getReport().getMediaTlsEndpoint()
     *      - innerMediaEndpoint = config.getInnerMediaEndpoint()
     *      - innerBrowserEndpoint = config.getSelfAddr()
     *   3. 发送POST请求到: http://{cse.getReportEndpoint()}/user-bind/v1/update
     *   4. 请求体为UserBind的JSON字符串
     *   5. 将响应体反序列化为UserBind对象
     *
     * 异常处理: catch RuntimeException，打印error日志，返回null
     */
    UserBind updateUserBind(String sessionID);
    
    /**
     * 发送媒体流量统计
     *
     * 功能: 上报媒体流量统计数据到远程监控服务
     *
     * 调用方:
     *   - MediaTcpServerHandle - 媒体通道流量统计
     *
     * 调用时机: 媒体通道流量统计事件触发时
     *
     * @param dataJson 媒体流量统计数据的JSON字符串
     *
     * 接口行为:
     *   - 发送POST请求到: http://{cse.getReportEndpoint()}/stats/v1/traffic/media
     *   - 请求体为dataJson
     *
     * 异常处理: catch RuntimeException，打印error日志（不抛异常）
     */
    void sendTrafficMedia(String dataJson);
    
    /**
     * 发送控制流量统计
     *
     * 功能: 上报控制流量统计数据到远程监控服务
     *
     * 调用方:
     *   - ControlTcpServerHandler - 控制通道流量统计
     *
     * 调用时机: 控制通道流量统计事件触发时
     *
     * @param dataJson 控制流量统计数据的JSON字符串
     *
     * 接口行为:
     *   - 发送POST请求到: http://{cse.getReportEndpoint()}/stats/v1/traffic/control
     *   - 请求体为dataJson
     *
     * 异常处理: catch RuntimeException，打印error日志（不抛异常）
     */
    void sendTrafficControl(String dataJson);
    
    /**
     * 发送会话信息
     *
     * 功能: 上报会话开始和结束信息到远程监控服务
     *
     * 调用方:
     *   - ControlTcpServerHandler.sessionLoginIn() - 会话开始
     *   - ControlTcpServerHandler.sessionLoginOut() - 会话结束
     *
     * 调用时机:
     *   - 用户连接时（会话开始）
     *   - 用户断开时（会话结束）
     *
     * @param dataJson 会话信息的JSON字符串
     *
     * 接口行为:
     *   - 发送POST请求到: http://{cse.getReportEndpoint()}/stats/v1/session
     *   - 请求体为dataJson
     *
     * 异常处理: catch RuntimeException，打印error日志（不抛异常）
     */
    void sendSession(String dataJson);
    
    /**
     * 上报事件
     *
     * 功能: 上报服务器事件到远程服务
     *
     * 调用方:
     *   - ControlTcpServerHandler - 上报流量统计事件
     *   - 其他模块 - 上报各种服务器事件
     *
     * 调用时机: 需要上报服务器事件时
     *
     * @param event 事件信息对象（泛型）
     *
     * 接口行为:
     *   - 调用ReportEventUtil.reportServerEvent(event, cse.getReportEndpoint())
     *   - 内部构建URL: http://{endpoint}/server/event/v1/uploadEvent
     *   - 设置日期格式: "yyyy-MM-dd HH:mm:ss"
     *   - 序列化为JSON并发送POST请求
     *
     * 异常处理: 由ReportEventUtil内部处理异常，打印error日志
     */
    <T> void reportEvent(EventInfo<T> event);
}
```

#### 3.1.3 LockManager 数据结构契约

```java
package com.huawei.browsergateway.service.impl;

import org.springframework.stereotype.Component;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.locks.ReentrantLock;

/**
 * 锁管理器
 * 提供用户级别的分布式锁管理
 */
@Component
public class LockManager {
    /** 用户锁映射表（线程安全） */
    private static final ConcurrentHashMap<String, ReentrantLock> lockMap = new ConcurrentHashMap<>();
    
    /**
     * 获取指定用户的锁对象（如果不存在则创建）
     *
     * 调用方: RemoteImpl.createChrome() - 获取用户锁
     *
     * @param userId 用户ID（格式: {imei}_{imsi}）
     * @return ReentrantLock 锁对象
     *
     * 接口行为:
     *   - 如果userId对应的锁不存在，创建新的ReentrantLock
     *   - 如果已存在，直接返回
     *   - 使用computeIfAbsent确保线程安全
     */
    public ReentrantLock getLock(String userId);
    
    /**
     * 移除指定用户的锁对象
     *
     * 调用方: RemoteImpl.createChrome() - finally块中清理锁
     *
     * @param userId 用户ID
     *
     * 接口行为:
     *   - 从映射表中移除该userId对应的锁
     *   - 释放锁对象占用的内存
     */
    public void removeLock(String userId);
}
```

#### 3.1.4 线程安全要求

| 方法/字段 | 线程安全机制 | 说明 |
|----------|-------------|------|
| lockMap | ConcurrentHashMap | 锁映射表线程安全 |
| createChrome() | tryLock + finally | 确保锁的获取和释放 |
| 锁超时 | 30秒超时 | LOCK_TIMEOUT_SECONDS = 30 |
| 锁清理 | removeLock() | 使用完锁后清理，避免内存泄漏 |

## 4. 依赖的外部接口契约

### 4.1 浏览器管理服务 (IChromeSet)

#### 4.1.1 接口描述
提供浏览器实例的全生命周期管理功能。

#### 4.1.2 使用的接口方法

```java
package com.huawei.browsergateway.service;

import com.huawei.browsergateway.entity.request.InitBrowserRequest;
import com.huawei.browsergateway.service.impl.UserChrome;

public interface IChromeSet {
    /**
     * 创建用户浏览器实例
     *
     * 调用方: RemoteImpl.createInstance()
     * 调用时机: 需要创建新浏览器实例时
     *
     * @param request 浏览器初始化请求参数
     * @return UserChrome 创建的用户浏览器实例
     * @throws RuntimeException 当容量不足时抛出，message = "cap is not enough!"
     */
    UserChrome create(InitBrowserRequest request);
    
    /**
     * 获取用户浏览器实例
     *
     * 调用方:
     *   - RemoteImpl.createChrome() - 检查是否已有实例
     *   - RemoteImpl.fallback() - 获取实例执行回退
     *   - RemoteImpl.handleEvent() - 获取实例处理事件
     *
     * @param userId 用户ID
     * @return UserChrome 用户浏览器实例，不存在时返回null
     */
    UserChrome get(String userId);
    
    /**
     * 删除用户浏览器实例（完整删除）
     *
     * 调用方: RemoteImpl.createChrome() - 创建失败时清理
     *
     * @param userId 用户ID
     */
    void delete(String userId);
    
    /**
     * 为重启场景删除实例（保持TCP连接）
     *
     * 调用方: RemoteImpl.createChrome() - 配置变更或状态异常需要重建实例时
     *
     * @param userId 用户ID
     */
    void deleteForRestart(String userId);
}
```

#### 4.1.3 调用场景

| 方法 | 调用方 | 说明 |
|------|--------|------|
| create() | RemoteImpl.createInstance() | 创建新浏览器实例 |
| get() | RemoteImpl.createChrome() | 检查是否已有实例 |
| get() | RemoteImpl.fallback() | 获取实例执行回退 |
| get() | RemoteImpl.handleEvent() | 获取实例处理事件 |
| delete() | RemoteImpl.createChrome() | 创建失败时清理 |
| deleteForRestart() | RemoteImpl.createChrome() | 配置变更需要重建时 |

### 4.2 CSE服务接口 (ICse)

#### 4.2.1 接口描述
提供CSE服务注册中心的端点地址获取功能，用于动态获取远程服务端点。

#### 4.2.2 使用的接口方法

```java
package com.huawei.browsergateway.service;

public interface ICse {
    /**
     * 获取CSE上报端点地址
     *
     * 调用方: RemoteImpl的所有HTTP请求方法
     * 调用时机: 每次执行HTTP请求前获取服务端点
     *
     * @return String CSE端点地址（格式: IP:Port），失败返回空字符串
     *
     * 接口行为:
     *   - 从CSE服务注册中心动态获取服务端点
     *   - 随机选择一个可用端点返回（负载均衡）
     *   - 如果查询失败或没有可用端点，返回空字符串
     *
     * 异常处理: 接口内部处理异常，可能返回空字符串
     * 说明: 返回空字符串时，HTTP请求会失败（无法构建URL）
     */
    String getReportEndpoint();
}
```

#### 4.2.3 调用场景

| 方法 | 调用方 | 说明 |
|------|--------|------|
| getReportEndpoint() | RemoteImpl的所有HTTP请求方法 | 获取远程服务端点，用于构建HTTP请求URL |

### 4.3 告警服务接口 (IAlarm)

#### 4.3.1 接口描述

#### 4.3.2 使用的接口方法

```java
package com.huawei.browsergateway.service;

import com.huawei.browsergateway.entity.alarm.AlarmEvent;

public interface IAlarm {
    /**
     * 发送告警
     *
     * 调用方: RemoteImpl.createChrome() - 创建失败时发送告警

     *   - 异常消息包含"failed to create browsers"时发送ALARM_300033

    /**
     * 清除告警
     *
     * 调用方: RemoteImpl.createChrome() - 创建成功后清除告警
     * 调用时机: 浏览器实例创建成功后
     *
     * @param alarmId 告警ID（如: "300033", "300031"）
     * @return boolean true=清除成功, false=清除失败
     *
     * 异常处理: 接口内部处理异常，返回false
     */
    boolean clearAlarm(String alarmId);
}
```

#### 4.3.3 调用场景

| 方法 | 调用方 | 说明 |
|------|--------|------|
| sendAlarm() | RemoteImpl.createChrome() | 创建失败时发送告警 |
| clearAlarm() | RemoteImpl.createChrome() | 创建成功后清除告警 |

## 6. 异常处理契约

### 6.1 异常处理原则

远程通信模块的接口方法采用**混合异常处理**策略：
- **关键操作**（createChrome）：部分异常向上抛出，部分异常内部处理
- **查询操作**（getUserBind、updateUserBind）：内部处理异常，返回null
- **上报操作**（sendTraffic*、sendSession、reportEvent）：内部处理异常，不抛异常

### 6.2 异常处理方式

#### 6.2.1 createChrome()

- **锁超时异常**: 抛出RuntimeException("get lock timeout!")
- **其他异常**: catch后删除实例，发送告警，打印error日志
- **finally块**: 确保锁释放

#### 6.2.2 getUserBind() / updateUserBind()

- **异常处理**: 内部catch RuntimeException，打印error日志，返回null
- **影响**: 降级处理，调用方需要检查返回值

#### 6.2.3 fallback() / fallbackByError()

- **异常处理**: 实例不存在时直接返回（不抛异常）
- **影响**: 安全降级，不影响调用方继续执行

#### 6.2.4 handleEvent()

- **异常处理**: 实例不存在时打印error日志并返回（不抛异常）
- **影响**: 安全降级

#### 6.2.5 上报操作（sendTraffic*、sendSession、reportEvent）

- **异常处理**: 内部catch RuntimeException，打印error日志（不抛异常）
- **影响**: 上报失败不影响主流程

## 7. 性能要求

### 7.1 响应时间要求

| 操作 | 响应时间要求 | 说明 |
|------|------------|------|
| getUserBind() | < 1秒 | 用户绑定信息查询 |
| updateUserBind() | < 1秒 | 用户绑定信息更新 |
| expiredUserBind() | < 1秒 | 用户绑定过期 |
| createChrome() | 取决于浏览器创建时间 | 包含浏览器实例创建，可能较慢 |
| handleEvent() | < 100ms | 事件处理转发 |
| sendTrafficMedia() | < 500ms | 媒体流量上报 |
| sendTrafficControl() | < 500ms | 控制流量上报 |
| sendSession() | < 500ms | 会话信息上报 |
| reportEvent() | < 500ms | 事件上报 |

### 7.2 并发要求

- **锁超时时间**: 30秒（LOCK_TIMEOUT_SECONDS）
- **锁管理**: 使用ConcurrentHashMap存储锁，线程安全
- **HTTP客户端**: 使用HttpUtil的连接池（最大100连接，每路由20连接）
- **CSE端点获取**: 每次请求独立获取，支持负载均衡

## 9. 数据流转路径

### 9.1 浏览器创建流程

```
客户端连接
  -> ControlTcpServerHandler.processLogin()
  -> IRemote.createChrome(encodedBytes, request, consumer)
    -> 获取用户锁（30秒超时）
    -> IChromeSet.get(userId) - 检查是否已有实例
    -> checkBrowserStatus() - 检查状态
      -> 如果状态不是NORMAL:
        -> IChromeSet.deleteForRestart(userId) - 删除旧实例
        -> IChromeSet.create(request) - 创建新实例
        -> Moon SDK登录，获取配置
        -> UserChrome.createBrowser() - 创建浏览器进程
    -> 如果consumer不为null:
      -> Moon SDK登录
      -> 通知控制连接已建立
      -> consumer.accept(null) - 执行回调
      -> handleEvent() - 处理初始事件
      -> IAlarm.clearAlarm() - 清除告警
    -> 释放锁
```

### 9.2 用户绑定更新流程

```
用户登录成功
  -> ControlTcpServerHandler.processLogin()
  -> IRemote.updateUserBind(sessionID)
    -> 创建UserBind对象（从config获取端点信息）
    -> POST请求到CSE: /user-bind/v1/update
    -> 返回UserBind对象
```

### 9.3 数据统计上报流程

```
流量统计事件触发
  -> ControlTcpServerHandler / MediaTcpServerHandle
  -> IRemote.sendTrafficMedia/Control(dataJson)
    -> POST请求到CSE: /stats/v1/traffic/media 或 /stats/v1/traffic/control
    -> 请求体为JSON字符串
```

### 9.4 事件上报流程

```
服务器事件触发
  -> IRemote.reportEvent(event)
    -> ReportEventUtil.reportServerEvent(event, endpoint)
      -> 构建URL: http://{endpoint}/server/event/v1/uploadEvent
      -> 设置日期格式
      -> 序列化为JSON
      -> POST请求
```
