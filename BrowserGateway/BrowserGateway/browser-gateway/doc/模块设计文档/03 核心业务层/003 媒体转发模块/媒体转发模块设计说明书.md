# BrowserGateway 媒体转发模块设计说明书

## 1. 概述

### 1.1 模块定位
媒体转发模块是BrowserGateway系统的核心业务模块，负责浏览器与客户端之间的媒体流和控制流的双向转发。模块通过TCP和WebSocket两种协议提供服务，支持TLS加密传输，实现音视频数据的实时转发、编解码处理和流量统计。

### 1.2 设计目标
- **双通道转发**：提供控制通道和媒体通道两个独立的TCP连接通道
- **协议支持**：支持TLV协议（TCP）和WebSocket协议（二进制流）
- **TLS加密**：支持TLS加密传输，保障数据传输安全
- **编解码处理**：支持FFmpeg和WebCodecs两种编解码模式
- **流量统计**：实时统计和上报控制流、媒体流的数据流量
- **会话管理**：管理客户端连接会话，支持心跳保活和自动清理
- **事件上报**：上报登录事件、流量统计事件等业务事件

### 2.4 数据存储

媒体转发模块使用内存级`ConcurrentHashMap`存储客户端连接和会话信息：

**TCP客户端连接存储**:
```java
// ControlClientSet / MediaClientSet
protected final Map<String, Client> map = new ConcurrentHashMap<>();
```
- **Key**: sessionId（由IMEI和IMSI拼接生成，格式：`{imei}_{imsi}`）
- **Value**: Client对象（封装Netty Channel、客户端属性）

**WebSocket会话存储**:
```java
// MediaSessionManager
private final Map<String, Session> sessions = new ConcurrentHashMap<>();
private final Map<String, MediaStreamProcessor> processorMap = new ConcurrentHashMap<>();
```
- **Key**: userId（imeiAndImsi）
- **Value**: WebSocket Session对象和MediaStreamProcessor对象

**流量统计存储**:
```java
// DataSizeTracker
private final ConcurrentHashMap<String, AtomicLong> dataSizeMap = new ConcurrentHashMap<>();
```
- **Key**: `{imeiAndImsi}@{appType}@{clientIP}`
- **Value**: 累计数据大小（字节）

**流量速率存储**:
```java
// FlowRateTracker
private final ConcurrentHashMap<String, AtomicLong> flowRateMap = new ConcurrentHashMap<>();
```
- **Key**: `{sessionId}@{serviceType}`
- **Value**: 当前统计周期内的流量（字节）

### 3.1 AbstractTcpServer TCP服务器抽象基类

**包路径**: `com.huawei.browsergateway.tcpserver.AbstractTcpServer`

#### 3.1.1 字段定义

| 字段名 | 类型 | 修饰符 | 说明 |
|--------|------|--------|------|
| bossGroup | `EventLoopGroup` | - | Netty boss线程组（接收连接） |
| workerGroup | `EventLoopGroup` | - | Netty worker线程组（处理数据） |
| channelFuture | `ChannelFuture` | - | 服务器通道Future |

#### 3.1.2 抽象方法

| 方法名 | 返回类型 | 说明 |
|--------|---------|------|
| getLogger() | `Logger` | 获取日志记录器 |
| getPort() | `Integer` | 获取监听端口 |

| getEncoder() | `ChannelHandler` | 获取编码器 |
| getDecoder() | `ChannelHandler` | 获取解码器 |

#### 3.1.3 start(boolean isTLS) 方法

**功能**: 启动TCP服务器

**执行流程**:
```
1. 获取端口和地址配置
2. 创建Netty事件循环组（bossGroup、workerGroup）
3. 在新线程中执行启动逻辑：
   a. 检查证书是否就绪（CertInfo.getInstance().isCertReady()）
   b. 如果证书就绪且isTLS=true：
      - 加载CA证书、设备证书、私钥
      - 构建SslContext（支持TLSv1.2、TLSv1.3）
      - 配置加密套件（ECDHE_RSA/ECDSA + AES_GCM）
   c. 创建ServerBootstrap：
      - 设置bossGroup和workerGroup
      - 使用NioServerSocketChannel
      - 配置childHandler（ChannelInitializer）：
        * 如果TLS且证书就绪，添加SSL Handler
        * 添加Decoder（TLV解码器）
        * 添加Encoder（TLV编码器）
        * 添加Handler（业务处理器）
      - 设置SO_BACKLOG=128
      - 设置SO_KEEPALIVE=true
   d. 绑定地址和端口
   e. 等待通道关闭（channelFuture.channel().closeFuture().sync()）
4. 打印启动日志
```

**异常处理**: catch所有异常，打印error日志

#### 3.1.4 stop() 方法

**功能**: 停止TCP服务器

**执行流程**:
```
1. 打印停止日志
2. 如果channelFuture不为null：
   - 关闭通道并等待完成（channel.close().sync()）
3. 优雅关闭workerGroup（shutdownGracefully()）
4. 优雅关闭bossGroup（shutdownGracefully()）
5. 打印停止完成日志
```

1. 从映射表移除：map.remove(key)

   - 关闭客户端连接（remove.close()）

**del(Client cli) 方法**:
```
1. 从客户端获取sessionID：cli.getStr(VAL_SESSION_ID)
2. 如果sessionID不为null：
   - 调用del(sessionID)
```

**get(String key) 方法**: 返回`map.get(key)`

**allClient() 方法**: 返回`map.keySet()`

#### 3.8.1 字段定义

| loginInfoMap | `ConcurrentMap<String, Message>` | final | 登录信息映射表 |

#### 3.8.2 channelActive(ChannelHandlerContext ctx) 方法

**功能**: 客户端连接建立时触发

**执行流程**:
```
1. 打印info日志："control client connected: {remoteAddress}"
```

#### 3.8.3 channelRead(ChannelHandlerContext ctx, Object msg) 方法

**功能**: 接收客户端发送的数据

**执行流程**:
```
1. 将msg转换为Tlv对象
2. 获取消息类型：tlv.getType()
3. 从上下文获取Client对象：Client.fromCtx(ctx)
4. 获取sessionId：cli.getStr(VAL_SESSION_ID)
5. 根据消息类型分发处理：
   - Type.LOGIN: 调用processLogin(cli, tlv)
   - Type.HEARTBEATS: 调用processHeartbeats(cli, tlv)
   - 其他: 调用processDefault(cli, tlv, type)
```

#### 3.8.4 processLogin(Client cli, Tlv tlv) 方法

**功能**: 处理登录消息

**执行流程**:
```
1. 解析TLV为Message对象：TlvCodec.unmarshal(tlv, message)
2. 校验lcdWidth和lcdHeight：
   - 如果width==0或height==0，抛出RuntimeException("lcd width or height is invalid")
3. 生成key：Type.tcpBindKey(message.getImei(), message.getImsi())
4. 获取UserBind：remote.getUserBind(key)
   - 如果为null，抛出RuntimeException("not found user bind info")
5. 校验token：
   - 如果message.getToken() != ub.getToken()，抛出RuntimeException("user token is invalid")
6. 生成tcpUniqueId：UUID.randomUUID().toString()
7. 设置客户端属性：
   - VAL_APP_TYPE = message.getAppType()
   - VAL_SESSION_ID = key
   - VAL_HEARTBEAT_TIME = System.nanoTime()
   - VAL_UPDATE_TIME = System.currentTimeMillis()
   - VAL_START_TIME = System.currentTimeMillis()
   - VAL_TCP_UNIQUE_ID = tcpUniqueId
   - VAL_NETWORK_TYPE = message.getNetworkType()
8. 保存客户端：cs.set(key, cli)
9. 保存登录信息：loginInfoMap.put(key, message)
10. 发送ACK应答：cli.ack(message.getType(), Code.OK)
11. 更新浏览器心跳：chromeSet.updateHeartbeats(key, System.nanoTime())
12. 更新UserBind：remote.updateUserBind(key)
13. 异步创建浏览器：ThreadUtil.execute(() -> createBrowser(cli, message, newUserBind, tlv))
14. 上报会话登录：sessionLoginIn(key, message.getAppType(), tcpUniqueId)
```

#### 3.8.5 createBrowser(Client cli, Message message, UserBind ub, Tlv tlv) 方法

**功能**: 创建浏览器实例

**执行流程**:
```
1. 将message序列化为JSON字符串
2. 反序列化为InitBrowserRequest对象
3. 设置innerMediaEndpoint：request.setInnerMediaEndpoint(ub.getInnerMediaEndpoint())
4. 将TLV序列化为字节数组：tlv.marshal(ByteOrder.BIG_ENDIAN)
5. 调用remote.createChrome(bytes, request, callback)：
   - callback: 创建成功后发送LoginResponse（包含媒体端点地址）
6. 如果异常：
   - 发送失败ACK：cli.ack(message.getType(), Code.FAILED)
   - 打印error日志
```

#### 3.8.6 processDefault(Client cli, Tlv tlv, int messageType) 方法

**功能**: 处理默认消息（控制事件等）

**执行流程**:
```
1. 记录开始时间：start = System.currentTimeMillis()
2. 解析TLV为Message对象：TlvCodec.unmarshal(tlv, message)
3. 获取sessionId：cli.getStr(VAL_SESSION_ID)
4. 发送ACK应答：cli.ack(message.getType(), Code.OK)
5. 将TLV序列化为字节数组：tlv.marshal(ByteOrder.BIG_ENDIAN)
6. 转发到远程服务：remote.handleEvent(bytes, sessionId)
7. 打印处理完成日志（包含耗时）
```

#### 3.8.7 processHeartbeats(Client cli, Tlv tlv) 方法

**功能**: 处理心跳消息

**执行流程**:
```
1. 解析TLV为Message对象：TlvCodec.unmarshal(tlv, message)
2. 更新客户端属性：
   - VAL_UPDATE_TIME = System.currentTimeMillis()
   - VAL_HEARTBEAT_TIME = System.nanoTime()
3. 发送ACK应答：cli.ack(message.getType(), Code.OK)
4. 获取sessionId：cli.getStr(VAL_SESSION_ID)
5. 更新浏览器心跳：chromeSet.updateHeartbeats(key, System.nanoTime())
6. 过期UserBind：remote.expiredUserBind(key)
```

#### 3.8.8 close(ChannelHandlerContext ctx, boolean closeByError) 方法

**功能**: 关闭连接

**执行流程**:
```
1. 从上下文获取Client对象
2. 关闭会话：closeSession(cli)

#### 3.12.3 onOpen(Session session, @PathVariable String imeiAndImsi, @RequestParam MultiValueMap<String, String> requestMap) 方法

**功能**: WebSocket连接建立时触发

**执行流程**:
```

4. 根据录制模式创建流处理器：
   - 如果config.getChrome().getRecordMode() == RecordModeEnum.WEBCODECS.getMode()：
     * mediaStreamProcessor = new WebCodecsStreamProcessor(clients, imeiAndImsi)
   - 否则：

5. 添加处理器：mediaSessionManager.addProcessor(imeiAndImsi, mediaStreamProcessor)
6. 解析请求参数：
   - 转换为单值Map：requestMap.toSingleValueMap()
   - 序列化为JSON：JSONUtil.toJsonStr(params)
   - 反序列化为MediaParam：JSONUtil.toBean(jsonStr, MediaParam.class)

| userId | `String` | final | 用户ID |

#### 3.15.2 构造函数

**执行流程**:
```
1. 保存clientSet和userId
2. 创建userIdPtr：new CharPointer(userId)
3. 分配缓存缓冲区：ByteBuffer.allocateDirect(FfmpegConstants.CACHE_SIZE)
4. 创建readPacket回调（调用readHook方法）
5. 创建writeVideoPacket回调（调用writeVideoHook方法）
6. 创建writeAudioPacket回调（调用writeAudioHook方法）
```

#### 3.15.3 init(MediaParam initParam) 方法

**功能**: 初始化FFmpeg处理器

**执行流程**:
```
1. 保存mediaParam
2. 创建FfmpegCodecService：new FfmpegCodecService(initParam)
3. 记录开始时间：startTime = System.currentTimeMillis()
4. 提交异步任务到executor：
   a. 等待缓存缓冲区有数据：
      - 循环检查cacheBuffer.position() <= 0
      - 如果等待超过120秒，设置isEOF=true并返回
      - 每次等待50毫秒
   b. 打印日志："wait for connection success, user:{userId}"
   c. 初始化FFmpeg服务：
      * ffmpegCodecService.init(userIdPtr, readPacket, writeVideoPacket, writeAudioPacket)
      * 如果失败，打印error日志并返回
   d. 启动FFmpeg服务：ffmpegCodecService.start()
```

#### 3.15.4 processMediaStream(byte[] data) 方法

**功能**: 处理媒体流数据

**执行流程**:
```
1. 如果isEOF为true，直接返回
2. 获取数据偏移和长度：offset=0, length=data.length
3. 同步写入缓存缓冲区：
   - 如果剩余空间足够：cacheBuffer.put(data, offset, length)
   - 否则：打印error日志（缓存空间不足）
```

#### 3.15.5 close() 方法

**功能**: 关闭处理器

**执行流程**:
```
1. 设置isEOF = true
2. 如果executor未关闭：executor.shutdown()
```

#### 3.15.6 readHook(BytePointer buf, int bufSize) 方法

**功能**: FFmpeg读取数据包回调

**执行流程**:
```
1. 如果isEOF为true，返回AVERROR_EOF
2. 等待缓存缓冲区有数据：
   - 循环检查cacheBuffer.position() <= 0
   - 每次等待50毫秒
3. 计算读取长度：len = Math.min(bufSize, cacheBuffer.position())
4. 同步读取数据：
   - cacheBuffer.flip()
   - 读取数据到字节数组
   - cacheBuffer.compact()
5. 将数据写入FFmpeg缓冲区：buf.put(data, 0, len)
6. 返回读取长度
```

#### 3.15.7 writeVideoHook(BytePointer buf, int bufSize) 方法

**功能**: FFmpeg写入视频数据包回调

**执行流程**:
```
1. 如果isEOF为true，返回AVERROR_EOF
2. 从FFmpeg缓冲区读取数据：buf.get(data, 0, bufSize)
3. 判断是否为关键帧：
   - 如果videoSeq % gopSize == 0：isKeyFrame = 1
   - 否则：isKeyFrame = 0
4. 判断是否需要丢帧：
   - 如果videoSeq < dropFrameMulti * frameRate：videoSeq++，直接返回bufSize（丢弃）
5. 创建VideoResponse：new VideoResponse(++videoSeq, data, userId, isKeyFrame)
6. 获取客户端：clientSet.get(userId)
7. 如果客户端不为null：
   - 发送响应：client.send(videoResponse)
8. 返回bufSize
```

#### 3.15.8 writeAudioHook(BytePointer buf, int bufSize) 方法

**功能**: FFmpeg写入音频数据包回调

**执行流程**:
```
1. 如果isEOF为true，返回AVERROR_EOF
2. 从FFmpeg缓冲区读取数据：buf.get(data, 0, bufSize)
3. 创建AudioResponse：new AudioResponse(++audioSeq, data, userId)
4. 获取客户端：clientSet.get(userId)
5. 如果客户端不为null：
   - 发送响应：client.send(audioResponse)
6. 返回bufSize

**异常处理**: catch所有异常，调用close()，打印error日志，返回false

#### 3.17.3 streamCodec(AVPacket pkt) 方法

**功能**: 处理视频数据包（解码->编码）

**执行流程**:
```
1. 发送数据包到解码器：avcodec.avcodec_send_packet(decodeCtx, pkt)
2. 循环接收解码帧：
   a. 接收帧：avcodec.avcodec_receive_frame(decodeCtx, frame)
   b. 如果返回AVERROR_EOF或AVERROR_EAGAIN：跳出循环
   c. 如果返回值<0：抛出RuntimeException("Error during decoding")
   d. 设置帧属性：
      * frame.pts = frame.best_effort_timestamp()
      * frame.time_base = decodeCtx.pkt_timebase()
      * frame.pict_type = AV_PICTURE_TYPE_NONE
   e. 编码帧：encodeVideoFrame(frame)
```

#### 3.17.4 encodeVideoFrame(AVFrame frame) 方法

**功能**: 编码视频帧

**执行流程**:
```
1. 如果frame不为null且pts有效：
   - 转换时间基准：frame.pts = av_rescale_q(frame.pts, frame.time_base, encodeCtx.time_base)
2. 发送帧到编码器：avcodec.avcodec_send_frame(encodeCtx, frame)
3. 循环接收编码数据包：
   a. 接收数据包：avcodec.avcodec_receive_packet(encodeCtx, encodePacket)
   b. 如果返回AVERROR_EOF或AVERROR_EAGAIN：跳出循环
   c. 如果返回值<0：抛出RuntimeException("Error during receiving a packet")
   d. 设置流索引：encodePacket.stream_index = 0
   e. 处理DTS时间戳：
      * 如果lastDTS >= encodePacket.dts：lastDTS++，设置dts和pts = lastDTS
   f. 更新lastDTS = encodePacket.dts
   g. 转换时间戳：av_packet_rescale_ts(encodePacket, encodeCtx.time_base, encodeCtx.pkt_timebase)
   h. 写入帧：avformat.av_write_frame(outFormatCtx, encodePacket)
   i. 释放数据包引用：avcodec.av_packet_unref(encodePacket)
```

#### 3.17.5 initDecCtx(AVFormatContext inFormartCtx) 方法

**功能**: 初始化解码器上下文

```

2. 如果未找到流：抛出RuntimeException("Cannot find video stream")
3. 获取流：stream = inFormatCtx.streams(streamIndex)
4. 查找解码器：decoder = avcodec.avcodec_find_decoder(stream.codecpar().codec_id())
5. 分配解码器上下文：codecCtx = avcodec.avcodec_alloc_context3(decoder)
6. 复制参数：avcodec.avcodec_parameters_to_context(codecCtx, stream.codecpar())

12. 从上下文复制参数：avcodec.avcodec_parameters_from_context(stream.codecpar(), encodeCtx)

**功能**: 初始化WebCodecs处理器

**说明**: 当前为空实现，WebCodecs模式不需要额外初始化

#### 3.19.4 processMediaStream(byte[] data) 方法

**功能**: 处理媒体流数据

**执行流程**:
```
1. 检查数据格式（支持两种格式）：
   a. 新格式：[4字节: 帧类型][4字节: 时间戳][4字节: 数据长度][N字节: 数据]
      - 如果data.length >= 12：
        * 解析帧类型：frameType = (data[0]<<24) | (data[1]<<16) | (data[2]<<8) | data[3]
        * 解析时间戳：timestamp = (data[4]<<24) | (data[5]<<16) | (data[6]<<8) | data[7]
        * 解析数据长度：dataLength = (data[8]<<24) | (data[9]<<16) | (data[10]<<8) | data[11]
        * 提取视频数据：videoData = ArrayUtil.sub(data, 12, data.length)
        * 转换帧类型：convertedFrameType = (byte)frameType
        * 创建VideoResponse：new VideoResponse(++videoSeq, videoData, userId, convertedFrameType)
        * 获取客户端：clients.get(userId)
        * 如果客户端不为null：
          - 提交到videoThread异步发送：client.send(response)
        * 返回
   b. 旧格式：[1字节: type][1字节: frameType][N字节: data]
      - 读取type = data[0]
      - 如果type == VIDEO_TYPE：
        * 读取frameType = data[1]
        * 提取视频数据：videoData = ArrayUtil.sub(data, 2, data.length)
        * 创建VideoResponse：new VideoResponse(++videoSeq, videoData, userId, frameType)
        * 获取客户端：clients.get(userId)
        * 如果客户端不为null：
          - 提交到videoThread异步发送：client.send(response)
        * 返回
      - 如果type == AUDIO_TYPE：
        * 提取音频数据：audioData = ArrayUtil.sub(data, 1, data.length)
        * 创建AudioResponse：new AudioResponse(++audioSeq, audioData, userId)
        * 获取客户端：clients.get(userId)
        * 如果客户端不为null：
          - 提交到audioThread异步发送：client.send(response)
      - 否则：打印warn日志（未知类型）
```

#### 3.19.5 close() 方法

**功能**: 关闭处理器

**执行流程**:
```
1. 如果videoThread未关闭：videoThread.shutdown()
2. 如果audioThread未关闭：audioThread.shutdown()
```

## 6. 关键流程

### 6.1 控制通道登录完整流程

```
客户端 -> ControlTcpServer/ControlTlvServer
  -> ControlTcpServerHandler.channelRead()
    -> processLogin(cli, tlv)
      -> 解析TLV为Message对象
      -> 校验lcdWidth和lcdHeight
      -> 生成key = Type.tcpBindKey(imei, imsi)
      -> IRemote.getUserBind(key) [获取用户绑定信息]
      -> 校验token
      -> 设置客户端属性（sessionId、appType、心跳时间等）
      -> ControlClientSet.set(key, cli) [保存客户端]
      -> 发送ACK应答
      -> IChromeSet.updateHeartbeats() [更新浏览器心跳]
      -> IRemote.updateUserBind() [更新用户绑定]
      -> 异步创建浏览器：createBrowser()
        -> 转换为InitBrowserRequest
        -> IRemote.createChrome(bytes, request, callback)
          -> [远程通信模块处理]
          -> IChromeSet.create() [创建浏览器实例]
          -> callback: 发送LoginResponse（包含媒体端点地址）
      -> IRemote.sendSession() [上报会话登录事件]
```

### 6.2 媒体通道登录完整流程

```
客户端 -> MediaTcpServer/MediaTlvServer
  -> MediaTcpServerHandle.channelRead()
    -> processLogin(client, tlv)
      -> 解析TLV为Message对象
      -> 生成key = Type.tcpBindKey(imei, imsi)
      -> IRemote.getUserBind(key) [获取用户绑定信息]
      -> 校验token
      -> 设置客户端属性
      -> MediaClientSet.set(key, client) [保存客户端]
      -> 发送ACK应答
      -> IRemote.reportEvent() [上报数据处理登录事件]
```

### 6.3 WebSocket媒体流处理完整流程

```
浏览器 -> MediaStreamSocketServer.onOpen()
  -> 根据录制模式创建流处理器：
     - WEBCODECS模式：WebCodecsStreamProcessor
     - FFMPEG模式：FfmpegStreamProcessor
  -> 解析请求参数为MediaParam
  -> 初始化处理器：processor.init(initParam)
    [FFmpeg模式]：
      -> 等待缓存缓冲区有数据（最多120秒）
      -> FfmpegCodecService.init() [初始化FFmpeg]
        -> 初始化输入格式上下文
        -> 初始化视频编解码器
        -> 初始化音频编解码器
      -> FfmpegCodecService.start() [启动编解码循环]
        -> 循环读取数据包
        -> 解码->编码处理
        -> 通过回调写入数据包

浏览器 -> MediaStreamSocketServer.onBinary(data)
  -> MediaSessionManager.getProcessor(userId)
  -> processor.processMediaStream(data)
    [WebCodecs模式]：
      -> 解析数据格式（新格式/旧格式）
      -> 创建VideoResponse/AudioResponse
      -> MediaClientSet.get(userId)
      -> Client.send(response) [发送到TCP客户端]
    [FFmpeg模式]：
      -> 写入缓存缓冲区
      -> FFmpeg通过readHook读取
      -> 解码->编码
      -> 通过writeVideoHook/writeAudioHook回调
      -> 创建VideoResponse/AudioResponse
      -> 发送到TCP客户端

TCP客户端 -> MediaTcpServerHandle.channelRead()
  -> 处理登录/心跳/其他消息
  -> 通过TlvEncoder编码响应
  -> 发送到客户端
```

### 6.4 控制事件转发流程

```
客户端 -> ControlTcpServerHandler.channelRead()
  -> processDefault(cli, tlv, type)
    -> 解析TLV为Message对象
    -> 发送ACK应答
    -> TLV序列化为字节数组
    -> IRemote.handleEvent(bytes, sessionId)
      -> [远程通信模块处理]
      -> 转发到浏览器实例
```

### 6.5 流量统计上报流程

```
数据发送/接收 -> TlvEncoder/TlvDecoder
  -> DataSizeTracker.addDataSize() [累加数据大小]
  -> FlowRateTracker.add() [累加流量速率]

定时任务（每period毫秒） -> DataSizeTracker.SendAllTrafficStatInfo()
  -> 遍历dataSizeMap
  -> 创建Traffic对象列表
  -> 分批发送（每批1000条）
  -> IRemote.sendTrafficMedia() / sendTrafficControl()

连接关闭 -> ControlTcpServerHandler.close()
  -> FlowRateTracker.flowRateStat() [获取并清除流量统计]
  -> 创建FlowStatEvent
  -> IRemote.reportEvent() [上报流量统计事件]
```

## 7. 线程安全设计

### 7.1 并发控制

| 组件 | 线程安全机制 | 说明 |
|------|-------------|------|
| ClientSet.map | ConcurrentHashMap | 线程安全的客户端映射表 |
| MediaSessionManager.processorMap | ConcurrentHashMap | 线程安全的处理器映射表 |
| DataSizeTracker.dataSizeMap | ConcurrentHashMap + AtomicLong | 线程安全的数据统计 |
| FlowRateTracker.flowRateMap | ConcurrentHashMap + AtomicLong | 线程安全的流量统计 |
| FfmpegStreamProcessor.cacheBuffer | synchronized(lock) | 缓存缓冲区同步访问 |
| CertInfo静态字段 | synchronized方法 | 证书信息同步访问 |

### 7.2 Netty线程模型

- **Boss线程组**：负责接收客户端连接（每个端口一个线程）
- **Worker线程组**：负责处理客户端数据（多个线程，可配置）
- **ChannelHandler**：每个连接绑定一个Handler实例，在Worker线程中执行

### 7.3 异步处理

- **浏览器创建**：`ThreadUtil.execute()` 异步执行，避免阻塞登录流程
- **WebCodecs处理**：使用独立的videoThread和audioThread异步发送响应
- **FFmpeg处理**：使用executor线程池异步执行编解码循环

## 8. 异常处理

### 8.1 TCP服务器层

- **AbstractTcpServer.start()**：catch所有异常，打印error日志，不中断启动流程
- **AbstractTcpServer.stop()**：catch InterruptedException，恢复中断标志

### 8.2 消息处理层

- **ControlTcpServerHandler.processLogin()**：
  - 参数校验失败：抛出RuntimeException，触发exceptionCaught()
  - UserBind不存在：抛出RuntimeException
  - Token校验失败：抛出RuntimeException
- **ControlTcpServerHandler.createBrowser()**：
  - 异常时发送失败ACK，打印error日志，不向上传播
- **MediaTcpServerHandle.processLogin()**：
  - 异常处理同ControlTcpServerHandler
- **exceptionCaught()**：
  - 打印error日志（包含堆栈）
  - 调用close()关闭连接

### 8.3 WebSocket层

- **MediaStreamSocketServer.onOpen()**：
  - init()异常时打印error日志，删除会话
- **MediaStreamSocketServer.onError()**：
  - 打印error日志，删除会话

### 8.4 FFmpeg编解码层

- **FfmpegCodecService.init()**：
  - 异常时打印error日志，调用close()，返回false
- **FfmpegCodecService.start()**：
  - av_read_frame失败：打印error日志，调用close()，返回
  - streamCodec异常：打印error日志，调用close()，抛出异常
- **VideoCodecProcessor/AudioCodecProcessor**：
  - 编解码异常：抛出RuntimeException，由上层捕获处理

### 8.5 数据统计层

- **DataSizeTracker.SendAllTrafficStatInfo()**：
  - 键解析失败：打印error日志，跳过该条目
  - 远程服务调用失败：由IRemote内部处理，不影响统计
