# BrowserGateway 配置项说明书

## 目录结构

本配置说明书涵盖 `src/main/java/com/huawei/browsergateway/config` 目录下的所有配置类，共8个配置文件。

---

## 1. ApplicationConfig

**文件路径**: `ApplicationConfig.java`

**作用**: 配置Spring Boot应用的外部配置文件加载路径，支持Windows和Linux不同操作系统的配置文件位置。

**功能说明**:
- 自动检测操作系统类型（Windows/Linux）
- 根据操作系统动态加载 `application.yaml` 配置文件
- 将YAML配置文件转换为Properties对象并注入到Spring容器

**配置文件位置规则**:
- **Windows系统**: `jar包路径/../src/main/resources/application.yaml`
- **Linux系统**: `jar包路径/conf/application.yaml`

**日志输出**:
- 启动时会打印配置文件的完整路径
- 启动时会打印配置文件的所有内容

**无外部可配置项**（自动根据运行环境确定）

---

## 2. Config

**文件路径**: `Config.java`

**作用**: 核心配置类，聚合所有子配置并提供常用路径计算方法。

### 2.1 常量定义

| 常量名 | 值 | 说明 |
|--------|-----|------|
| USER_DATA_PATH | `"userdata"` | 用户数据目录 |
| BASE_DATA_PATH | `"basedata"` | 基础数据目录 |
| LOCAL_STORAGE_PATH | `"storage"` | 本地存储目录 |
| TMP_PATH | `"tmp"` | 临时文件目录 |
| EXTENSION_PATH | `"extension"` | 浏览器扩展目录 |
| KEY | `"keys"` | 密钥扩展目录 |
| TOUCH | `"touch"` | 触控扩展目录 |
| RECORD | `"record"` | 录制扩展目录 |
| JAR | `"jar"` | JAR包目录 |

### 2.2 配置项

| 配置项 | 配置键 | 类型 | 必填 | 默认值 | 说明 |
|--------|--------|------|------|--------|------|
| workspace | `browsergw.workspace` | String | 是 | - | 工作空间根目录，所有子目录的父路径 |
| contextLimit | `browsergw.context-limit` | int | 否 | 40 | Chrome浏览器上下文数量限制 |
| address | `server.address` | String | 是 | - | 服务器监听地址 |
| port | `server.port` | Integer | 是 | - | 服务器监听端口 |

### 2.3 聚合的子配置

- `ReportConfig report` - 上报配置
- `WebsocketConfig websocket` - WebSocket配置
- `TcpConfig tcp` - TCP配置
- `ChromeConfig chrome` - Chrome浏览器配置

### 2.4 计算方法

| 方法名 | 返回类型 | 说明 | 示例结果 |
|--------|----------|------|----------|
| `getLocalStoragePath()` | String | 获取本地存储目录绝对路径 | `{workspace}/storage` |
| `getUserDataPath()` | String | 获取用户数据目录绝对路径 | `{workspace}/userdata` |
| `getBaseDataPath()` | String | 获取基础数据目录绝对路径 | `{workspace}/basedata` |
| `getTmpPath()` | String | 获取临时文件目录绝对路径 | `{workspace}/tmp` |
| `getExtensionPath()` | String | 获取扩展目录绝对路径 | `{workspace}/extension` |
| `getKeyExtensionPath()` | String | 获取密钥扩展目录绝对路径 | `{workspace}/extension/keys` |
| `getJarDirPath()` | String | 获取JAR目录绝对路径 | `{workspace}/jar` |
| `getTouchExtensionPath()` | String | 获取触控扩展目录绝对路径 | `{workspace}/extension/touch` |
| `getRecordExtensionPath()` | String | 获取录制扩展目录绝对路径 | `{workspace}/extension/record` |
| `getCodecMode()` | String | 获取编解码模式 | `"ffmpeg"` 或 `"webcodecs"` |
| `getRecordExtensionPage()` | String | 获取录制扩展页面URL | `chrome-extension://{id}/offscreen.html` |
| `getSelfAddr()` | String | 获取服务自身地址 | `{address}:{port}` |
| `getInnerMediaEndpoint()` | String | 获取内部媒体流端点 | `{address}:{websocket.mediaPort}` |

## 3. ChromeConfig

**文件路径**: `ChromeConfig.java`

**作用**: 配置Chrome浏览器的运行参数和扩展信息。

### 配置项

| 配置项 | 配置键 | 类型 | 必填 | 默认值 | 说明 |
|--------|--------|------|------|--------|------|
| recordMode | `browsergw.chrome.record-mode` | Integer | 是 | - | 录制模式：<br>• 0 = ffmpeg模式<br>• 1 = webcodecs模式 |
| headless | `browsergw.chrome.headless` | boolean | 否 | false | Chrome是否以无头模式启动（无GUI界面） |
| recordExtensionId | `browsergw.chrome.record-extension-id` | String | 是 | - | 录制扩展的Chrome扩展ID |
| endpoint | `browsergw.chrome.endpoint` | String | 是 | - | Chrome远程调试端点地址 |
| executablePath | `browsergw.chrome.executable-path` | String | 是 | - | Chrome可执行文件的完整路径 |

### 录制模式说明

- **ffmpeg模式 (0)**: 使用FFmpeg进行视频录制，兼容性好但性能一般
- **webcodecs模式 (1)**: 使用浏览器原生WebCodecs API进行录制，性能更优

## 4. ReportConfig

**文件路径**: `ReportConfig.java`

**作用**: 配置服务信息上报相关参数，包括控制流、媒体流的端点地址。

### 配置项

| 配置项 | 配置键 | 类型 | 必填 | 默认值 | 说明 |
|--------|--------|------|------|--------|------|
| controlEndpoint | `browsergw.report.control-endpoint` | String | 是 | - | 控制流对外暴露地址（格式：`ip:port`） |
| controlTlsEndpoint | `browsergw.report.control-tls-endpoint` | String | 否 | `41.203.73.4:30011` | 控制流TLS对外暴露地址，若环境变量为空则使用默认值（尼日局点兼容） |
| mediaEndpoint | `browsergw.report.media-endpoint` | String | 是 | - | 媒体流对外暴露地址（格式：`ip:port`） |
| mediaTlsEndpoint | `browsergw.report.media-tls-endpoint` | String | 否 | `41.203.73.4:30013` | 媒体流TLS对外暴露地址，若环境变量为空则使用默认值（尼日局点兼容） |
| cap | `browsergw.report.cap` | Integer | 是 | - | 服务容量，表示服务能同时处理的客户端数量上限 |
| ttl | `browsergw.report.ttl` | Integer | 是 | - | 上报信息过期时间，单位：秒 |
| chainEndpoints | `browsergw.report.chain-endpoints` | String | 是 | - | Chain平面访问地址列表（多个地址间用逗号分隔） |

### 使用场景

- 上报服务注册信息到服务中心
- 用于服务发现和负载均衡
- TLS地址用于加密通信场景

## 5. TcpConfig

**文件路径**: `TcpConfig.java`

**作用**: 配置TCP服务器相关参数，包括控制流和媒体流的监听端口和网络配置。

### 配置项

| 配置项 | 配置键 | 类型 | 必填 | 默认值 | 说明 |
|--------|--------|------|------|--------|------|
| address | `browsergw.tcp.address` | String | 是 | - | TCP服务器监听地址 |
| controlPort | `browsergw.tcp.control-port` | Integer | 是 | - | TCP控制流监听端口 |
| mediaPort | `browsergw.tcp.media-port` | Integer | 是 | - | TCP媒体流监听端口 |
| controlTlsPort | `browsergw.tcp.control-tls-port` | Integer | 是 | - | TCP控制流TLS监听端口 |
| mediaTlsPort | `browsergw.tcp.media-tls-port` | Integer | 是 | - | TCP媒体流TLS监听端口 |
| heartbeatTtl | `browsergw.tcp.heartbeat-ttl` | long | 是 | - | TCP心跳检测超时时间，单位：毫秒 |
| enableHttp | `browsergw.tcp.enable-http` | boolean | 是 | - | 是否启用HTTP协议支持 |

### 端口说明

- **控制流端口**: 用于传输控制指令（如鼠标、键盘输入）
- **媒体流端口**: 用于传输音视频数据
- **TLS端口**: 加密传输端口，用于安全通信场景

## 6. WebsocketConfig

**文件路径**: `WebsocketConfig.java`

**作用**: 配置WebSocket服务器相关参数，用于实时数据传输。

### 配置项

| 配置项 | 配置键 | 类型 | 必填 | 默认值 | 说明 |
|--------|--------|------|------|--------|------|
| mediaPort | `browsergw.websocket.media-port` | Integer | 是 | - | WebSocket媒体流监听端口 |
| muenPort | `browsergw.websocket.muen-port` | Integer | 是 | - | WebSocket Muen服务监听端口 |
| boss | `browsergw.websocket.boss` | Integer | 是 | - | Netty Boss线程池大小（接受连接的线程数） |
| worker | `browsergw.websocket.worker` | Integer | 是 | - | Netty Worker线程池大小（处理IO的线程数） |
| heartbeatTtl | `browsergw.websocket.heartbeat-ttl` | Long | 是 | - | WebSocket心跳检测超时时间，单位：毫秒 |

### 线程池配置建议

- **boss线程数**: 通常设置为1，因为只需要一个线程监听并接受连接
- **worker线程数**: 建议设置为CPU核心数的2倍，用于处理大量并发IO操作

## 7. SchedulingConfig

**文件路径**: `SchedulingConfig.java`

**作用**: 启用Spring的定时任务调度功能。

**功能说明**:
- 通过 `@EnableScheduling` 注解启用定时任务支持
- 使项目中所有使用 `@Scheduled` 注解的方法能够按计划执行

**无外部可配置项**

---

## 8. DataTrackerConfig

**文件路径**: `DataTrackerConfig.java`

**作用**: 配置数据流量追踪器，用于统计和监控TCP数据传输量。

### Bean定义

| Bean名称 | 类型 | 作用 |
|----------|------|------|
| `mediaDataSizeTracker` | `DataSizeTracker` | 追踪媒体流数据传输量（类型：`TCP_MEDIA`） |
| `controlDataSizeTracker` | `DataSizeTracker` | 追踪控制流数据传输量（类型：`TCP_CONTROL`） |

### 数据流类型

- **TCP_MEDIA**: 媒体流数据（音视频）
- **TCP_CONTROL**: 控制流数据（指令）

**无外部可配置项**（自动注入两个追踪器Bean）

## 配置文件示例

以下是一个完整的 `application.yaml` 配置示例：

```yaml
# 服务器基础配置
server:
  address: 0.0.0.0
  port: 8080

# 工作空间配置
browsergw:
  workspace: /opt/browsergateway
  context-limit: 40

  # Chrome浏览器配置
  chrome:
    record-mode: 1              # 0=ffmpeg, 1=webcodecs
    headless: false
    record-extension-id: abcdefghijklmnopqrstuvwxyz
    endpoint: 127.0.0.1:9222
    executable-path: /usr/bin/google-chrome

  # 上报配置
  report:
    control-endpoint: 192.168.1.100:30010
    control-tls-endpoint: 192.168.1.100:30011
    media-endpoint: 192.168.1.100:30012
    media-tls-endpoint: 192.168.1.100:30013
    cap: 100
    ttl: 300
    chain-endpoints: 192.168.1.101:8080,192.168.1.102:8080

  # TCP配置
  tcp:
    address: 0.0.0.0
    control-port: 30010
    media-port: 30012
    control-tls-port: 30011
    media-tls-port: 30013
    heartbeat-ttl: 30000
    enable-http: false

  # WebSocket配置
  websocket:
    media-port: 30012
    muen-port: 30014
    boss: 1
    worker: 4
    heartbeat-ttl: 30000
```

## 注意事项

1. **路径配置**: `workspace` 是所有相对路径的根目录，确保该目录有足够的磁盘空间和读写权限。

2. **端口冲突**: 确保所有配置的端口未被其他进程占用，特别是：
   - TCP控制流端口和TLS端口
   - TCP媒体流端口和TLS端口
   - WebSocket媒体流端口和Muen端口

3. **录制模式选择**:
   - 性能优先：选择 `webcodecs` (mode=1)
   - 兼容性优先：选择 `ffmpeg` (mode=0)

4. **线程池调优**: 根据实际并发量调整 `boss` 和 `worker` 线程数，避免资源浪费或性能瓶颈。

5. **心跳超时**: `heartbeatTtl` 应根据网络延迟合理设置，过短会导致频繁断连，过长会影响故障检测速度。

6. **TLS默认值**: `controlTlsEndpoint` 和 `mediaTlsEndpoint` 的默认值用于尼日局点兼容，其他局点必须显式配置。

7. **环境变量**: 支持通过环境变量覆盖配置项，优先级：环境变量 > 配置文件 > 默认值。
