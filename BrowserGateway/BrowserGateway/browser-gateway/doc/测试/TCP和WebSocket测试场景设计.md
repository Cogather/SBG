## 2. WebSocket媒体流传输测试场景（FR-006）

### 2.1 功能需求回顾

**URL**: `ws://{server}:30002/browser/websocket/{imeiAndImsi}`

**技术要求**：
- 支持两种编解码模式：WebCodecs模式和FFmpeg模式
- 客户端连接后必须发送初始化参数
- 媒体流数据格式：`[4字节: 帧类型][4字节: 时间戳][4字节: 数据长度][N字节: 数据]`
- 视频帧类型：1-I帧, 2-P帧, 3-Audio帧
- 性能要求：延迟 < 100ms，支持30fps以上流畅播放

### 2.2 测试场景设计

#### 场景组1：连接建立测试

| 场景编号 | 场景描述 | 测试条件 | 预期结果 | 优先级 |

| WS-MEDIA-001 | 正常连接建立 | 有效的imeiAndImsi，正确的URL | 连接成功，会话创建 | 高 |
| WS-MEDIA-002 | imeiAndImsi为空 | URL中imeiAndImsi为空 | 连接失败或拒绝 | 高 |
| WS-MEDIA-003 | imeiAndImsi格式错误 | imeiAndImsi包含非法字符 | 连接失败或拒绝 | 中 |
| WS-MEDIA-004 | 重复连接 | 同一用户建立多个连接 | 新连接覆盖旧连接或拒绝 | 中 |
| WS-MEDIA-005 | 连接超时 | 连接建立后长时间无数据 | 连接自动关闭 | 中 |

#### 场景组2：初始化参数测试

| 场景编号 | 场景描述 | 测试条件 | 预期结果 | 优先级 |
|---------|---------|---------|---------|--------|
| WS-MEDIA-006 | 正常初始化参数 | 所有参数有效 | 初始化成功，处理器创建 | 高 |
| WS-MEDIA-007 | 缺少必填参数 | width/height/frameRate等缺失 | 使用默认值或初始化失败 | 高 |
| WS-MEDIA-008 | 参数值超出范围 | width/height为负数或过大 | 使用默认值或初始化失败 | 中 |
| WS-MEDIA-009 | 参数类型错误 | 参数类型不匹配 | 初始化失败 | 中 |
| WS-MEDIA-010 | WebCodecs模式初始化 | codecType=WebCodecs | 创建WebCodecsStreamProcessor | 高 |
| WS-MEDIA-011 | FFmpeg模式初始化 | codecType=FFmpeg或默认 | 创建FfmpegStreamProcessor | 高 |

**初始化参数验证**：
```json
{
  "width": 1920,              // 默认: 1920，范围: >0
  "height": 1080,             // 默认: 1080，范围: >0
  "frameRate": 30,            // 默认: 30，范围: 1-60
  "sampleRate": 44100,        // 默认: 44100，范围: 8000-48000
  "channels": 2,              // 默认: 2，范围: 1-8
  "bitRate": 128,             // 默认: 128，范围: 32-320
  "gopSize": 29,              // 默认: frameRate-1
  "dropFrameMulti": 0.0,      // 默认: 0.0，范围: 0.0-1.0
  "codecType": "H264"         // 默认: H264，可选: H264/H265
}
```
