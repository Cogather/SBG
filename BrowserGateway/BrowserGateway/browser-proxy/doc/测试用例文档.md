# Browser Proxy API 测试用例文档

## 测试说明

本文档为 Browser Proxy 项目的完整 API 测试用例，涵盖所有接口的功能验证。每个接口都包含正常场景、异常场景和边界情况的测试用例，便于功能验收和自动化测试。

---

## 1. 浏览器管理 API 测试用例

### 1.1 创建浏览器实例 (POST /api/browsers)

#### TC-BROWSER-001: 创建浏览器实例 - 正常场景
**测试目标**: 验证能成功创建基本的浏览器实例  
**前置条件**: 服务正常运行，Chromium浏览器已安装  
**测试数据**:
```json
{
  "executable_path": "/usr/bin/google-chrome-stable",
  "browser_type": "KEYS",
  "headless": true,
  "language": "en-US"
}
```
**预期结果**: 
- HTTP状态码: 200
- 响应包含浏览器ID和浏览器类型
- 浏览器实例被创建并添加到全局列表

#### TC-BROWSER-002: 创建浏览器实例 - 指定ID
**测试目标**: 验证能成功创建指定ID的浏览器实例  
**测试数据**:
```json
{
  "executable_path": "/usr/bin/google-chrome-stable",
  "browser_id": "test-browser-001",
  "browser_type": "KEYS",
  "headless": true
}
```
**预期结果**: 
- HTTP状态码: 200
- 响应返回指定的browser_id
- 通过该ID能成功获取浏览器信息

#### TC-BROWSER-003: 创建浏览器实例 - TOUCH模式
**测试目标**: 验证能成功创建TOUCH模式浏览器实例  
**测试数据**:
```json
{
  "executable_path": "/usr/bin/google-chrome-stable",
  "browser_type": "TOUCH",
  "headless": true
}
```
**预期结果**: 
- HTTP状态码: 200
- 响应中browser_type为"TOUCH"
- 浏览器支持触摸操作

#### TC-BROWSER-004: 创建浏览器实例 - 用户数据目录
**测试目标**: 验证能使用自定义用户数据目录  
**测试数据**:
```json
{
  "executable_path": "/usr/bin/google-chrome-stable",
  "browser_type": "KEYS",
  "base_data": "/tmp/test_user_data"
}
```
**预期结果**: 
- HTTP状态码: 200
- 浏览器使用指定用户数据目录
- 多次重启后状态保持一致

#### TC-BROWSER-005: 创建浏览器实例 - 扩展管理
**测试目标**: 验证能加载和管理浏览器扩展  
**测试数据**:
```json
{
  "executable_path": "/usr/bin/google-chrome-stable",
  "browser_type": "KEYS",
  "extension_paths": ["/path/to/test_extension.crx"],
  "extension_ids": ["test-extension-id"],
  "allowlisted_extension_id": "test-extension-id"
}
```
**预期结果**: 
- HTTP状态码: 200
- 扩展被成功加载
- 白名单扩展正常工作

#### TC-BROWSER-006: 创建浏览器实例 - 无效路径
**测试目标**: 验证无效executable_path的错误处理  
**测试数据**:
```json
{
  "executable_path": "/invalid/path/to/browser",
  "browser_type": "KEYS"
}
```
**预期结果**: 
- HTTP状态码: 500
- 错误信息包含路径无效提示

#### TC-BROWSER-007: 创建浏览器实例 - 重复ID
**测试目标**: 验证重复browser_id的处理  
**前置条件**: 已存在ID为"existing-browser"的浏览器  
**测试数据**:
```json
{
  "executable_path": "/usr/bin/google-chrome-stable",
  "browser_id": "existing-browser",
  "browser_type": "KEYS"
}
```
**预期结果**: 
- HTTP状态码: 500或409
- 提示浏览器ID已存在

#### TC-BROWSER-008: 创建浏览器实例 - 无效浏览器类型
**测试目标**: 验证无效browser_type的错误处理  
**测试数据**:
```json

  "executable_path": "/usr/bin/google-chrome-stable",
  "browser_type": "INVALID_TYPE"
}
```

- HTTP状态码: 422
