# BrowserGateway 测试步骤总结

## 快速测试流程

### 第一步：环境准备

```bash
# 1. 进入项目目录
cd browsergateway-test-client

# 2. 创建虚拟环境（可选但推荐）
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Linux/Mac

# 3. 安装依赖
pip install -r requirements.txt
```

### 第二步：配置服务器

编辑 `config/config.yaml`，修改服务器地址：

```yaml
server:
  address: "你的服务器IP"  # 例如: "192.168.1.100"
  http_port: 8090
  # ... 其他端口配置
```

### 第三步：启动测试

#### 方式一：Web 界面测试（推荐，可视化）

```bash
# 启动 Web 服务器
python scripts/run_test.py

# 浏览器访问
http://localhost:8000
```

**在 Web 界面中：**
1. 配置服务器地址、IMEI、IMSI
2. 选择协议类型（TCP 控制流/媒体流 或 WebSocket 控制流/媒体流）
3. 点击"连接"按钮
4. 使用虚拟按键或触摸屏发送控制事件
5. 点击"开始视频流"测试媒体流传输
6. 使用 REST API 按钮测试各种接口

#### 方式二：自动化测试（命令行）

**推荐使用一键脚本：**

```bash
# Linux/Mac/Git Bash - 一键启动服务并测试
./scripts/run_all_tests.sh

# Windows CMD - 一键启动服务并测试
scripts\run_all_tests.bat
```

**或手动运行测试：**

```bash
# 运行所有测试
pytest tests/ -v

# 运行 TCP 控制流测试
pytest tests/test_tcp_control.py -v

# 运行 TCP 媒体流测试
pytest tests/test_tcp_media.py -v

# 运行 WebSocket 测试
pytest tests/test_websocket_control.py -v
pytest tests/test_websocket_media.py -v

# 运行 REST API 测试
pytest tests/test_rest_api.py -v
```

## 常见问题快速解决

| 问题 | 解决方案 |
|------|---------|
| 连接失败 | 检查服务器地址和端口，确认服务器已启动 |
| TLS 错误 | 检查 TLS 端口配置，查看服务器日志 |
| 测试失败 | 确认服务器运行中，检查配置文件 |
| 依赖安装失败 | 使用国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
